OfficeFlow 3 사용자 안내

업무가 많아도 빠르게 찾고, 하루 일정부터 여러 날·반복 일정까지 한곳에서 관리합니다.

시작하기업무와 일정많은 업무 찾기 2.6 가져오기백업문제 해결

1. 시작하기

  1. 상단 빠른 등록에 업무 제목을 입력하고 Enter를 누릅니다.
  2. 날짜·기간·반복·알림이 필요하면 업무를 열어 상세 내용을 지정합니다.
  3. 창을 닫을 때 트레이로 숨길지 완전히 종료할지는 설정에서 선택합니다.

Ctrl+Alt+O 전역 단축키는 다른 프로그램을 사용 중일 때도 OfficeFlow 빠른 등록을 엽니다.

2. 업무와 일정

  • 일정 없음: 할 일만 기록할 때 사용합니다.
  • 하루 일정: 시작일만 지정합니다.
  • 기간 일정: 시작일과 종료일을 지정하면 캘린더의 모든 포함 날짜에 표시됩니다.
  • 반복 일정: 매일·매주·매월 규칙과 종료일을 지정할 수 있습니다.
  • 발생별 처리: 반복 일정 한 건을 완료하거나 건너뛰어도 다음 일정은 유지됩니다.

입력 화면에서는 Tab으로 다음 항목, Shift+Tab으로 이전 항목으로 이동할 수 있습니다.

3. 업무가 많을 때 빠르게 찾기

오늘 화면의 요약 카드를 누르면 지연·진행·예정·완료 그룹으로 바로 이동합니다. 검색과 상태·중요도·고정·첨부 필터를 함께 사용할 수 있으며, 보기별 설정은 자동으로 기억됩니다.

목록이 길면 간결 보기를 사용하고, 완료 그룹은 접어 현재 업무에 집중할 수 있습니다.

4. OfficeFlow 2.6 데이터 가져오기

  1. OfficeFlow 2.6을 완전히 종료합니다.
  2. v3의 데이터 → 2.6 데이터 가져오기를 엽니다.
  3. office_tasks.db를 선택합니다. 옆의 saved_files는 자동으로 찾습니다.
  4. 가져오기 전 검사에서 개수와 경고를 확인하고 안전하게 가져오기를 실행합니다.
  5. 완료 후 OfficeFlow를 완전히 종료하고 다시 실행합니다.

원본 DB는 수정하지 않으며 현재 v3 데이터도 유지됩니다. 실행 중이라는 오류가 나오면 2.6을 종료하고 잠시 기다린 뒤 다시 검사하세요.

5. 내보내기와 백업

  • 현재 검색·필터 결과는 Excel로 내보낼 수 있습니다.
  • 여러 날 및 반복 일정은 ICS로 내보내 다른 캘린더에서 열 수 있습니다.
  • .ofbackup은 DB·첨부파일·설정을 함께 보관하고 복원 전에 무결성을 검사합니다.
  • 복원은 다음 실행 전에 적용되며, 적용 직전 현재 데이터도 자동 백업됩니다.

6. 문제 해결

증상확인할 내용
창이 보이지 않음작업 표시줄 알림 영역의 OfficeFlow 아이콘을 두 번 누릅니다.
전역 단축키가 동작하지 않음다른 프로그램이 같은 키를 사용 중인지 확인하고 설정에서 다른 조합을 지정합니다.
첨부파일 누락업무 기록 화면에서 누락 상태를 확인하고 원본 파일을 다시 연결합니다.
복원 후 내용이 바뀌지 않음트레이를 포함해 OfficeFlow를 완전히 종료한 뒤 다시 실행합니다.
2.6 DB를 검사할 수 없음2.6을 종료하고 DB와 같은 위치의 -wal 파일이 사라졌는지 확인합니다.

데이터 위치

기본 사용자 데이터는 %LOCALAPPDATA%\OfficeFlow에 저장됩니다. 프로그램 제거 시 이 폴더는 자동 삭제하지 않습니다.

안전한 재설치

먼저 데이터 화면에서 수동 백업을 만든 뒤 재설치하십시오. 같은 PC의 업그레이드는 기존 데이터 폴더를 그대로 사용합니다.
