OfficeFlow 3.0.3 사용자 안내

업무가 많아도 빠르게 찾고, 하루 일정부터 여러 날·반복 일정까지 한곳에서 관리합니다.

시작하기업무와 일정기록과 첨부 알림검색과 캘린더2.6 가져오기 백업Python 실행문제 해결

1. 시작하기

  1. 상단 빠른 등록에 업무 제목을 입력하고 Enter를 누릅니다.
  2. 날짜·기간·반복·알림이 필요하면 업무를 열어 상세 내용을 지정합니다.
  3. 창을 닫을 때 트레이로 숨길지 완전히 종료할지는 설정에서 선택합니다.

Ctrl+Alt+O 전역 단축키는 다른 프로그램을 사용 중일 때도 OfficeFlow 빠른 등록을 엽니다.

2. 업무와 일정

  • 일정 없음: 할 일만 기록할 때 사용합니다.
  • 하루 일정: 시작일만 지정합니다.
  • 기간 일정: 시작일과 종료일을 지정하면 캘린더의 모든 포함 날짜에 표시됩니다.
  • 반복 일정: 매일·매주·매월 규칙과 종료일을 지정할 수 있습니다.
  • 발생별 처리: 반복 일정 한 건을 완료하거나 건너뛰어도 다음 일정은 유지됩니다.

오늘 화면은 처리 필요, 오늘 할 일, 접힌 완료한 업무로 구분됩니다. 업무 왼쪽의 원을 누르면 바로 완료하며 10초 안에 실행 취소할 수 있습니다. 결과를 함께 남기려면 업무의 ⋯ 또는 오른쪽 버튼 메뉴에서 완료 요약 입력 후 완료를 선택합니다.

업무를 지우면 먼저 휴지통으로 이동해 기록과 첨부파일을 유지합니다. 휴지통에서는 업무를 복원하거나 오른쪽 버튼 메뉴·상세 화면의 영구 삭제로 완전히 지울 수 있습니다. 영구 삭제는 되돌릴 수 없으며 체크리스트·알림·첨부파일과 반복 일정 처리 상태도 함께 삭제됩니다. 업무일지는 날짜별 기록으로 남지만 삭제한 업무와의 연결은 해제됩니다.

새 업무는 시작 날짜·시각과 시작 알림 중심으로 표시합니다. 종료 시각·반복·종료 알림은 추가 설정 보기에서 필요한 경우에만 지정합니다.

입력 화면에서는 Tab으로 다음 항목, Shift+Tab으로 이전 항목으로 이동할 수 있습니다.

3. 기록, 업무일지와 첨부파일

  • 업무 기록에서 체크리스트, 완료 요약, 업무일지와 첨부파일을 관리합니다.
  • 목록과 캘린더의 첨부 표시로 파일 유무를 확인하고, 업무의 오른쪽 버튼 메뉴에서 첨부 목록을 바로 열 수 있습니다.
  • 첨부 화면의 파일 선택 (여러 개)를 누르거나 Windows 탐색기의 파일 여러 개를 첨부 목록으로 끌어놓어 한번에 추가할 수 있습니다. 파일 하나가 중복·오류로 실패해도 나머지 파일은 계속 처리됩니다.
  • 업무에서 첨부 연결을 해제해도 파일은 즉시 삭제하지 않습니다. 데이터 → 첨부 정리에서 원래 업무로 복원하거나 확인 후 영구 삭제합니다.
  • 업무일지는 검색어가 없을 때 선택한 하루를 보여 줍니다.
  • 검색어를 입력하면 기본적으로 전체 기간의 제목·설명·완료 요약·일지 본문·진행 결과를 찾습니다. 필요한 경우 기간 제한 (끄면 전체 기간)을 켜 범위를 지정할 수 있으며 결과 위에 실제 검색 범위가 표시됩니다.

4. 알림과 놓친 알림

알림 창은 완료·대기·확인·다시 알림 중 하나로 처리할 때까지 화면 위에 유지됩니다. 확인은 알림만 처리하며 업무를 완료하지 않습니다. 다시 알림은 기본 10분부터 최대 24시간까지 분 단위로 지정할 수 있습니다. 미룬 뒤에는 업무 목록, 캘린더의 날짜별 목록과 선택 업무 상세에서 ⏰ 재알림 시각을 계속 확인할 수 있습니다.

놓친 알림 확인 범위란?

프로그램이 종료되어 있거나 PC가 절전 상태라 예정 시각에 알림을 표시하지 못했을 때, 다음 실행 또는 복귀 시 얼마나 이전의 미처리 알림까지 다시 보여줄지 정하는 값입니다.

  • 기본값 120분은 현재부터 최근 2시간 안에 놓친 알림만 한 번 다시 표시한다는 뜻입니다.
  • 설정 범위보다 오래된 알림은 프로그램 시작 때 한꺼번에 띄우지 않습니다.
  • 복구된 항목은 알림 창에 놓친 알림으로 표시되며 같은 예정 알림을 중복으로 만들지 않습니다.
  • 다시 알림으로 미룬 항목은 이 범위와 별개로 사용자가 지정한 시각에 다시 울립니다. 다시 울리거나 알림을 처리하면 업무 화면의 재알림 표시가 사라집니다.

설정의 놓친 알림 확인 범위를 지나치게 길게 잡으면 오래된 알림이 늦게 나타날 수 있습니다. 일반적인 사용에는 기본 120분을 권장합니다.

5. 검색, 캘린더와 내보내기

첨부파일 찾기

상단 검색 대상에서 첨부파일을 선택하면 완료·보관 업무를 포함한 전체 기간의 원래 파일명을 찾습니다. 파일명 일부를 2글자 이상 입력하며, 여러 단어는 모두 같은 파일명에 있어야 합니다. 문서 본문·셀·이미지 내용은 검색하지 않습니다.

결과를 더블클릭하거나 선택 후 Enter·파일 열기로 바로 엽니다. 연결 업무는 기록을, 첨부 관리는 선택 파일의 첨부 목록을 엽니다. 검색 및 첨부 관리 중에도 알림을 처리할 수 있습니다.

추가 조건에서 첨부일과 휴지통·정리 대기 포함 여부를 지정합니다. 기본은 휴지통·정리 대기 제외이며 휴지통 업무는 읽기 전용입니다. 결과는 50개씩 조회하고 500개 이후에는 구간을 이동합니다. 표시 개수와 더 있음은 조회 결과이며 전체 개수를 뜻하지 않습니다.

검색 해제는 검색어와 추가 조건을 지웁니다. 돌아가기 버튼은 검색어를 지우고 기존 업무 필터·캘린더 날짜를 유지한 채 원래 보기로 돌아갑니다. 기존 업무·캘린더·업무일지 검색도 파일명을 찾지만 해당 보기의 날짜·필터 범위를 유지합니다.

첫 실행에서는 기존 DB 보호 사본을 data/schema-backups에 만들고 검색 색인을 준비합니다. 첨부 실물·경로는 변경하지 않습니다. 보호 사본은 DB만 포함하며 전체 백업 .ofbackup을 대체하지 않습니다.

오늘 화면의 요약 카드를 누르면 지연·진행·예정·완료 그룹으로 바로 이동합니다. 검색과 상태·중요도·고정·첨부 필터를 함께 사용할 수 있으며, 보기별 설정은 자동으로 기억됩니다. 검색 중에는 검색창과 결과 안내가 파란색으로 강조되며, 결과가 없으면 업무가 삭제된 것이 아니라는 안내와 검색 해제를 표시합니다. 오늘·예정·전체 업무 등 왼쪽 업무 메뉴를 누르면 이전 검색어가 자동으로 지워집니다.

목록이 길면 간결 보기를 사용하고, 완료 그룹은 접어 현재 업무에 집중할 수 있습니다.

캘린더는 일정이 많은 달에 날짜별 개수를 중심으로 표시합니다. 날짜를 누르면 아래 목록에 최소 3개 일정이 보이고, 4개째부터는 아래에 남은 개수와 스크롤바가 표시됩니다. 달력과 목록 사이의 분할선을 드래그하거나 목록 확대를 눌러 더 많은 일정을 한번에 확인할 수 있습니다. 일정 막대나 날짜 목록을 오른쪽 클릭해 기록과 첨부파일을 열 수 있습니다.

ICS 내보내기는 현재 목록, 선택 업무 또는 기간을 지정할 수 있습니다. 기간에 하루라도 겹치는 여러 날 일정이 포함되며 반복 일정은 기본적으로 제외됩니다. 여러 업무는 Ctrl을 누른 채 선택합니다.

6. OfficeFlow 2.6 데이터 가져오기

  1. OfficeFlow 2.6을 완전히 종료합니다.
  2. v3의 데이터 → 2.6 데이터 가져오기를 엽니다.
  3. office_tasks.db를 선택합니다. 옆의 saved_files는 자동으로 찾습니다.
  4. 가져오기 전 검사에서 개수와 경고를 확인하고 안전하게 가져오기를 실행합니다.
  5. 완료 후 OfficeFlow를 완전히 종료하고 다시 실행합니다.

원본 DB는 수정하지 않으며 현재 v3 데이터도 유지됩니다. 실행 중이라는 오류가 나오면 2.6을 종료하고 잠시 기다린 뒤 다시 검사하세요.

7. 데이터 관리와 백업

  • 데이터 → 사용량에서 DB·첨부·백업 크기, 정리 대기 파일과 용량이 큰 첨부파일 상위 5개를 확인합니다.
  • 첨부 저장 폴더 열기로 관리 폴더를 확인할 수 있지만, 탐색기에서 파일을 이동·이름 변경·삭제하면 연결이 깨질 수 있으므로 변경은 OfficeFlow에서 합니다.
  • .ofbackup은 DB·첨부파일·설정을 함께 보관하고 복원 전에 무결성을 검사합니다.
  • 지금 백업은 현재 상태를 수동 백업으로 만들며 자동 백업 일정에는 영향을 주지 않습니다.
  • 최근 자동 백업, 다음 백업 기준 시각, 수동·자동 백업 개수와 전체 용량을 데이터 화면에서 확인할 수 있습니다.
  • PC가 자동 백업 기준 시각에 꺼져 있으면 다음 OfficeFlow 실행 후 백업합니다. 자동 백업은 설정한 개수만 보관합니다.
  • 수동 백업은 자동 삭제하지 않습니다. 오래된 수동 백업 정리에서 남길 개수와 삭제 용량을 확인한 뒤 정리합니다.
  • 복원은 다음 실행 전에 적용되며, 적용 직전 현재 데이터도 보호용 백업으로 남깁니다.

8. Python 실행 모드

회사 보안 정책이 서명되지 않은 실행 파일을 제한하지만 Python 실행은 허용하는 경우 OfficeFlow-Python-3.0.3.zip을 별도 폴더에 압축 해제해 사용할 수 있습니다.

  1. Python 3.12 64비트를 설치합니다. 다른 Python 버전이 함께 있어도 괜찮습니다.
  2. 최초 한 번 setup-officeflow-python.cmd를 실행해 전용 .venv와 라이브러리를 준비합니다.
  3. 이후에는 run-officeflow-python.cmd로 실행합니다.
  4. 실행에 문제가 있으면 diagnose-officeflow-python.cmd로 환경을 점검합니다.

Python 실행 모드도 설치형과 동일한 %LOCALAPPDATA%\OfficeFlow의 DB·첨부·설정을 사용합니다. 설치형과 Python형을 동시에 실행하지 말고 전환 전에는 트레이에서 완전히 종료하십시오.

Python 배포 폴더를 옮겼다면 설정 스크립트를 다시 실행하고 Windows 자동 시작 설정을 껐다가 켜십시오.

9. 문제 해결

증상확인할 내용
창이 보이지 않음작업 표시줄 알림 영역의 OfficeFlow 아이콘을 두 번 누릅니다.
전역 단축키가 동작하지 않음다른 프로그램이 같은 키를 사용 중인지 확인하고 설정에서 다른 조합을 지정합니다.
첨부파일 누락업무 기록 화면에서 누락 상태를 확인하고 원본 파일을 다시 연결합니다.
알림을 놓침설정의 놓친 알림 확인 범위와 Windows 자동 실행 여부를 확인합니다. 범위보다 오래된 알림은 자동으로 다시 띄우지 않습니다.
복원 후 내용이 바뀌지 않음트레이를 포함해 OfficeFlow를 완전히 종료한 뒤 다시 실행합니다.
2.6 DB를 검사할 수 없음2.6을 종료하고 DB와 같은 위치의 -wal 파일이 사라졌는지 확인합니다.
설치형이 보안 프로그램에 의해 종료됨조직 정책을 확인하고, Python 실행이 허용된 PC에서는 Python 3.12 실행 모드를 사용합니다.

데이터 위치

기본 사용자 데이터는 %LOCALAPPDATA%\OfficeFlow에 저장됩니다. 프로그램 제거 시 이 폴더는 자동 삭제하지 않습니다.

안전한 재설치

먼저 데이터 화면에서 수동 백업을 만든 뒤 재설치하십시오. 같은 PC의 업그레이드는 기존 데이터 폴더를 그대로 사용합니다.
