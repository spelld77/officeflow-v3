OfficeFlow 3.0.8 사용자 안내

업무가 많아도 빠르게 찾고, 하루 일정부터 여러 날·반복 일정까지 한곳에서 관리합니다.

시작하기업무와 일정기록과 첨부 이력·중요 보관알림검색과 캘린더 백업Python 실행문제 해결

1. 시작하기

  1. 상단 빠른 등록에 업무 제목을 입력하고 Enter를 누릅니다.
  2. 날짜·기간·반복·알림이 필요하면 업무를 열어 상세 내용을 지정합니다.
  3. 창을 닫을 때 트레이로 숨길지 완전히 종료할지는 설정에서 선택합니다.

Ctrl+Alt+O 전역 단축키는 다른 프로그램을 사용 중일 때도 OfficeFlow 빠른 등록을 엽니다.

2. 업무와 일정

  • 일정 없음: 할 일만 기록할 때 사용합니다.
  • 하루 일정: 시작일만 지정합니다.
  • 기간 일정: 시작일과 종료일을 지정하면 캘린더의 모든 포함 날짜에 표시됩니다.
  • 반복 일정: 매일·매주·매월 규칙과 종료일을 지정할 수 있습니다.
  • 발생별 처리: 반복 일정 한 건을 완료하거나 건너뛰어도 다음 일정은 유지됩니다.

오늘 화면은 처리 필요, 오늘 할 일, 접힌 완료한 업무로 구분됩니다. 업무 왼쪽의 원을 누르면 바로 완료하며 10초 안에 실행 취소할 수 있습니다. 결과를 함께 남기려면 업무의 ⋯ 또는 오른쪽 버튼 메뉴에서 완료 요약 입력 후 완료를 선택합니다.

날짜·시간 변경과 절전·트레이 복귀 때 업무 목록을 자동 갱신합니다. 검색어, 필터, 접힌 그룹, 더 보기로 읽은 목록, 선택과 스크롤 위치는 유지하고 캘린더의 선택 날짜와 달도 바꾸지 않습니다.

업무를 지우면 먼저 휴지통으로 이동해 기록과 첨부파일을 유지합니다. 휴지통에서는 업무를 복원하거나 오른쪽 버튼 메뉴·상세 화면의 영구 삭제로 완전히 지울 수 있습니다. 영구 삭제는 되돌릴 수 없으며 체크리스트·알림·첨부파일과 반복 일정 처리 상태도 함께 삭제됩니다. 업무일지는 날짜별 기록으로 남지만 삭제한 업무와의 연결은 해제됩니다.

새 업무는 시작 날짜·시각과 시작 시각 알림 하나가 기본입니다. 종료·반복은 추가 설정 보기, 여러 알림은 알림 → 설정…에서 지정합니다. 날짜 입력칸 안의 요일은 자동 계산되며 Tab 이동에 끼어들지 않습니다.

입력 화면에서는 Tab으로 다음 항목, Shift+Tab으로 이전 항목으로 이동할 수 있습니다.

3. 기록, 업무일지와 첨부파일

  • 업무 기록에서 체크리스트, 완료 요약, 업무일지와 첨부파일을 관리합니다.
  • 목록·캘린더·파일 검색·업무일지의 기록과 첨부 창을 열어 둔 채 업무 알림과 매시 알림을 처리할 수 있습니다. 업무일지 창을 닫으면 그 안에서 연 기록 창도 닫히며, 첨부 복사 중이면 안전하게 취소하고 마무리합니다.
  • 목록과 캘린더의 첨부 표시로 파일 유무를 확인하고, 업무의 오른쪽 버튼 메뉴에서 첨부 목록을 바로 열 수 있습니다.
  • 첨부 화면의 파일 선택 (여러 개)를 누르거나 Windows 탐색기의 파일 여러 개를 첨부 목록으로 끌어놓어 한번에 추가할 수 있습니다. 파일 하나가 중복·오류로 실패해도 나머지 파일은 계속 처리됩니다.
  • 첨부 목록은 일반 / 원본 / 작업본, 파일명, 짧은 상태를 한 줄로 표시합니다. 위에 파일 수가 표시되고 세로 스크롤로 나머지를 볼 수 있습니다. 긴 이름은 가운데를 생략하며 전체 이름·메모·최초 정보는 파일을 선택한 뒤 정보에서 확인합니다. 보관함에서 보관본을 조회하고 현재 첨부와 함께 여러 파일을 저장할 수 있습니다.
  • 파일 하나를 선택하고 오른쪽 클릭 또는 더보기 → 이름 변경… / 메모…를 사용합니다. 이름 변경은 목록·검색·외부 저장 기본 이름에 적용되며, 확장자와 실제 관리 파일 경로·처음 첨부한 이름은 유지합니다. 메모는 최대 2,000자의 선택 입력으로 파일 내용·업무일지와 별개입니다. 휴지통·정리 대기 파일은 복원한 뒤 변경합니다. 저장 오류가 나면 입력을 남겨두며 다른 창과 변경이 겹치면 덮어쓰지 않습니다.
  • 업무에서 첨부 연결을 해제해도 파일은 즉시 삭제하지 않습니다. 데이터 → 첨부 정리에서 원래 업무로 복원하거나 확인 후 영구 삭제합니다.
  • 첨부파일을 선택하고 위로 / 아래로로 순서를 조정합니다. 오른쪽 클릭의 맨 위로 / 맨 아래로로 끝까지 이동할 수 있으며 순서는 즉시 저장됩니다. 새 파일은 맨 아래에 추가되고 파일 복사·검사 중이나 휴지통 업무에서는 이동할 수 없습니다.
  • 첨부와 순서는 반복 업무의 모든 회차에서 공유합니다. 다른 기록 창의 첨부 목록도 갱신되며 입력 중인 결과·업무일지는 유지됩니다. 전체 첨부 검색의 첨부일순은 바뀌지 않습니다. 연결 해제·복원은 순서값을 보존하지만 그동안 재배열했다면 원래 이웃까지 같아지지는 않습니다.
  • 파일 하나는 오른쪽 클릭의 다른 이름으로 저장…에서 이름과 위치를 선택합니다. Ctrl/Shift로 같은 업무의 여러 파일을 선택하면 선택 N개 저장…으로 폴더에 한번에 저장합니다. 동명 파일은 번호를 붙여 보존하고 단일 덮어쓰기는 확인받습니다. 문서는 자동으로 열지 않습니다.
  • 외부 저장은 독립 사본이며 내부 첨부는 그대로 남습니다. 문서 편집기에서 저장한 내용만 포함하고 미저장 내용은 포함하지 않습니다. 파일 형식을 변환하지 않으며 원래 확장자를 유지합니다. 마지막 성공한 저장 폴더를 다음 기본 위치로 사용합니다.
  • 첨부 탭에 돌아오면 보이는 파일의 크기·수정 시각을 빠르게 확인합니다. 더보기 → 파일 정보 확인에서 전체 내용을 검사합니다. 확인 결과는 별도 첨부파일 정보 창에서 닫기 전까지 유지되며 목록 갱신이나 다른 파일 선택으로 지워지지 않습니다. 최초 정보와 최근 관측을 구분하고 첨부 후 수정됨은 정상 편집일 수 있으므로 손상 판정으로 보지 않습니다. 과거 기준이 없으면 확인 후에도 최초 기준 없음으로 표시합니다.
  • 파일을 열면 필요한 준비·검증 진행만 표시하고 연결 프로그램으로 전달한 뒤 진행 창은 자동으로 닫힙니다. 매번 완료 버튼을 누를 필요가 없습니다. 파일 읽기·연결 프로그램 실행 실패 안내는 자동으로 지우지 않으며, 원본·보관본의 보호 정책은 유지합니다.
  • 저장 결과의 미처리 재시도는 실패/미처리만 새 작업으로 저장하고 그때의 최신 내용을 복사합니다. 잠금 실패 시 문서를 저장하고 닫은 뒤 다시 시도하세요. 내부 관리 폴더나 출처와 같은 파일에는 저장하지 않습니다.
  • 데이터 → 첨부 정리에서도 해제/연결 없는 파일을 열거나 외부에 저장할 수 있습니다. 내부 삭제와는 별도 행동이며 사용 중인 파일 삭제는 보류합니다. 일반 첨부와 작업본은 관리 파일을 편집하고, 원본과 보관본은 검증된 보기 사본으로 엽니다.
  • 강제 종료 뒤에는 데이터 → 첨부 정리 → 중단된 저장 확인에서 정확한 자료 위치를 확인합니다. 이미 저장된 출력은 다시 만들지 않고 최종 출력 파일을 삭제하지 않습니다. 복구/준비 파일 정리는 사용자 확인 후 검증 가능한 자료에만 적용합니다. 이후 수정된 자료와 미분류 자료는 보존합니다.
  • 업무일지는 검색어가 없을 때 선택한 하루를 보여 줍니다.
  • 반복 업무의 완료 결과는 회차별로 검색하고 해당 회차의 완료 요약·업무일지만 함께 보여 줍니다. 별도 일지가 없는 완료 건도 찾으며, 늦게 처리한 업무는 실제 완료일을 기준으로 표시합니다. 반복 회차의 완료 요약은 내용의 부분 일치도 지원합니다.
  • 검색어를 입력하면 기본적으로 전체 기간의 제목·설명·완료 요약·일지 본문·진행 결과를 찾습니다. 필요한 경우 기간 제한 (끄면 전체 기간)을 켜 범위를 지정할 수 있으며 결과 위에 실제 검색 범위가 표시됩니다.

업무 변경 이력과 중요 시점 보관

업무·캘린더의 오른쪽 메뉴 또는 업무 기록 창 하단의 이력·보관을 누릅니다. 평소 업무 목록에 이력을 펼치지 않으며, 창을 열어 둔 채 업무·알림을 처리할 수 있습니다.

  • 자동 이력: 제목·설명·일정·중요도·상태·결과메모의 실제 저장된 변경을 기록합니다. 같은 내용 저장, 취소·실패, 알림 확인·다시 알림은 변경 이력으로 만들지 않습니다. 완료 후 실행 취소는 별도 상태 변경입니다.
  • 기존 업무의 첫 변경부터 이력 기록 시작과 변경 내용을 남깁니다. 도입 이전의 과거 변경은 재구성하지 않습니다. 공통 변경과 원래 반복 회차별 처리를 구분하며 회차를 이동해도 같은 회차의 이력을 찾을 수 있습니다.
  • 현재 상태 보관…: 팀장 검토 전, 최종 제출 자료처럼 자유롭게 이름을 붙여 당시 저장된 업무 정보·결과메모·체크리스트와 선택 파일을 남깁니다. 파일 없이 업무 정보만 보관할 수도 있습니다. 파일 왼쪽의 파란 테두리 체크박스를 누르면 ✓가 표시되고 버튼이 선택 N개와 함께 보관으로 바뀝니다. 단순히 파일 행을 강조 선택하는 것과 보관할 파일의 체크는 다릅니다. 현재 첨부·개별 보관본을 페이지를 바꿔 최대 100개까지 체크합니다.
  • 파일을 선택했다면 먼저 문서를 저장하고 닫은 뒤 확인란을 체크합니다. 미저장 초안·편집기 내용은 자동 저장하지 않습니다. 보관 중 대상 내용이 바뀌거나 파일 하나라도 누락·잠금·검증 오류가 있으면 전체 보관을 성공으로 표시하지 않습니다.
  • 이력과 중요 보관을 한 줄 목록으로 50건씩 조회합니다. 범위·종류·변경 항목·기간으로 좁힐 수 있습니다. 상세는 별도 읽기 전용 창이므로 목록 높이가 줄어들지 않습니다.
  • 비교에 추가 → 선택 2시점 비교로 두 기록을 비교합니다. 선택은 페이지 이동에도 남습니다. 업무 공통끼리 또는 같은 원래 회차끼리 비교하며, 현재와 비교는 현재 조회 시각의 업무 정보 6항목만 비교합니다.
  • 문장의 실제 문구를 그대로 비교합니다. 매우 긴 글은 변경 강조를 생략해도 전체 원문을 유지합니다. 중요 보관끼리는 체크리스트·파일 정보도 볼 수 있지만 HWP·Excel 내부 내용의 의미를 비교하지 않습니다. 과거 상태·알림을 통째로 되돌리는 기능은 아닙니다.
  • 중요 보관의 보기 / 선택 저장… / 새 작업본…으로 당시 파일을 활용합니다. 현재 출처 첨부를 지워도 보관 파일은 남습니다. 파일 하나씩이 아니라 이 보관 삭제…로 묶음 전체를 확인 후 삭제하며 다른 참조가 쓰는 파일은 유지합니다.

휴지통에서는 이력·보관 조회와 외부 저장만 가능합니다. 새 보관·작업본 생성·보관 삭제는 업무 복원 후 합니다. 업무 영구 삭제에는 자동 이력·중요 보관·선택 파일도 포함되므로 확인창의 별도 범위를 확인하세요. 전체 백업은 이력·보관과 참조 파일을 함께 보존합니다.

중단된 중요 보관은 이력·보관 → 중단된 보관에서 확인합니다. 확정 여부를 검사하고 미확정 준비 파일은 명시적인 확인 후 안전하게 검증된 것만 정리합니다. 변경·손상·정체 불명 자료는 보존하며 자동으로 새 보관을 만들지 않습니다.

4. 알림과 놓친 알림

매시 알림 (3.0.4부터)

실제로 새로 실행할 때마다 자동으로 켜지며 기본 매시 35분에 안내합니다. 대상 시간에 시작하면 현재 구간을 바로 안내합니다. 인사랑의 출근·업무기록은 직접 해야 하며, 이 기능은 기록을 만들거나 근무 인정을 확인하지 않습니다.

  • 평일 09:00~18:00은 제외하고 주말은 하루 전체입니다. 평일 공휴일 출근에는 트레이의 오늘 휴일근무를 선택합니다. 해당 날짜에만 기억합니다.
  • 평일 08시 이후 첫 실행에는 아침 안내가 없습니다. 08시 전부터 또는 전날부터 ON이 이어지면 08시까지 자동 연속 안내합니다. 오늘 09시에 만료합니다. 실제 조기출근·기록 후 앱만 늦게 켰다면 08시 구간의 오늘 08시 알림 받기를 선택합니다.
  • 닫기·X·Escape는 현재 구간 안내만 끝내고 다음 시간 알림은 유지합니다. 미리 기록했다면 트레이에서 이번 시간 건너뛰기를 선택할 수 있습니다.
  • 5분 뒤 알림은 같은 구간의 허용 시간에만 가능하고 다음 정기 시각은 유지합니다. 19:55 이후에는 20시로 미루지 않습니다.
  • 이번 실행 동안 끄기는 다음 실제 실행에 기억하지 않습니다. 기존 업무 알림도 끄지 않습니다.
  • 트레이의 매시 알림 또는 설정 → 매시 알림 설정...에서 문구·분·평일 제외 시간과 추가 제외 시간(모든 요일, 최대 8개)·소리를 변경합니다. 제외된 정기 시각은 임의의 다른 분으로 옮기지 않습니다.
  • 추가 설정의 늦게 켜도 08시 알림 받기는 기본 꺼짐입니다. 켜면 평일 08:00~08:59에 처음 켜도 안내합니다. 08시 전부터 켜두었다면 이 옵션 없이도 자동으로 이어집니다.
  • 업무 화면 하단은 다음 20:35처럼 짧게 표시하며 상세 상태는 마우스를 올리거나 메뉴를 열면 볼 수 있습니다.
  • 절전 복귀 시 지난 시간들을 몰아서 띄우지 않고 현재 구간만 안내합니다. 열린 단일 창은 다음 허용 구간으로 갱신합니다.

트레이로 숨겼다 다시 여는 것은 재실행이 아닙니다. PC·프로그램 종료 또는 강제 종료 중에는 알릴 수 없습니다. Windows 보안 화면·독점 전체화면·일부 네이티브 창에서 위 표시와 정확한 발화는 보장하지 않습니다.

업무에 연결된 알림

한 업무에 최대 20개 알림 규칙을 설정합니다. 날짜·시각 직접 지정은 일정이 없어도 가능한 1회 예약이며, 시작·종료 기준은 일정과 함께 이동하고 반복 업무의 회차마다 적용됩니다. 지난·사용 안 함 규칙도 개수에 포함되므로 설정 개수와 남은 울림 횟수는 다릅니다.

시작·종료 기준은 20일 전 같은 빠른 선택 또는 일·시간·분과 전/후로 입력합니다. 계산된 알림 날짜·요일·시각을 확인한 뒤 적용하세요.

업무 등록창의 알림 설정 적용은 임시 초안이고 업무의 저장이 최종 저장입니다. 취소하면 해당 단계의 변경을 버립니다. 목록·달력 오른쪽 메뉴나 선택 상세의 알림 설정…에서는 알림만 바로 저장합니다. 여러 입력·설정 창을 열어 둬도 알림을 처리할 수 있습니다.

오늘 화면의 오늘 알림은 업무 검색·필터와 독립적으로 다음 달 업무·일정 없는 업무의 오늘 예약도 보여 줍니다. 낮은 창에서는 2행, 일반 창에서는 3행과 남은 건수를 표시하고 전체 보기로 나머지를 확인합니다. 달력에는 날짜별 알림 N과 하단의 [알림] 행을 표시하며 같은 업무를 복제하지 않습니다. 시각·제목·상태를 분리하고 원래 업무 일정은 선택 상세·툴팁에서 확인합니다.

날짜별 알림은 예정·미확인·재알림·확인함·완료와 다른 날로 이동한 상태를 구분합니다. 조회만으로 알림을 발생·확인하지 않으며, 과거는 저장된 실제 이력을 보여 줍니다. 대량 자료의 조회가 예산을 넘으면 일부 조회 / 더 조회로 안내합니다. 규칙 삭제 시 발생 이력도 제거되므로 이 화면은 영구 업무일지를 대체하지 않습니다.

오늘/달력은 유효한 알림 수와 처리 이력을 구분합니다. 발생 기록 확인 필요는 실제로 울렸다는 뜻이 아닙니다. 다른 날로 미룬 경우 새 날짜에만 유효 수로 셉니다. 업무 완료 후 기존 확인 이력은 업무 완료 · 알림 확인함으로 유지하고 미래 예약은 중단합니다.

열린 편집창은 실제 실행 상태를 갱신하되 작성 중인 제목·설명·일정·알림 초안을 지우지 않습니다. 미저장 설정 미리보기는 실제 예약과 구분하고 최종 저장 시 충돌 검사도 유지합니다.

기본 버튼 이번 알림 확인은 이번 알림만 닫고 업무 상태와 다음 예약을 유지합니다. 다시 알림은 선택한 알림 하나만 미룹니다. 별도의 업무 완료…는 업무 자체를 완료하고 남은 알림·재알림을 모두 중단하므로 확인창을 띄우며, 기본 선택은 취소입니다. 반복 업무의 이번 회차 완료…는 해당 회차만 중단하고 다음 회차를 유지합니다. 회차가 없는 직접 지정 알림의 업무 전체 완료…는 이후 반복도 모두 중단합니다.

알림 창은 처리할 때까지 화면 위에 유지됩니다. Enter의 기본 동작은 이번 알림 확인입니다. 업무 대기로는 업무를 보류하지만 다음 예약은 끄지 않습니다. 다시 알림은 기본 10분부터 최대 24시간까지 분 단위로 지정할 수 있습니다. 미룬 뒤에는 업무 목록, 캘린더의 날짜별 목록과 선택 업무 상세에서 ⏰ 재알림 시각을 계속 확인할 수 있습니다.

놓친 알림 확인 범위란?

프로그램이 종료되어 있거나 PC가 절전 상태라 예정 시각에 알림을 표시하지 못했을 때, 다음 실행 또는 복귀 시 얼마나 이전의 미처리 알림까지 다시 보여줄지 정하는 값입니다.

  • 기본값 120분은 현재부터 최근 2시간 안에 놓친 알림만 한 번 다시 표시한다는 뜻입니다.
  • 설정 범위보다 오래된 알림은 프로그램 시작 때 한꺼번에 띄우지 않습니다.
  • 알림창이 떴지만 처리하지 않은 채 정상 종료하거나 강제 종료되어도, 다음 실행 때 이 범위 안이면 다시 보여줍니다. 다시 알림이 실제로 울린 뒤 종료했다면 마지막으로 울린 시각이 기준입니다.
  • 이미 확인·완료·대기로 처리한 알림, 완료·취소·보관·휴지통 업무, 꺼 둔 알림과 처리된 반복 발생 건은 복구에서 제외합니다. 복구한 알림은 실행 중에 반복해서 뜨지 않습니다.
  • 복구된 항목은 알림 창에 놓친 알림으로 표시되며 같은 예정 알림을 중복으로 만들지 않습니다.
  • 다시 알림으로 미룬 항목은 이 범위와 별개로 사용자가 지정한 시각에 다시 울립니다. 다시 울리거나 알림을 처리하면 업무 화면의 재알림 표시가 사라집니다.

설정의 놓친 알림 확인 범위를 지나치게 길게 잡으면 오래된 알림이 늦게 나타날 수 있습니다. 일반적인 사용에는 기본 120분을 권장합니다.

5. 검색, 캘린더와 내보내기

첨부파일 찾기

상단 검색 대상에서 첨부파일을 선택하면 완료·보관 업무를 포함한 전체 기간의 현재 표시 이름을 찾습니다. 파일명 일부를 2글자 이상 입력하며, 여러 단어는 모두 같은 파일명에 있어야 합니다. 문서 본문·셀·이미지 내용과 첨부 메모는 검색하지 않습니다.

결과를 더블클릭하거나 선택 후 Enter·파일 열기로 바로 엽니다. 연결 업무는 기록을, 첨부 관리는 선택 파일의 첨부 목록을 엽니다. 검색 및 첨부 관리 중에도 알림을 처리할 수 있습니다.

추가 조건에서 첨부일과 휴지통·정리 대기 포함 여부를 지정합니다. 기본은 휴지통·정리 대기 제외이며 휴지통 업무는 읽기 전용입니다. 결과는 50개씩 조회하고 500개 이후에는 구간을 이동합니다. 표시 개수와 더 있음은 조회 결과이며 전체 개수를 뜻하지 않습니다.

검색 해제는 검색어와 추가 조건을 지웁니다. 돌아가기 버튼은 검색어를 지우고 기존 업무 필터·캘린더 날짜를 유지한 채 원래 보기로 돌아갑니다. 기존 업무·캘린더·업무일지 검색도 파일명을 찾지만 해당 보기의 날짜·필터 범위를 유지합니다.

첫 실행에서는 기존 DB 보호 사본을 data/schema-backups에 만들고 검색 색인을 준비합니다. 첨부 실물·경로는 변경하지 않습니다. 보호 사본은 DB만 포함하며 전체 백업 .ofbackup을 대체하지 않습니다.

오늘 화면의 요약 카드를 누르면 지연·진행·예정·완료 그룹으로 바로 이동합니다. 검색과 상태·중요도·고정·첨부 필터를 함께 사용할 수 있으며, 보기별 설정은 자동으로 기억됩니다. 검색 중에는 검색창과 결과 안내가 파란색으로 강조되며, 결과가 없으면 업무가 삭제된 것이 아니라는 안내와 검색 해제를 표시합니다. 오늘·예정·전체 업무 등 왼쪽 업무 메뉴를 누르면 이전 검색어가 자동으로 지워집니다.

목록이 길면 간결 보기를 사용하고, 완료 그룹은 접어 현재 업무에 집중할 수 있습니다.

캘린더는 일정이 많은 달에 날짜별 개수를 중심으로 표시합니다. 날짜를 누르면 아래 목록에 최소 3개 일정이 보이고, 4개째부터는 아래에 남은 개수와 스크롤바가 표시됩니다. 달력과 목록 사이의 분할선을 드래그하거나 목록 확대를 눌러 더 많은 일정을 한번에 확인할 수 있습니다. 일정 막대나 날짜 목록을 오른쪽 클릭해 기록과 첨부파일을 열 수 있습니다.

일정을 한 번 클릭하면 선택되고, 더블클릭·선택 후 Enter·기록으로 해당 업무의 기록 창을 엽니다. 처음에는 체크리스트, 이후에는 이번 실행의 최근 탭을 보여줍니다. 첨부는 등록 파일 목록을 바로 열며, 파일 선택창은 추가 버튼을 누를 때만 열립니다. 파일이 없다면 목록에서 추가할 수 있습니다.

일정 수정은 ⋯/오른쪽 클릭 → 업무 수정으로 합니다. 메뉴에서 체크리스트·업무일지·첨부로 직접 이동하거나 완료할 수도 있습니다. 같은 업무·같은 반복 회차의 기록 창을 재사용해 미저장 입력을 유지하며 다른 회차는 별도로 엽니다. 빈 날짜 더블클릭은 새 일정 등록입니다.

ICS 내보내기는 현재 목록, 선택 업무 또는 기간을 지정할 수 있습니다. 기간에 하루라도 겹치는 여러 날 일정이 포함되며 반복 일정은 기본적으로 제외됩니다. 여러 업무는 Ctrl을 누른 채 선택합니다.

완료 업무를 포함하면 일정 설명에 업무 상태: 완료와 완료 요약을 남깁니다. 일정 자체의 상태는 캘린더 표준에 맞는 CONFIRMED이며, 외부 캘린더의 완료 체크와 자동 연결되지는 않습니다.

Excel 내보내기는 업무를 나누어 읽고 순서대로 작성하며 진행창에 작성 개수를 표시합니다. 작업 중 수정한 내용은 내보내는 파일에 섞이지 않습니다. 취소·오류 시 기존 파일은 덮어쓰지 않습니다.

6. 데이터 관리와 백업

  • 데이터 → 사용량에서 DB·첨부·백업 크기, 정리 대기 파일과 용량이 큰 첨부파일 상위 5개를 확인합니다.
  • 첨부 저장 폴더 열기로 관리 폴더를 확인할 수 있지만, 탐색기에서 파일을 이동·이름 변경·삭제하면 연결이 깨질 수 있으므로 변경은 OfficeFlow에서 합니다.
  • .ofbackup은 DB·첨부파일·설정을 함께 보관하고 복원 전에 무결성을 검사합니다.
  • 지금 백업은 현재 상태를 수동 백업으로 만들며 자동 백업 일정에는 영향을 주지 않습니다.
  • 최근 자동 백업, 다음 백업 기준 시각, 수동·자동 백업 개수와 전체 용량을 데이터 화면에서 확인할 수 있습니다.
  • PC가 자동 백업 기준 시각에 꺼져 있으면 다음 OfficeFlow 실행 후 백업합니다. 자동 백업은 설정한 개수만 보관합니다.
  • 수동 백업은 자동 삭제하지 않습니다. 오래된 수동 백업 정리에서 남길 개수와 삭제 용량을 확인한 뒤 정리합니다.
  • 복원은 다음 실행 전에 적용되며, 적용 직전 현재 데이터도 보호용 백업으로 남깁니다.

백업은 DB와 독립 첨부 사본을 확보한 뒤 압축합니다. 필요한 파일이 누락되거나 안정적으로 읽을 수 없으면 새 전체 백업을 성공으로 표시하지 않습니다. 3.0.8의 새 형식 v3는 파일 자산·참조와 내용을 함께 확인하며 3.0.8 이상에서 복원해야 합니다. 이전 형식 v1/v2도 읽으며 과거 백업의 누락 경고는 유지합니다.

원본·작업본·보관본: 첨부 한 개를 선택해 오른쪽 클릭/더보기에서 원본으로 지정, 새 작업본, 보관본 남기기를 사용합니다. 먼저 편집기를 저장하고 닫아 주세요. 원본 지정은 지금 저장된 내용을 고정하며 이전 편집 파일도 해제 목록에 보존합니다. 작업본은 별도 내부 편집 파일이며 자동으로 열지 않습니다. 보관본은 중요한 시점에 수동으로 남기는 고정 파일입니다. 이름은 검토 v2, 결재 전처럼 자유롭게 정하고 선택 메모를 붙일 수 있습니다. 파일 메모는 업무 설명·완료 요약·업무일지와 별개입니다.

원본 지정 해제: 현재 원본 한 개를 선택하고 오른쪽 클릭/더보기에서 원본 지정 해제…를 확인하면 같은 항목이 편집 가능한 일반 첨부가 됩니다. 이름·메모·순서·기존 작업본 연결은 유지합니다. 해제 전 원본의 고정 내용은 보관함에 원본 해제 전 내용으로 남습니다. 보기 사본에서 수정한 내용은 자동으로 반영하거나 삭제하지 않으며 필요하면 별도로 작업본에 보존합니다.

보관함에서 현재 첨부와 보관본을 체크해 함께 외부 저장할 수 있습니다. 페이지/종류를 바꿔도 체크를 유지하며 현재 페이지 전체 체크는 보이지 않는 다른 페이지를 선택하지 않습니다. 현재 첨부는 페이지당 100개, 보관본은 50개까지 표시합니다. 추가 페이지가 있을 때만 이전 페이지 / 다음 페이지를 표시하며 마지막 페이지에서는 다음으로 이동하지 않습니다. 원래 작업본을 삭제해도 보관본은 남고, 이전 보관본에서 새 작업본을 만들 수 있습니다. 보관본의 외부 기본 이름에는 보관 이름을 붙입니다. 외부 저장 파일은 OfficeFlow 내부 파일과 독립적입니다.

여러 파일 삭제: Ctrl/Shift로 파일을 여러 개 선택한 뒤 첨부 목록의 오른쪽 클릭/더보기에서 선택 N개 삭제…, 보관함에서 선택 항목 삭제…를 누릅니다. 한 번의 확인창에서 파일명과 삭제/유지 범위를 확인하고 삭제합니다. 보관함에서는 현재 페이지에서 강조 선택한 항목만 삭제하며, 외부 저장용 체크는 삭제에 포함하지 않습니다. 선택하지 않은 보관본과 외부 사본/기존 백업은 남습니다. 파일 하나라도 사용 중이거나 확인 후 대상이 바뀌면 전체 삭제를 보류합니다. 읽기 전용/휴지통 업무의 첨부는 이 화면에서 삭제할 수 없습니다.

보기 사본: 원본/보관본 자체는 편집기에 전달하지 않습니다. 수정 없는 임시 사본은 다시 열 때 재사용합니다. 사본에서 저장한 변경은 원본에 반영되지 않습니다. 변경이 확인되면 첨부 목록에 수정본 있음과 수정본 저장… 버튼이 표시됩니다. 오른쪽 메뉴/더보기의 수정본 확인/저장…, 데이터 → 첨부 정리 → 보기 사본에서도 확인합니다. 편집기에서 저장하고 문서를 닫은 뒤 수정본 저장… → 이름 입력 → 문서를 닫았음 체크 → 저장하면 새 작업본으로 남습니다. 내용 확인 후에도 선택이 유지됩니다. 원본은 그대로 유지되며 다시 원본을 열면 수정 전 원본 내용이 보입니다. 작업을 이어가려면 새 작업본을 엽니다. 필요 없는 변경은 편집기에서 문서 닫기 → 변경 버리기/정리 → 확인창에서 문서를 닫았음 체크 → 선택한 사본만 삭제로 버립니다. 별도의 닫음 확인 버튼을 먼저 누를 필요가 없습니다. 확인창을 연 뒤 사본을 다시 열거나 수정했으면 삭제하지 않습니다. 문서를 닫은 뒤 확인창을 새로 열어 재시도하세요.

보기 사본은 백업 대상이 아닙니다. 변경된 내용이 중요하면 먼저 작업본 또는 외부 파일로 보존하세요. 마지막 사용 후 7일이 지났어도 닫음 확인·미수정·독점 파일 확인이 모두 통과해야 자동 정리합니다. 수정본·종료 미확인·이전 복원 사본·편집기 임시 파일은 자동 삭제하지 않습니다. 미수정 사본 생성 상한은 100개/512MiB이며 사본이 없는 경우 단일 큰 파일을 허용합니다. 같은 원본의 보호 사본이 2개면 추가 열람을 제한하여 정리를 안내합니다. 프로그램은 편집기의 미저장 내용과 실제 문서 종료를 자동으로 알 수 없습니다.

중단된 생성·삭제 작업은 데이터 → 첨부 정리 → 중단된 내부 작업에서 확인합니다. 확정된 작업만 백그라운드에서 마무리하고, 미확정 생성은 같은 명령을 사용자가 재검증하여 재시도할 수 있습니다. 미확정·손상·소유 불명 자료는 자동 등록하거나 지우지 않습니다. 전체 백업은 정식 자산과 별도 recovery 영역을 구분해 보존합니다. 복원된 복구 자료는 데이터 루트/recovery/복원 ID에 남고 자동 등록·명령 재실행되지 않습니다. 관리 폴더의 작업 기록·준비 파일을 탐색기에서 임의 삭제하지 마세요.

정상 백업을 복원할 때 현재 파일의 누락/고정 불일치로 복원 전 전체 백업을 만들 수 없으면, 검증한 백업으로 교체하되 이전 DB·첨부·설정을 backups/pre-restore-preserved-…에 별도로 보존하고 위치를 알립니다. 이 폴더는 정상 전체 백업이 아니며 자동 삭제하지 않습니다. 다른 오류를 무조건 우회해서 복원하는 기능은 아닙니다.

영구 삭제 확인창에 연결·보관본·업무 이력·중요 보관과 실제 삭제/유지 파일 개수를 표시합니다. 업무 전체 삭제에서 보관자료가 있으면 전체 보관자료 포함 범위를 별도로 확인합니다. 보관자료를 남기려면 업무 영구 삭제를 취소하고 휴지통에 보존하세요. 삭제 도중 종료되면 DB 확정 전에는 격리한 파일을 복구하고, 확정 후에는 참조 없는 실제 파일만 정리합니다. 경로 충돌·잠금·저널 불명은 자료를 보존합니다. 외부 사본과 기존 백업은 내부 삭제로 없어지지 않습니다. .trash/delete-…의 기록과 파일을 임의로 지우지 마세요.

3.0.8은 자산 원장 0013 → 변경 이력 0014 → 중요 보관 0015 순서로 이행합니다. 기존 파일 ID·실제 경로·내용은 유지하고 이행 전 DB 보호 사본을 남깁니다. 기존 첨부는 일반 첨부로 유지하며 자동 원본 지정하지 않습니다. 업데이트 전 전체 백업을 권장합니다. 새 DB/형식 v3 백업은 3.0.8 이상에서 사용하며 3.0.7 이하로 프로그램만 되돌려 열지 마세요. 후속 개선 1·2·3차 기능은 이번 설치형·Windows ZIP·Python ZIP에 함께 포함됩니다.

복원 중 종료되면 다음 실행에 단계 기록을 확인해 복구합니다. 이전 자료로 되돌리지 못한 경우 불완전한 DB를 열지 않습니다. 복원 성공 뒤 이전 폴더 정리가 실패해도 복원 결과를 유지하고 다음 실행에 정리를 재시도합니다.

복원 예약·적용 전에 OfficeFlow DB 구조와 지원 버전도 검사합니다. 예약된 복원에 실패하면 복원 다시 시도, 예약 취소 후 현재 자료 사용, 시작 중단 중 선택합니다. 예약 취소는 복원 파일을 백업 폴더의 canceled-restore-….ofbackup으로 보존하며 다음 실행에 자동 적용하지 않습니다. 시작 중단은 현재 자료와 예약을 유지합니다. 자료 교체가 불완전한 경우에는 취소하고 넘어갈 수 없습니다.

첨부의 무결성 확인은 별도 작업으로 실행하며 진행률·취소 버튼을 표시합니다. 검사 중에도 업무·매시 알림을 처리할 수 있습니다. 도중 파일이 변경되면 다시 검사하도록 안내합니다. 첨부 후 내용 변경을 확인하는 기능이며 악성코드 검사는 아닙니다.

첨부 영구 삭제 중 종료되면 DB 연결이 남은 파일은 원래 위치로 복구하고 삭제가 확정된 파일만 정리를 재개합니다. 정체를 확인할 수 없는 격리 파일은 별도로 보존·백업하며 데이터 → 사용량 → 삭제 복구 대기에서 확인할 수 있습니다. 첨부 폴더의 .trash를 임의로 삭제하지 마세요.

3.0.5에서는 사용이 끝난 이전 버전 가져오기 기능을 제거했습니다. 이미 이전한 업무·업무일지·첨부파일과 기존 백업은 그대로 사용할 수 있으며, DB 스키마나 사용자 데이터를 변경하지 않습니다.

첨부 수동 순서 기능의 첫 실행은 DB 보호 사본을 data/schema-backups에 만든 뒤 0011로 업그레이드합니다. 기존 업무·일지·파일 ID·경로·내용과 표시 순서를 보존합니다. 보호·변환 실패 시 시작을 중단합니다. 보호 사본은 DB만 포함하므로 업데이트 전 전체 백업도 권장합니다. 0011 적용 DB와 백업은 이 기능이 포함된 새 앱으로 사용해야 하며 기존 공개 3.0.6으로 프로그램만 되돌리면 안 됩니다.

7. Python 실행 모드

회사 보안 정책이 서명되지 않은 실행 파일을 제한하지만 Python 실행은 허용하는 경우 OfficeFlow-Python-3.0.8.zip을 별도 폴더에 압축 해제해 사용할 수 있습니다.

  1. Python 3.12 64비트를 설치합니다. 다른 Python 버전이 함께 있어도 괜찮습니다.
  2. 최초 한 번 setup-officeflow-python.cmd를 실행해 전용 .venv와 라이브러리를 준비합니다.
  3. 이후에는 run-officeflow-python.cmd로 실행합니다.
  4. 실행에 문제가 있으면 diagnose-officeflow-python.cmd로 환경을 점검합니다.

Python 실행 모드도 설치형과 동일한 %LOCALAPPDATA%\OfficeFlow의 DB·첨부·설정을 사용합니다. 설치형과 Python형을 동시에 실행하지 말고 전환 전에는 트레이에서 완전히 종료하십시오.

Python 배포 폴더를 옮겼다면 설정 스크립트를 다시 실행하고 Windows 자동 시작 설정을 껐다가 켜십시오.

8. 문제 해결

증상확인할 내용
창이 보이지 않음작업 표시줄 알림 영역의 OfficeFlow 아이콘을 두 번 누릅니다.
전역 단축키가 동작하지 않음다른 프로그램이 같은 키를 사용 중인지 확인하고 설정에서 다른 조합을 지정합니다.
첨부파일 누락업무 기록 화면에서 누락 상태를 확인하고 원본 파일을 다시 연결합니다.
알림을 놓침설정의 놓친 알림 확인 범위와 Windows 자동 실행 여부를 확인합니다. 범위보다 오래된 알림은 자동으로 다시 띄우지 않습니다.
복원 후 내용이 바뀌지 않음트레이를 포함해 OfficeFlow를 완전히 종료한 뒤 다시 실행합니다.
종료가 오래 걸림파일·백업·내보내기 작업에 취소를 요청한 뒤 안전하게 끝날 때까지 응답 가능한 안내를 표시합니다. 디스크·보안 검사나 파일 저장 응답이 느리면 시간이 더 걸릴 수 있으므로 강제 종료하지 마세요.
설치형이 보안 프로그램에 의해 종료됨조직 정책을 확인하고, Python 실행이 허용된 PC에서는 Python 3.12 실행 모드를 사용합니다.

데이터 위치

기본 사용자 데이터는 %LOCALAPPDATA%\OfficeFlow에 저장됩니다. 프로그램 제거 시 이 폴더는 자동 삭제하지 않습니다.

안전한 재설치

먼저 데이터 화면에서 수동 백업을 만든 뒤 재설치하십시오. 같은 PC의 업그레이드는 기존 데이터 폴더를 그대로 사용합니다.

오래 실행하지 않은 반복 알림은 복구 범위 이전 건을 건너뛰며, 처리량이 많으면 나누어 이어서 확인합니다. 운영체제·보안 프로그램이 프로세스를 직접 종료하는 상황까지 방지하거나 종료 전에 알림을 보장하지는 않습니다.
