# OfficeFlow 3.0.8

후속 개선 1~3차를 설치형·Windows ZIP·Python 실행형에 함께 반영합니다.

## 주요 변경

- 첨부파일을 한 개 또는 여러 개 선택해 원하는 폴더에 사본으로 저장합니다. 표시 이름 변경과 파일별 메모도 제공합니다.
- 서식은 원본으로 지정하고 별도 작업본에서 편집합니다. 중요한 파일 상태는 자유 이름의 보관본으로 남기고, 이전 보관본에서도 새 작업본을 만들 수 있습니다.
- 원본·보관본은 보호된 보기 사본으로 엽니다. 수정한 사본은 작업본으로 보존하거나 문서를 닫은 뒤 변경을 버립니다. 원본 지정 해제도 지원합니다.
- 제목·설명·일정·중요도·상태·결과메모의 실제 저장된 변경을 자동 이력으로 남깁니다. 같은 값 저장·알림 확인·다시 알림은 새 업무 이력을 만들지 않습니다.
- `이력·보관`에서 변경 전/후, 두 시점 또는 현재 업무 정보와 비교합니다. 중요한 시점은 업무 정보·체크리스트·선택 파일을 함께 보관할 수 있습니다. 파일 없이 업무 정보만 보관할 수도 있습니다.
- 당시 보관 파일은 출처 첨부가 없어져도 열기·여러 파일 외부 저장·새 작업본 생성에 사용할 수 있습니다.
- 첨부 다중 선택/삭제, 긴 파일명, 상세 창의 내용 유지, 목록 공간·스크롤·이동 버튼과 체크박스 가독성을 정비했습니다. 파일 열기 후 불필요한 완료창도 제거했습니다.
- 내부 생성·삭제·중요 보관의 중단 상태와 참조를 검사하며 불명·수정 자료는 자동 삭제하거나 재등록하지 않습니다.

일정/알림의 중복처럼 보이는 표시 개선, `처리 필요` 분류 변경과 외부 Git 연동은 이번 범위가 아닙니다.

## 업데이트와 데이터 호환

**업데이트 전에 기존 버전에서 전체 백업을 만들고 OfficeFlow를 트레이에서도 완전히 종료하세요.**

3.0.8은 DB 보호 사본 후 스키마 0015로 이행합니다. 기존 업무·일지·첨부파일 ID·경로·내용은 보존하며 기존 첨부를 자동으로 원본 지정하지 않습니다. 보호·이행 실패 시 시작을 중단합니다.

**새 DB·형식 v3 백업은 3.0.8 이상에서 사용하세요. 3.0.7 이하로 프로그램만 되돌리면 안 됩니다.** 되돌려야 한다면 업데이트 전 앱과 업데이트 전 전체 백업을 함께 사용합니다. 자동 보호 사본은 DB만 포함하므로 전체 백업을 대신하지 않습니다. 이전 형식 v1/v2 백업 읽기는 유지합니다.

전체 백업은 업무 이력·중요 보관·참조 파일을 포함합니다. 임시 보기 사본은 제외되므로 중요한 수정 내용은 먼저 작업본이나 외부 파일로 보존하세요.

### Python 실행형

1. `OfficeFlow-Python-3.0.8.zip`을 새 폴더에 압축 해제합니다.
2. Python 3.12 64비트 환경에서 `setup-officeflow-python.cmd`를 한 번 실행합니다. 오프라인 라이브러리 미포함 배포본은 최초 구성에 인터넷 연결이 필요합니다.
3. `run-officeflow-python.cmd`로 실행합니다. 기본 `%LOCALAPPDATA%\OfficeFlow` 데이터를 그대로 사용하므로 DB·첨부를 새 배포 폴더에 옮길 필요가 없습니다. 별도 데이터 경로라면 같은 경로를 유지합니다.
4. 바로가기와 Windows 자동 시작을 새 실행기 위치에 맞춥니다.

### Windows 설치형과 EXE ZIP

`OfficeFlow-3.0.8-Setup.exe`를 기존 설치 위에 실행하면 프로그램 파일을 갱신하고 사용자 데이터는 유지합니다.

설치 없이 실행하려면 `OfficeFlow-3.0.8-Windows.zip` 전체를 풀고 `OfficeFlow/OfficeFlow.exe`를 실행합니다. `_internal`을 포함한 폴더 전체가 필요합니다. 이 방식도 기본 사용자 데이터 위치를 사용하며 USB 독립 데이터 모드는 아닙니다. 조직에서 EXE 실행을 제한하면 허용된 Python 실행형을 사용하세요.

## 다운로드 파일

- `OfficeFlow-3.0.8-Setup.exe`: Windows 설치·업데이트 프로그램
- `OfficeFlow-3.0.8-Windows.zip`: 설치 없이 실행할 전체 EXE 폴더
- `OfficeFlow-Python-3.0.8.zip`: Python 소스·실행기·설정기·도움말
- `OfficeFlow-Python-3.0.8.zip.sha256.txt`: Python ZIP 체크섬
- `SHA256SUMS.txt`: 빌드 파일 SHA-256 목록
- `release-manifest.json`: 버전·빌드 정보·파일 크기·체크섬

체크섬은 다운로드 손상 확인용이며 코드 서명이나 보안 인증을 대신하지 않습니다. 사용자 DB·첨부·백업·로그는 배포물에 포함하지 않습니다.

## 검증과 한계

최종 검증·실제 배포 결과는 [3.0.8 릴리스 체크리스트](https://github.com/spelld77/officeflow-v3/blob/main/docs/37-release-checklist.md)에 기록합니다. 검사에는 격리 자료를 사용하며 실제 사용자 프로필을 수정하지 않습니다.

검사 통과가 모든 PC·보안/DRM 정책·실제 편집기·장기간 상주 실행을 보증하지는 않습니다. 앱이나 PC가 꺼져 있으면 알림은 울리지 않습니다. 필요한 외부 사본과 전체 백업을 계속 보관하세요.
