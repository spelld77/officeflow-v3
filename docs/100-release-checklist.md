# 3.0.19 릴리스

보관함 드래그 U44만 기능 변경으로 포함한다. 정지 원인 조사는 사용자 요청으로 중단했다.
Python ZIP 전용, DB0018/백업 v3 유지. 운영 자료/실행 폴더는 변경하지 않는다.

관련 검사 16개 통과. 첫 검사에서 긴 기본 임시 경로의 파일 생성 오류 7개와 버전 기대값 실패 1개가 발생했다.
짧은 소유 임시 경로 및 버전 메타데이터를 보완해 동일 16개를 완료했다.
기존 native 좁은 창 검증은 98번을 따른다. 실제 탐색기 드롭/회사 환경/150·200%/전체 제품 회귀는 이번에 수행하지 않았다.
