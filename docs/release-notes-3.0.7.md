# OfficeFlow 3.0.7

한 업무의 여러 알림, 오늘·달력의 알림 미리보기와 첨부파일 수동 순서를 추가하고 날짜 입력과 알림 처리를 정돈했습니다.

## 주요 변경

- 한 업무에 최대 20개 알림을 설정합니다. 날짜·시각 직접 지정 또는 시작·종료 기준으로 추가하며, 시작·종료 기준은 일정 변경과 반복 회차에 연동합니다. 새 업무의 시작 시각 알림 하나는 그대로 유지합니다.
- 오늘의 `오늘 알림`은 업무 검색·필터와 독립적으로 표시합니다. 다음 달 업무나 일정 없는 업무의 오늘 알림도 확인하며 `전체 보기`로 나머지를 볼 수 있습니다. 달력의 `알림 N`과 하단 날짜 목록에서도 업무와 알림을 함께 확인합니다.
- 알림창의 기본 버튼은 `이번 알림 확인`입니다. 이번 알림만 닫고 업무 상태·다른 예약·재알림은 유지합니다. `업무 완료…`는 남은 알림을 중단한다는 확인을 거치며, 반복 업무의 `이번 회차 완료…`는 다음 회차를 유지합니다. `업무 대기로`는 업무만 보류하고 다음 예약은 끄지 않습니다.
- 날짜 입력칸 안에 `2026-10-07 (수)`처럼 요일을 표시합니다. 업무 등록·수정, 알림 설정, 업무일지·첨부 검색과 ICS 기간 입력에 적용하며 Tab 순서는 유지합니다.
- 첨부 목록에서 위·아래, 맨 위·맨 아래로 수동 순서를 바꾸고 즉시 저장합니다. 파일 자체를 이동하거나 다시 복사하지 않습니다. 같은 업무의 열린 기록 창에도 순서를 반영하며 미저장 입력은 보존합니다.
- Windows 어두운 테마에서 업무 입력창의 본문이 검게 보이던 문제를 수정하고, 작은 창과 높은 배율의 날짜·알림 버튼 표시를 점검했습니다.
- 업무·알림 저장은 같은 트랜잭션으로 처리하며 저장 충돌·실패 시 입력을 유지합니다. 변경하지 않은 알림의 확인·재알림 이력과 예약은 보존합니다.
- 배포 검증에서 발견한 알림 미리보기의 작업 스레드 결과·오류 전달 경로를 UI 스레드로 명시적으로 연결하고 취소·후속 조회·종료 검사를 추가했습니다.
- `처리 필요`의 분류 기준은 이번 버전에서 변경하지 않았습니다.

## 업데이트와 데이터 호환

**3.0.7은 기존 DB 보호 사본을 만든 뒤 첨부 순서 스키마 0011로 업그레이드합니다.** 기존 업무·일지·첨부파일 ID·경로·내용과 표시 순서는 보존합니다. 보호·변환이 실패하면 시작을 중단합니다.

**업그레이드된 DB·백업은 3.0.7 이상에서 사용하세요. 3.0.6 이하로 프로그램만 되돌리면 안 됩니다.** 되돌려야 한다면 업데이트 전 버전과 업데이트 전 전체 백업을 함께 사용해야 합니다. 자동 생성하는 보호 사본은 DB만 포함하므로 업데이트 전 수동 전체 백업도 권장합니다. 이전 형식 v1/v2 백업은 계속 읽을 수 있습니다.

### Python 실행형

1. 기존 OfficeFlow를 트레이에서 완전히 종료하고 가능하면 기존 버전에서 전체 백업을 만듭니다.
2. `OfficeFlow-Python-3.0.7.zip`을 새 폴더에 압축 해제합니다. 기존 폴더에 덮어쓰지 않습니다.
3. Python 3.12 64비트 환경에서 `setup-officeflow-python.cmd`를 한 번 실행합니다. ZIP에는 오프라인 런타임 라이브러리가 없어 최초 구성 시 인터넷 연결이 필요합니다.
4. `run-officeflow-python.cmd`로 실행합니다. 기본 `%LOCALAPPDATA%\OfficeFlow`를 그대로 사용하므로 DB·첨부파일을 새 배포 폴더에 옮길 필요는 없습니다. 별도 데이터 경로를 사용한다면 같은 경로를 유지합니다.
5. 바로가기와 Windows 자동 시작을 새 폴더의 실행기에 맞춥니다.

### Windows 설치형

`OfficeFlow-3.0.7-Setup.exe`로 기존 설치 위에 업데이트할 수 있습니다. 사용자 데이터는 유지됩니다. 회사 정책상 EXE가 제한되면 Python 실행형을 사용하세요. 개발 폴더의 `dist/OfficeFlow/OfficeFlow.exe`를 직접 실행하려면 같은 폴더의 라이브러리도 모두 필요합니다.

## 다운로드 파일

- `OfficeFlow-3.0.7-Setup.exe`: Windows 설치·업데이트 프로그램
- `OfficeFlow-Python-3.0.7.zip`: Python 실행형 소스·실행기·설정기·도움말
- `OfficeFlow-Python-3.0.7.zip.sha256.txt`: Python ZIP 체크섬
- `SHA256SUMS.txt`: 빌드 파일의 SHA-256 목록
- `release-manifest.json`: 버전·빌드 정보·파일 크기·체크섬

체크섬은 다운로드 손상 확인용이며 코드 서명이나 보안 인증을 대신하지 않습니다. 이전 공개 릴리스는 변경하지 않습니다.

## 검증

전체 회귀 테스트 655개, Windows 125%·200% 네이티브 검사 각 73개, 스레드 회귀 검사 10회 반복과 정적·타입 검사를 통과했습니다. 격리 설치·재설치·제거와 데이터 보존, 새 Python ZIP의 런타임 진단 8/8·실행·빈 DB, 868개 빌드 파일의 체크섬과 사용자 자료 제외도 확인했습니다. 공개 결과는 [릴리스 체크리스트](https://github.com/spelld77/officeflow-v3/blob/main/docs/22-release-checklist.md)에 기록합니다.

검사 통과가 모든 PC·보안 정책·장기간 상주 실행을 보증하는 것은 아닙니다. 앱·PC가 꺼져 있거나 보안 제품이 프로세스를 종료하면 알림이 울리지 않습니다.
