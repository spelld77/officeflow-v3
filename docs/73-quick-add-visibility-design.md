# 빠른 등록 결과 가시성 보완

2026-10-16. 사용자 `이거는 해야되지` 승인. 구현 전 상세설계다.
첨부 창은 작은 창/상시 필터 없는 타 프로그램 조사·제안만 하며 구현하지 않는다.
기존 미커밋 소스·문서는 보존한다. 버전·DB 스키마·배포·Git·실사용 자료는 변경하지 않는다.

## 문제와 등록 계약

예정 탭의 빠른 등록이 일정 없는 업무를 만들고 전체로 전환했다. 일정순에서는 맨 아래에 놓여
미등록으로 오해하고 다시 입력할 수 있다. Enter 입력 오류와 별개로 실제 UI/서비스 조합에서 재현했다.

- 오늘: 오늘 종일·알림 없음 유지.
- 예정: 내일 종일·알림 없음으로 등록하고 예정 탭 유지.
- 전체: 일정 없음·알림 없음 유지.
- 중요/대기/완료: 기존의 일정 없는 진행 업무 생성/전체 이동은 유지하되 입력 전에 전체 이동을 표시한다.
  중요도/상태를 임의로 바꾸지 않는다. 휴지통에서는 빠른 등록을 숨긴다.
- 제목에서 날짜를 추측하지 않는다. 시각/알림이 필요하면 기존 새 업무/업무 수정에서 정한다.
- 주 화면 시계를 한 번 읽어 로컬 날짜/저장 시각/요청 식별에 동일 적용한다. 자정·연말·DST를 검사한다.

## 작은 화면과 성공 확인

빠른 입력 아래 한 줄을 둔다. 일반 상태에는 `내일 10.17(토) · 종일 · 알림 없음` 등 실제 등록 기준을 표시한다.
등록 후 같은 한 줄을 `등록됨 · 제목 · 날짜/일정 없음 · 알림 없음`으로 바꾼다.
가로 폭이 좁으면 말줄임/전체 도움말·접근성 이름을 사용하며 큰 설명 패널/창 크기 증가는 없다.
성공 시에만 같은 줄에 업무 보기 버튼을 제공한다. 입력/탭 변경 때 이전 성공 표시를 해제한다.

새 업무가 로드된 목록에 있으면 해당 그룹을 펼치고 선택·스크롤해 실제 행이 보이게 한다.
입력 포커스는 유지해 연속 등록이 가능하며 선택 강조로 새 업무를 구분한다. 정렬/검색/필터는 임의로 지우지 않는다.
첫 조회 구간(현재 50행) 밖이나 현재 검색/필터에 가려졌다면 전체 업무를 끝까지 읽지 않는다.
성공 표시와 직접 업무 보기로 저장 여부를 확인한다. 이때 목록 밖이라는 점을 표시한다.
보기는 실제 저장 ID로 재조회하고 삭제/누락을 안내한다. 단순 보기로 완료/알림 확인/새 저장을 만들지 않는다.

저장 실패/빈 제목은 입력을 보존하고 성공 표시를 만들지 않는다. 기존 요청 식별·중복 재시도 계약을 유지한다.
같은 제목의 정상 업무를 무조건 중복 금지하지 않는다. 성공 후 다시 입력한 것은 별도 요청이다.

## 검증과 제외

예정 날짜/탭 유지, 입력 기준/성공 표시, 목록 행 선택·스크롤, 필터 밖/첫 조회 구간 밖의 제한된 조회,
직접 보기/누락, 빈 제목/실패/Enter·숫자 Enter·연속 등록/Tab, 로컬 날짜·DST·자정을 검사한다.
관련 기존 회귀와 Ruff/mypy/format, 좁은 창의 Windows 밝은/어두운 기본 팔레트·100/150/200%를 확인한다.
기능과 실제 회사 PC 확인을 구분하고 합성 fixture만 정리한다. 전체 릴리스 검사는 이번 범위 밖이다.

DB/파일 보존/자동 알림/기존 업무 일정/정렬 설정은 바꾸지 않는다. EXE·설치·ZIP·커밋·업로드는 별도 요청 후다.
