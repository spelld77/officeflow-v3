# OfficeFlow 3.0.6

캘린더를 기록·첨부 확인 중심으로 개선하고, 전체 코드 점검에서 확인한 알림·데이터 보호·조회·대량 처리 문제(A1–A8, B1–B4)를 정비한 릴리스입니다.

## 주요 변경

- 캘린더 일정 더블클릭 또는 선택 후 Enter로 해당 업무의 체크리스트·업무일지·첨부 기록을 엽니다. 하단의 `기록`, `첨부`, `⋯`로 바로 접근하며 일정 수정은 추가 메뉴에서 가능합니다. 같은 업무의 기록 창은 입력 내용을 지우지 않고 재사용합니다.
- 기록·첨부 창을 열어 둔 상태에서도 알림을 처리할 수 있습니다. 시작 시 설정한 복구 범위 안의 미처리 알림을 다시 표시하고, 표시 실패는 재시도합니다.
- 백업은 DB·첨부 사본을 함께 확보한 후 압축합니다. 복원과 첨부 영구 삭제에는 중단 복구 단계 기록을 추가했습니다. 복원 실패 시 재시도·예약 취소·시작 중단을 선택할 수 있고, 불완전한 자료 교체는 시작을 차단합니다.
- 날짜·시간 경과와 창 복귀 시 검색·필터·선택·스크롤을 유지하며 목록을 갱신합니다. 반복 업무의 완료일과 개별 결과 메모도 완료 검색에 포함합니다.
- 첨부 무결성 확인은 백그라운드 검사·진행률·취소를 지원합니다. 검사 중 변경된 파일은 다시 검사하도록 안내합니다.
- Excel은 고정 DB 사본을 배치 조회하고 스트리밍 저장합니다. 취소·실패 시 기존 출력 파일을 보존합니다. 오래된 반복 알림 계산도 복구 범위 이동과 이어 처리로 개선했습니다.
- ICS의 완료 일정 상태를 표준 값으로 수정하고, 업무 완료 여부와 결과 메모를 설명·확장 속성에 포함합니다.
- 종료 중에는 작업 취소와 자료 보호 상태를 안내하고 안전하게 마친 뒤 DB를 닫습니다. 작은 창과 Windows 125% 배율의 캘린더 하단도 검증했습니다.

## 데이터와 백업 호환

DB 스키마 변경은 없습니다. 기존 업무·업무일지·첨부파일과 설정을 그대로 사용합니다.

**3.0.6에서 만드는 백업은 형식 v2입니다. 새 백업은 3.0.6 이상에서 복원해야 합니다.** 이전 형식 v1 백업은 계속 읽을 수 있습니다. 백업이 이미 누락된 파일을 되살려 주지는 않으며, 누락 개수는 안내에 표시합니다. 첨부 저장소의 `.trash`는 삭제 복구 자료이므로 탐색기에서 임의로 지우지 마세요.

이 정비가 운영체제·회사 보안 제품에 의한 프로세스 강제 종료를 막아 주는 것은 아닙니다. PC·앱이 꺼져 있으면 알림이 울리지 않습니다. 느린 디스크나 보안 검사로 파일 저장·취소·종료가 지연될 수 있습니다.

## Python 실행형 업데이트

1. 실행 중인 OfficeFlow를 트레이 메뉴에서 **완전히 종료**하고, 가능하면 기존 버전에서 수동 백업을 만듭니다.
2. `OfficeFlow-Python-3.0.6.zip`을 **새 폴더**에 압축 해제합니다. 기존 폴더에 덮어쓰지 않습니다.
3. Python 3.12 64비트가 설치된 상태에서 `setup-officeflow-python.cmd`를 한 번 실행합니다. ZIP에는 런타임 라이브러리가 없어 최초 구성 시 인터넷이 필요합니다.
4. `run-officeflow-python.cmd`로 실행합니다. 기본 `%LOCALAPPDATA%\OfficeFlow`를 그대로 사용하므로 DB·첨부를 배포 폴더에 복사할 필요가 없습니다. 별도 데이터 경로를 지정했다면 같은 경로를 유지합니다.
5. 바로가기를 새 폴더의 실행기로 변경합니다. Windows 시작 시 실행을 사용한다면 새 실행기에서 설정을 확인해 이전 폴더 경로가 남지 않도록 합니다.

## Windows 설치형

`OfficeFlow-3.0.6-Setup.exe`로 기존 설치 위에 업데이트할 수 있습니다. 기존 사용자 데이터는 유지됩니다. 회사 정책상 EXE가 제한되면 Python 실행형을 계속 사용하세요. `dist/OfficeFlow/OfficeFlow.exe`를 직접 실행하려면 같은 폴더의 라이브러리도 모두 필요합니다.

## 다운로드 파일

- `OfficeFlow-3.0.6-Setup.exe`: Windows 설치·업데이트 프로그램
- `OfficeFlow-Python-3.0.6.zip`: Python 실행형 소스와 실행기·설정기·도움말
- `OfficeFlow-Python-3.0.6.zip.sha256.txt`: Python ZIP 체크섬
- `SHA256SUMS.txt`: 빌드 파일의 SHA-256 목록
- `release-manifest.json`: 버전·빌드 정보·파일 크기·체크섬

체크섬은 다운로드 손상 확인용이며 코드 서명이나 보안 인증을 대신하지 않습니다. 이전 공개 릴리스는 변경하지 않습니다.

## 검증

전체 회귀 테스트 567개(커버리지 87%), 실제 Windows 100%·125% 배율 UI 검사 각각 47개,
배포 검사 9개, 정적·타입 검사를 통과했습니다. 격리 설치·재설치·제거·데이터 보존,
새 ZIP의 런타임 진단 8/8과 실행 검사, 867개 빌드 파일 체크섬도 확인했습니다.
검사 통과가 모든 PC·보안 정책·장기간 상주 실행에서 문제가 없음을 보증하는 것은 아닙니다.
