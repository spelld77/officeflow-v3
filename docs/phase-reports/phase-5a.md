# Phase 5A 완료 보고서

- 완료일: 2026-09-14
- 상태: 완료

## 구현 결과

### 반복 규칙

- iCalendar RRULE 호환 문자열 저장
- 매일, 매주, 매월 반복과 1~99 간격 지원
- 반복 종료일을 사용자 화면에서는 포함 날짜로 입력
- 종료 없는 반복 지원
- 앱 시간대의 시계 시각을 유지해 일광절약시간 경계를 계산
- 지원 범위를 벗어난 외부 RRULE은 수정 화면에서 원문 유지
- 잘못된 규칙과 시작 일정 없는 반복을 저장 단계에서 차단

### 발생 건과 완료 이력

- 반복 원본 업무와 날짜별 발생 건을 분리
- `task_id + occurrence_start`를 식별자로 사용하는 발생 이력 저장
- 발생 건별 pending, completed, skipped, canceled 상태
- 완료 시각과 결과 메모 저장
- 한 발생 건을 완료하거나 건너뛰어도 원본 반복 업무와 이후 발생 유지
- 완료·건너뛴 발생을 제외하고 다음 실행 가능한 발생 계산

### 화면 연결

- 업무 편집창에 반복 유형, 간격, 종료일 입력 추가
- 캘린더 42일 범위에서 반복 발생을 실제 일정으로 확장
- 반복 일정과 완료 발생을 캘린더 및 날짜별 목록에서 구분
- 오늘 화면의 지연, 진행 중, 오늘 예정, 오늘 완료 그룹에 반복 발생 통합
- 캘린더 및 오늘 화면에서 선택 발생만 완료하거나 건너뛰기
- 반복 일정 편집은 현재 전체 원본 편집으로 처리

### 데이터베이스

- `tasks(recurrence_until, starts_at)` 반복 범위 인덱스
- `task_occurrences(task_id, status, occurrence_start)` 발생 이력 인덱스
- Alembic `0003_recurrence_indexes` 마이그레이션
