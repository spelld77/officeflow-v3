- 반복 실행 가능한 5,000건 벤치마크 명령

## 성능 기준과 결과

기준 데이터 5,000건, Windows 로컬 SQLite, 각 시나리오 1회 예열 후 10회 측정 결과다.
제품 요구사항의 핵심 검색·날짜 필터 목표는 200ms 이내다.

| 시나리오 | 중앙값 | 최댓값 |
|---|---:|---:|
| 오늘 그룹 4개 조회 | 5.53ms | 5.80ms |
| 상태·중요도 복합 필터 100건 | 3.27ms | 3.33ms |
| 제목·설명 부분 문자열 검색 | 4.44ms | 4.63ms |

세 시나리오 모두 200ms 목표를 충분히 만족했다. 현재 규모에서는 FTS5의 동기화 복잡도를
추가할 이점이 작으므로 도입을 보류한다. 업무일지가 검색 대상에 포함되는 Phase 6 또는 실제
데이터에서 검색 지연이 확인될 때 다시 측정한다.
