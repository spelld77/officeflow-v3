# Phase 5C 완료 보고서

- 완료일: 2026-09-14
- 상태: 완료

## 구현 결과

### 시스템 트레이와 Windows 알림

- 코드로 생성한 OfficeFlow 앱 아이콘을 창과 트레이에 공통 적용
- 트레이 메뉴에서 창 열기, 빠른 업무 등록, 완전 종료 제공
- 창 닫기 시 설정에 따라 트레이 숨김 또는 완전 종료
- 최초 트레이 숨김 시 앱이 계속 실행된다는 안내 표시
- Phase 5B 알림을 트레이의 Windows 메시지와 앱 내부 묶음 알림창에 함께 전달
- 트레이 알림 클릭 시 앱과 알림창을 앞으로 복원

### 단일 실행

- 데이터 디렉터리별 `QLockFile`로 실행 소유권을 원자적으로 결정
- `QLocalServer`/`QLocalSocket`으로 기존 프로세스에 활성화 명령 전달
- 두 번째 일반 실행은 기존 창을 복원하고 즉시 종료
- `--quick-add` 실행은 기존 앱의 전체 업무 빠른 등록 입력으로 이동
- 비정상 종료 후 stale lock과 로컬 서버를 안전하게 복구

### 전역 단축키와 자동 실행

- 기본 `Ctrl+Alt+O` Windows 전역 빠른 등록 단축키
- 영문·숫자·F1~F24와 Ctrl/Alt/Shift/Win 조합 검증
- Windows `RegisterHotKey` 등록과 종료 시 `UnregisterHotKey` 보장
- 현재 사용자 전용 `OfficeFlow v3` 시작 프로그램 레지스트리 값
- 로그인 실행은 `--background`로 시작해 트레이에서 대기
- 트레이가 없는 환경에서는 백그라운드 옵션이어도 창을 표시

### 설정 화면

- 트레이로 숨기기 사용 여부
- Windows 로그인 시 실행 여부
- 전역 빠른 등록 단축키
- 놓친 알림 복구 범위
- 작은 설정창에서도 모든 항목과 적용 버튼이 보이는 레이아웃
