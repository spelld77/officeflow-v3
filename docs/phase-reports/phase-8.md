# Phase 8 완료 보고서

- 완료일: 2026-09-16
- 상태: 완료
- 출시 버전: 3.0.0

## 구현 결과

### Windows 패키지

- PyInstaller 6.22.3의 onedir·windowed 방식으로 Python 설치가 필요 없는 x64 실행본 생성
- 실행 파일에 OfficeFlow 아이콘과 파일·제품 버전 3.0.0 리소스 삽입
- Alembic 마이그레이션 파일과 시간대 데이터를 패키지에 명시적으로 포함
- 개발 환경 PATH의 호환되지 않는 ICU DLL이 패키지에 섞이지 않도록 빌드 후 정리
- PySide6과 일치하는 Visual C++ 런타임을 패키지 루트에 배치
- 패키지 실행 시 빈 사용자 데이터 경로에서 DB를 생성하는 smoke test 추가

### 설치 프로그램

- Inno Setup 6.7.3 기반 `OfficeFlow-3.0.0-Setup.exe`
- 관리자 권한이 필요 없는 현재 사용자 설치
- 고정 AppId를 사용해 이후 버전이 같은 설치 위치를 안전하게 업그레이드
- 시작 메뉴, 선택형 바탕 화면 바로가기와 선택형 Windows 자동 시작
- 한국어·영어 설치 화면
- 제거 전 앱이 만든 자동 시작 레지스트리 항목 정리
- 프로그램 파일과 `%LOCALAPPDATA%\OfficeFlow` 사용자 데이터 경로 분리

### 도움말과 출시 도구

- 앱 사이드바의 `도움말`에서 설치된 한국어 HTML 안내 열기
- 업무·기간·반복·대량 탐색·v2.6 가져오기·백업·문제 해결 안내
- 한 명령으로 실행본, 설치 프로그램, 무결성 목록과 릴리스 명세 생성
- 별도 검증 스크립트에서 설치·업그레이드·제거 수명주기 자동 시험

## 설치 수명주기 검증

1. 비어 있는 임시 설치·데이터 경로에 현재 사용자 권한으로 무인 설치
2. Python과 개발 도구를 PATH에서 제거한 상태로 패키지 실행 및 DB 생성
3. 사용자 데이터 표식 생성
4. 동일 AppId와 경로에 3.0.0 재설치로 업그레이드 흐름 시험
5. 패키지 재실행 및 데이터 표식 보존 확인
6. 무인 제거 후 실행 파일 제거와 사용자 데이터 보존 확인

모든 단계가 통과했다. 실제 사용자 폴더는 시험에 사용하지 않았으며 검증 종료 후 임시 설치와
데이터를 정리했다.

## 알려진 배포 조건

현재 빌드는 개인 PC 설치용으로 코드 서명을 생략했다. 따라서 처음 실행할 때 Windows가
게시자를 확인할 수 없다는 경고를 표시할 수 있다. 외부 공개 배포 전에는 공인 코드 서명과
별도 Windows 10 실기기 확인을 추가한다.
