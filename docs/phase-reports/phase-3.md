# Phase 3 완료 보고서

- 완료일: 2026-09-13
- 상태: 완료

## 구현 결과

### 대량 업무 탐색

- 오늘 업무를 지연, 진행 중, 오늘 예정, 오늘 완료로 구분
- 완료 그룹 기본 접힘과 모든 그룹의 접기·펼치기
- 상단 요약 카드 클릭으로 그룹을 펼치고 바로 이동
- 정확한 시작·종료 경계에서 한 업무가 여러 그룹에 중복되지 않는 규칙
- 상태, 중요도, 고정 조건을 조합하는 필터와 한 번에 초기화
- 일정순, 중요도순, 최근 수정순, 제목순 정렬
- 보기별 필터와 정렬 상태 저장

### 목록 밀도와 지연 로딩

- 일반 목록은 최초 50건만 조회하고 Qt `fetchMore`로 50건씩 추가
- 그룹 목록은 그룹별 최초 50건과 `N개 더 보기` 제공
- 현재 로드 수와 전체 결과 수 표시
- 70px 일반 보기와 48px 간결 보기
- 간결 보기 설정과 그룹 접힘 상태 저장
- 서로 다른 높이의 그룹·업무·더 보기 행을 그리는 Qt delegate

### 작은 창 대응

- 960×640에서 검색, 복합 필터, 네 그룹 바로가기와 업무 목록 동시 표시
- 760×560에서 설명 문구와 여백을 축소하고 요약 카드를 2×2로 배치
- 목록의 불필요한 가로 스크롤 제거
- 최소 창에서도 그룹 헤더와 실제 업무 행을 함께 표시
