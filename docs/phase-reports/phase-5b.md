## 구현 결과

### 알림 규칙과 계산

- 업무별 시작·종료 기준 알림을 각각 설정
- 기준 시각, 5분·10분·30분·1시간·1일 전 프리셋
- 종일 일정의 당일 오전 9시 제안
- 단일·기간·반복 일정에 동일한 알림 계산 적용
- 업무 시간대의 현지 시각을 유지해 일광절약시간 경계 처리
- 완료·건너뛰기·취소된 반복 발생 건의 알림 제외

### 신뢰성과 복구

- 업무, 반복 발생, 알림 규칙, 예정 시각을 조합한 영구 중복 방지 키
- 데이터베이스 고유 제약을 통한 이중 발송 차단
- 앱 시작과 재확인 시 기본 최근 120분 범위의 놓친 알림 복구
- 여러 놓친 알림을 한 창에 묶어서 표시
- 다시 알림은 기존 발송 이력을 유지한 채 10분 뒤 재표시
- 다시 알림 대기 중 업무가 완료되면 불필요한 재표시 차단

### 사용자 동작

- 알림에서 바로 업무 또는 반복 발생 건 완료
- 업무를 대기 상태로 전환
- 10분 후 다시 알림
- 상태 변경 없는 확인 처리
- 30초 간격의 앱 내부 알림 확인

### 데이터베이스

- `reminder_deliveries` 발송 이력 테이블
