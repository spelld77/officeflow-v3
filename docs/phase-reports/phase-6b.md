# Phase 6B 완료 보고서

- 완료일: 2026-09-15

## 구현 결과

### 안전한 관리형 저장소

- 원본 파일명과 별개인 UUID 내부 파일명 사용
- 파일 확장자는 안전한 영문·숫자 확장자만 보존
- 내부 이름 앞 4자리로 디렉터리를 분산해 대량 파일 처리 대비
- DB에는 앱 첨부 폴더 기준 POSIX 상대 경로만 저장
- 절대 경로, `..`, 역슬래시 및 관리 루트 이탈 경로 차단
- 1MB 청크 단위 복사와 SHA-256 동시 계산
- 같은 볼륨의 `.part` 파일을 완성한 뒤 원자적으로 최종 경로 확정

### 실패와 취소 복구

- 복사 취소 또는 I/O 실패 시 `.part` 파일 제거
- 파일 확정 후 DB 저장 실패 시 관리 파일 제거
- 실제 삭제는 `.trash`로 먼저 격리한 뒤 DB 연결 삭제
- DB 삭제 실패 시 격리 파일을 원래 위치로 복원
- 격리 파일 최종 정리 실패는 별도 오류로 사용자에게 보고

### 첨부파일 기능

- 기록 창의 네 번째 `첨부파일` 탭
- UI를 멈추지 않는 작업 스레드 복사와 취소 진행창
- 파일 열기, SHA-256 무결성 확인, 연결 해제, 실제 파일 삭제
- 연결 해제 시 실제 파일 보존 위치 안내
- 누락 파일 자동 감지와 `missing_at` 기록·복구
- 체크섬 불일치 시 첨부 후 파일 변경 경고

### 탐색과 작은 창 대응

- 업무 목록 일정 정보 옆 `첨부` 표시
- 상태·중요도·고정 필터와 조합 가능한 `첨부만` 필터
- 필터 상태를 보기별 사용자 설정에 보존
- 620×650 기록 창과 500×540 최소 기록 창에서 모든 첨부 동작 접근 가능
