# Phase 7 완료 보고서

- 완료일: 2026-09-16
- 상태: 완료

## 구현 결과

### 앱 내 가져오기 흐름

- 사이드바 `데이터`에 `2.6 데이터 가져오기` 진입점 추가
- `office_tasks.db`와 선택적 첨부 폴더 지정
- 실제 변환 전 원본·가져올 개수, 누락 파일, 고아 연결과 날짜 오류 미리보기
- 긴 검사와 변환은 작업 스레드에서 수행하며 취소 지원
- 완료 결과는 다음 실행용으로 예약하고 사용자가 즉시 완전 종료할 수 있게 안내

### 변환 규칙

- `content` 첫 유효 줄 최대 80자를 제목, 전체 원문을 설명으로 보존
- 단일·매일·매주 일정, 상태, 중요도, 결과 메모와 완료 시각 변환
- 시각 없는 유효 날짜는 하루 종일 일정으로 변환하며 자동 알림은 만들지 않음
- 반복 업무의 과거 완료 이력을 발생 완료와 업무일지로 연결
- 전역 메모를 v3 노트로, 실제 파일을 관리 첨부로 복사
- 누락 첨부는 메타데이터와 누락 상태를 유지
- `deadline`과 해석할 수 없는 관련 경로는 추정하지 않고 설명과 보고서에 보존

### 데이터 안전성

- 원본 DB를 SQLite 읽기 전용 모드로 검사
- WAL 존재 시 v2.6 종료를 요구해 실행 중 변경 차단
- 변환 직전 원본 DB를 SQLite 온라인 백업으로 별도 보관
- 현재 v3 DB·첨부·설정을 임시 영역에 복제한 뒤 v2.6 데이터 병합
- 임시 DB의 무결성, 외래키와 변환 개수를 검증한 뒤 `.ofbackup` 생성
- 다음 실행에서 기존 Phase 6C 복원 절차로 적용하며 적용 직전 데이터도 자동 백업
- 원본 SHA-256과 `legacy_id` 기반 동일 데이터 중복 가져오기 차단

### 진단 보고서

- 앱 버전, 원본 경로·체크섬, 원본 안전 사본과 적용 예약 경로
- 원본·예정·실제 변환 개수
- 누락 첨부, 고아 업무일지·첨부, 잘못된 날짜·시간과 기본값 변환 내역
- 사용자 데이터 폴더의 `migration-reports`에 JSON으로 원자적 저장
