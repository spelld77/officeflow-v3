# Phase 6C 완료 보고서

- 완료일: 2026-09-15
- 상태: 완료

## 구현 결과

### Excel 내보내기

- 현재 업무 보기의 검색·상태·중요도·고정·첨부 필터와 정렬을 그대로 적용
- ID, 제목, 설명, 상태, 중요도, 시작·종료, 종일, 반복, 고정, 결과 메모, 첨부 여부와 생성·수정일 포함
- 날짜를 문자열이 아닌 Excel 날짜 값으로 저장
- 고정 헤더, 자동 필터, 줄무늬 표, 열 너비와 인쇄 너비 설정
- 사용자 문자열을 수식으로 해석하지 않도록 셀 형식을 명시적으로 텍스트 처리
- 임시 파일 저장, 재개방 구조 검증 후 원자적으로 최종 파일 확정

### ICS 내보내기

- 일정이 있는 전체 원본 업무를 RFC 5545 호환 VCALENDAR로 출력
- 종일 일정은 종료일 제외 방식의 `DTEND;VALUE=DATE`로 기간 보존
- 시간 일정은 업무 시간대의 `TZID`와 현지 시각 유지
- 반복 일정의 RRULE 원문 보존
- 제목·설명·결과 메모 이스케이프와 UTF-8 75바이트 줄 접기
- 취소 또는 실패 시 부분 파일 제거

### 백업과 복원

- 실행 중에도 일관된 DB 사본을 만드는 SQLite online backup API 사용
- 데이터베이스, 첨부파일과 설정을 하나의 `.ofbackup` ZIP 컨테이너에 보관
- SQLite `integrity_check`, 테이블별 레코드 개수, SHA-256, 파일 크기를 명세와 대조
- 중복 항목, 절대 경로, `..`, 역슬래시와 알 수 없는 파일을 거부해 ZIP 경로 탈출 차단
- 검증된 백업만 복원 예약 파일로 원자적 복사
- 다음 실행의 DB 연결 전에 현재 데이터를 `pre-restore` 백업한 뒤 교체
- DB·WAL·SHM, 첨부와 설정을 롤백 영역에 보존하고 복원 후 개수·체크섬 재검증
- 교체 실패 시 기존 데이터 원상 복구

### 자동 백업과 UI

- 사이드바 `데이터` 화면에서 Excel·ICS 내보내기, 수동 백업과 복원 예약 제공
- 긴 파일 작업은 QThread 워커에서 실행해 UI 응답성 유지
- 설정에서 자동 백업 사용 여부, 1~720시간 주기와 1~100개 보관 개수 지정
- 앱 시작 직후와 실행 중 15분마다 백업 필요 여부 확인
- 자동 백업 보관 정책은 자동 백업만 정리하며 수동·복원 직전 백업은 보존
