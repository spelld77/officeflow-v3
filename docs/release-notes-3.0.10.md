# OfficeFlow 3.0.10

3.0.9 이후 확인한 개선을 설치형·Windows ZIP·Python 실행형에 함께 반영합니다.

## 주요 변경

- 업무에 외부 폴더 바로가기를 연결하고 탐색기에서 엽니다. 폴더 이름/위치가 바뀌면 다시 지정할 수 있습니다. 연결 삭제는 실제 폴더를 삭제하지 않습니다.
- 연도·기간·선택 업무를 HTML/Excel과 첨부파일 묶음으로 외부 보관합니다. OfficeFlow 없이 제목·내용·일지·파일명·메모를 찾아볼 수 있으며 내부 업무/파일은 그대로 유지됩니다.
- 새 업무 시작 시각은 최소 1시간 뒤 정각으로 제안합니다(14:10 → 16:00). 시간에 `1124`를 입력하면 `11:24`로 확정되고, 알림 추가/수정도 동일하게 동작합니다. 닫힌 입력칸의 휠이 날짜/시간을 바꾸지 않습니다.
- 알림의 `업무 보기`로 해당 업무/회차의 기록 창을 엽니다. 업무 오른쪽 메뉴의 중복 진입을 정돈했습니다. 보기만으로 알림을 확인/완료 처리하지 않습니다.
- 캡처 후 클립보드 사진을 새 업무·업무 수정·첨부 목록에서 이름과 미리보기 확인 후 첨부합니다. `목록 / 썸네일`로 여러 이미지를 구분하며 보기 선택을 기억합니다. 더블클릭은 기존 외부 열기입니다.
- 기록·첨부·이력·설정·데이터 관리·백업·외부 보관 화면의 문구와 버튼을 정돈했습니다. 긴 설명은 펼쳐 확인하며 미확인·실패·보호 안내는 숨기지 않습니다.
- 오늘 알림은 건수·다음 시각·미확인·일부 조회를 구분합니다. 매시 설정은 실제 상태와 저장 전 설정을 구분합니다.
- 빠른 등록 Enter가 선택 업무 수정창을 열던 충돌을 수정했습니다. 일반 Enter/숫자키패드 Enter를 지원하며 업무 열기 단축키는 각 목록에서만 동작합니다.
- 데이터 관리 창을 즉시 닫을 때 뒤늦게 조회가 시작되던 문제와 좁은 창의 배경·잘림·목록 공간을 보완했습니다.

`처리 필요` 분류·알림 처리·매시 규칙은 유지합니다. URL 연결·클라우드 동기화·내부 자료 자동 삭제는 추가하지 않습니다.

## 업데이트와 데이터

먼저 기존 버전에서 전체 백업을 만들고 OfficeFlow를 트레이까지 완전히 종료하세요.

3.0.10 첫 실행은 DB 보호 사본 후 외부 폴더 연결용 스키마 0016으로 이행합니다. 기존 업무·일지·첨부 내용과 경로는 보존합니다. 전체 백업 형식은 v3를 유지합니다.
0016 DB와 이 DB를 담은 백업은 3.0.10 이상에서 사용하세요. 3.0.9 이하로 돌아가려면 업데이트 전 자료가 필요합니다. 보호 사본은 DB만 포함하므로 전체 백업을 대신하지 않습니다.

외부 폴더는 OfficeFlow가 관리하는 첨부 폴더가 아닙니다. 전체 백업에는 연결 정보만 포함되고 실제 외부 폴더 내용은 별도로 보관해야 합니다. HTML/Excel 업무 묶음은 조회용 사본이며 전체 복원용 `.ofbackup`과 다릅니다.

### Python 실행형

1. `OfficeFlow-Python-3.0.10.zip`을 새 폴더에 압축 해제합니다.
2. Python 3.12 64비트 환경에서 `setup-officeflow-python.cmd`를 한 번 실행합니다.
3. `run-officeflow-python.cmd`로 시작합니다. 같은 사용자 데이터 경로라면 DB·첨부를 옮길 필요가 없습니다.
4. 바로가기와 Windows 자동 시작을 새 실행기 위치로 연결합니다.

최초 구성용 오프라인 라이브러리는 ZIP에 포함하지 않습니다. 인터넷 연결 또는 조직이 승인한 라이브러리 공급 방법이 필요합니다. 조직 보안 정책을 우회하는 기능은 아닙니다.

### 설치형 / Windows ZIP

- `OfficeFlow-3.0.10-Setup.exe`: 기존 설치 위에 업데이트합니다.
- `OfficeFlow-3.0.10-Windows.zip`: 전체 해제 후 `OfficeFlow/OfficeFlow.exe`를 실행합니다. `_internal`을 포함한 전체 폴더가 필요합니다.
- `OfficeFlow-Python-3.0.10.zip.sha256.txt`, `SHA256SUMS.txt`, `release-manifest.json`: 다운로드 무결성과 배포 정보를 확인합니다. 코드 서명이나 보안 인증을 대신하지 않습니다.

사용자 DB·첨부·백업·로그는 배포에 포함하지 않습니다. 검증 결과와 제한은 [3.0.10 릴리스 체크리스트](https://github.com/spelld77/officeflow-v3/blob/main/docs/59-release-checklist.md)를 참고하세요.
