# OfficeFlow 3.0.11

첨부파일이 여러 개일 때 좁은 창에서도 원본과 작업본을 구분하고 찾아 쓰기 쉽도록 개선했습니다.

## 주요 변경

- 넓은 첨부 목록과 `전체 파일 / 원본 / 작업본 / 일반` 필터, 표시/전체 개수와 `전체 보기`.
- 작업본의 직접 출처 한 줄 표시. 전체 이름·메모·생성 당시 출처는 `더보기 → 파일 정보…`에서 확인.
- `관련 파일 보기…`로 같은 계열의 현재 첨부를 기존 보관함에서 조회하고 범위를 명확히 표시.
- `넓게 보기 / 이전 크기`로 같은 업무 보기 창을 조절하고 다음 창에서도 크기 기억.
- 숨긴 파일은 저장·삭제 대상에서 제외. 필터 중 순서 이동은 막고 전체 수동 순서는 유지.
- 어두운 시스템 환경의 스크롤 본문 가독성·최소 창 잘림과 정보 조회/선택 변경 경쟁 보완.

## 호환과 업데이트

DB0016·전체 백업 v3를 유지합니다. 3.0.10에서 추가 DB 이행은 없으며 업무·첨부 내용/경로를 변경하지 않습니다.
더 오래된 DB는 첫 실행 때 필요한 이행을 적용하므로 업데이트 전 전체 백업을 권장합니다.

기존 프로그램을 트레이까지 완전히 종료한 뒤 설치본을 실행하거나 새 ZIP을 별도 폴더에 풀어 사용하세요.
Python 사용자는 새 ZIP에서 `setup-officeflow-python.cmd`를 한 번 실행한 후 `run-officeflow-python.cmd`로 실행합니다.
같은 `%LOCALAPPDATA%\OfficeFlow` 데이터 경로를 사용하면 DB·첨부를 복사할 필요가 없습니다.
Python ZIP에는 Python 자체와 오프라인 wheel이 없으며 최초 환경 구성에 인터넷 연결이 필요합니다.

## 배포 파일

- `OfficeFlow-3.0.11-Setup.exe`: Windows 사용자별 설치/업데이트.
- `OfficeFlow-3.0.11-Windows.zip`: 전체 EXE 폴더. 압축 해제 후 `OfficeFlow/OfficeFlow.exe` 실행.
- `OfficeFlow-Python-3.0.11.zip`: Python 실행용 소스·실행기·사용자 안내.
- `OfficeFlow-Python-3.0.11.zip.sha256.txt`: Python ZIP의 SHA-256.
- `SHA256SUMS.txt`: 배포 파일 해시 목록.
- `release-manifest.json`: 버전·파일 경로·크기·SHA-256 목록.

회사 보안/DRM·외부 문서 편집기·실사용 설치/Python 실행 폴더는 자동으로 교체하지 않습니다.
