# 업무 입력·알림 연결 공통 및 상세설계

2026-10-10 사용자 승인: U18/U19를 처음부터 끝까지 상세설계·구현·테스트한다.
버전·커밋·배포·업로드, 미저장 초안 보호, 빠른 업무 이동, 외부 보관 내역, 내부 정리는 제외한다.
기존 미커밋 외부 폴더/보관 작업은 보존한다. DB/백업 형식은 변경하지 않는다.

## 1차: 입력

- 새 업무/업무 수정의 날짜·시간·닫힌 콤보·반복 간격은 휠로 값을 바꾸지 않는다. 본문 스크롤로 전달한다.
  펼친 콤보 목록/달력 팝업은 기존 스크롤을 유지한다. 공통 클래스를 쓰되 이번 적용 범위는 업무 입력창이다.
- 시간은 전체 값으로 입력한다. 1~2자리 시(11→11:00), 3~4자리 시분(924→09:24), HH:mm을 허용한다.
  진입 시 전체 선택, 붙여넣기, Tab/Shift+Tab 확정. 잘못된 입력은 그대로 보여주고 저장을 막는다.
  시간 데이터 접근은 미확정 텍스트도 검증하며 기존 값으로 몰래 되돌리지 않는다.
- 작은 −/+ 버튼은 한 시간 증감(접근 가능한 이름/툴팁). Tab 동선에는 버튼을 추가하지 않는다.
  시간칸 ↑/↓도 한 시간 증감한다. 분은 유지하고 자정을 넘으면 연결 날짜를 하루 증감한다.
  끝/반복 제약은 기존 업무 저장 검증을 따른다. 24개 정각판/최근 시각 메뉴는 만들지 않는다.
- 종료·반복이 숨겨졌을 때 해당 입력칸을 검사하거나 Tab으로 진입하지 않는다.

## 2차: 기본값·등록

- 창을 열 때 실제 현재 시각 + 최소 60분을 만족하는 가장 이른 정각으로 결정한다.
  14:00:00→15:00, 14:00:01/14:10→16:00. 입력 도중/저장 때 시각을 재설정하지 않는다.
  날짜는 실제 자정 경계를 반영한다. DST는 실제 경과 시간을 기준으로 하고 UI에서 구별할 수 없는
  두 번째 중복 시각보다 다음 명확한 시각을 사용한다.
- 달력에서 날짜를 지정해 열면 그 날짜를 유지하고 위 기본 시각의 시·분만 사용한다.
  과거 선택 날짜는 사용자의 의도일 수 있으므로 자동으로 미래 날짜로 바꾸지 않는다.
  기존 저장 서비스의 과거 새 알림 금지 규칙은 유지한다. 과거 업무는 알림 없음으로 기록할 수 있으며
  새 알림이 유효하지 않으면 입력/알림 설정 위치로 안내한다. 주 화면과 입력창은 같은 현재 시각을 사용한다.
- 알림은 시작 기준 0분 하나. 새 업무의 미수정 기본 알림만 일정 없음 선택 동안 숨겨서 저장에서 제외한다.
  다시 일정 지정하면 복구한다. 사용자 지정 알림/기존 업무 알림은 조용히 삭제하지 않는다.
  사용자 지정 시작/종료 기준 알림이 일정과 맞지 않으면 설정 버튼 위치로 안내한다.
- 종료 기본값은 직접 편집 전까지만 시작 +1시간을 따른다. 실제 기존 종료/직접 입력한 종료는 유지한다.
  하루 일정에서 날짜를 넘길 수 없으면 23:59까지 제안하고, 시작이 23:59라면 기간 일정 선택을 안내한다.
  기간 일정에서는 종료 날짜도 다음 날로 맞춘다. 날짜의 최소값으로 사용자의 종료를 몰래 덮어쓰지 않는다.
- 제목/시간/종료/반복 오류는 해당 항목을 표시·강조하고 스크롤/포커스를 이동한다.
  기존 제목→설명→중요도 등 Tab 순서는 유지한다. 단순 이동 기능과 미저장 보호는 추가하지 않는다.

## 3차: 알림에서 업무 보기

- 선택한 알림의 delivery ID로 업무 보기 요청. 실제 업무 ID/원래 반복 회차 시각을 사용한다.
- 현재 DB 업무를 재조회한다. 삭제/사라진 업무·이미 처리된 알림은 오류/상태 안내하고 잘못된 창을 열지 않는다.
- 기존 비모달 업무 기록 창을 사용한다. 동일 업무/회차/읽기 전용 상태의 열린 창은 재사용한다.
  업무일지 하위에 이미 열린 창도 찾는다. 선택/검색 중인 주 화면 상태는 바꾸지 않는다.
- 보기만으로 delivery 확인/미루기/업무 완료를 하지 않는다. 알림은 남고 별도로 처리한다.
- 알림은 상단 고정이므로 기록 창은 옆으로 배치해 겹침을 줄인다. 새 modal/topmost 기록 창을 만들지 않는다.
  작은 화면에서 공간이 없으면 완전한 비겹침을 보장하지 않으며 두 창의 조작 가능 여부를 검사한다.
- 주 화면/앱 종료는 기존 안전한 기록 창·알림 창 정리 절차를 사용한다.

## 검증

### 후속 보완 (2026-10-10)

- 알림 추가/수정의 직접 지정 시각도 공통 전체 시간 입력을 사용한다. Tab/Shift+Tab,
  붙여넣기, 한 시간 조정과 날짜 경계/휠 보호를 동일하게 적용한다. 잘못된 시각은
  그대로 남겨 수정하도록 안내하고 추가/적용을 막는다. 상대 기준에서는 숨긴 시각을 검사하지 않는다.
- 직접 지정의 새 기본 시각도 최소 한 시간 뒤 정각을 사용한다. 기존 알림의 시각은 유지한다.
- 업무 목록·달력·휴지통 우클릭의 동일 기록 창 진입은 `업무 보기` 하나로 통일한다.
  업무일지/체크리스트/첨부는 해당 창의 탭을 이용한다. 기존 마지막 탭 기억·회차·휴지통 읽기 전용과
  목록/달력의 첨부 바로가기 버튼은 유지한다. 폴더 바로가기·이력·완료·수정 기능은 유지한다.

입력 파서 정상/오류/붙여넣기/포커스/Tab/휠 전달/증감·자정·숨김,
기본값 초·연말·DST/달력 선택/알림 보존/종료 직접 입력/오류 위치,
알림 실제 회차·읽기 비변경·중복 창·타 창 동시 조작/종료를 격리 자료로 검증한다.
공통 스타일 밝음/어둠 제어 팔레트·좁은 창·100/150/200% Qt 배율 캡처를 포함한다.
관련 회귀와 전체 검사, Ruff/mypy를 수행한다. 실제 사용자 프로필/회사 보안 환경은 사용하지 않는다.
