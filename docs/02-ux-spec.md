# UX 설계

## 1. 기본 레이아웃

```text
┌──────────────────────────────────────────────────────────────────┐
│ OfficeFlow     통합 검색                         + 새 업무       │
├────────────┬──────────────────────────────┬──────────────────────┤
│ 오늘       │ 보기 제목 / 필터 / 정렬      │ 업무 상세            │
│ 예정       ├──────────────────────────────┤ 제목                  │
│ 중요       │ ▼ 지연 3                     │ 기간                  │
│ 대기       │   업무 카드                  │ 상태·중요도           │
│ 완료       │ ▼ 진행 중 4                 │ 설명·체크리스트       │
│ 전체       │   업무 카드                  │ 알림·첨부·업무일지    │
│            │ ▶ 나중에 21                 │                      │
│ 캘린더     │                              │ [저장]               │
│ 업무일지   │                              │                      │
│ 설정       │                              │                      │
└────────────┴──────────────────────────────┴──────────────────────┘
```

- 왼쪽: 고정된 탐색 영역
- 가운데: 현재 보기의 결과 목록 또는 캘린더
- 오른쪽: 선택 항목의 상세 내용
- 1100px 이상: 사이드바, 업무 목록, 상세 패널을 동시에 표시한다.
- 850~1099px: 상세 패널을 숨기고 목록 공간을 우선한다. 업무 선택 시 상세 내용을 서랍 또는 대화상자로 연다.
- 760~849px: 사이드바를 88px로 축소하고 요약 카드를 2×2로 배치한다.
- 최소 창 크기는 760×560이며 안내 문구는 사용 가능한 폭에 맞춰 줄바꿈한다.
- 마지막 정상 창 크기와 위치를 저장하고, 현재 연결된 화면 범위에 있을 때만 복원한다.

## 2. 많은 업무를 다루는 규칙

### 기본 그룹

오늘 화면의 기본 순서는 다음과 같다.

1. 지연
2. 현재 진행 중인 기간 일정
3. 다음 알림이 임박한 업무
4. 오늘 예정
5. 시간 미정
6. 완료

각 그룹은 접고 펼칠 수 있으며 상태를 사용자 설정으로 기억한다. 완료 그룹은 기본적으로 접는다.

### 목록 밀도

- 기본 보기: 제목, 기간/시간, 중요도, 상태, 첨부·반복 표시
- 간결 보기: 한 줄에 제목과 핵심 상태만 표시
- 카드 높이는 내용 길이에 따라 무한히 커지지 않는다.
- 긴 내용은 상세 패널에서 확인한다.

### 검색과 필터

- 검색창은 250ms 디바운스를 적용한다.
- 활성 필터는 칩 형태로 표시한다.
- 필터 전체 해제 기능을 항상 노출한다.
- 빈 결과에는 적용 중인 검색어와 필터를 보여준다.
- 마지막으로 사용한 보기별 필터는 선택적으로 기억한다.

### 키보드 흐름

- `Ctrl+N`: 새 업무
- `Ctrl+K`: 통합 검색
- `Ctrl+F`: 현재 보기 검색
- `Enter`: 선택 업무 열기
- `Ctrl+Enter`: 편집 저장
- `Space`: 완료 상태 전환 전 확인
- `Esc`: 상세 편집 취소 또는 대화상자 닫기

단축키는 설정에서 변경할 수 있고 OS 전역 단축키와 앱 내부 단축키를 구분한다.

## 3. 업무 등록 흐름

### 빠른 등록

제목만 입력하면 일정 없는 활성 업무로 등록한다. 자연어 날짜 해석은 초기 버전에 포함하지 않는다.

### 상세 등록

필수 입력은 제목뿐이다. 나머지는 다음 순서로 제공한다.

1. 제목과 설명
2. 일정 없음 / 하루 / 기간
3. 종일 또는 시간 지정
4. 중요도와 상태
5. 반복
6. 알림
7. 체크리스트와 첨부파일

종료일이 시작일보다 앞서면 저장할 수 없고, 해당 입력 근처에 오류를 표시한다.

## 4. 기간 일정 규칙

- 화면에서 시작일과 종료일은 모두 포함되는 날짜로 표시한다.
- 종일 일정 `9월 14일~17일`은 14, 15, 16, 17일에 나타난다.
- 시간이 있는 일정은 정확한 시작·종료 시각을 표시한다.
- 종료 시각이 없는 일정은 시작 시각만 가진 업무로 처리할 수 있다.
- 현재 시간이 시작과 종료 사이면 `진행 중` 배지를 표시한다.
- 기간이 지난 미완료 업무는 자동 완료하지 않고 `지연`으로 계산한다.

## 5. 캘린더 동작

- 월간 보기에서 여러 날 일정은 행을 따라 연결된 막대로 표시한다.
- 주 경계를 넘으면 다음 행에서 이어진다는 표시를 사용한다.
- 한 날짜에 표시 공간을 넘는 경우 `+N개 더 보기`를 제공한다.
- 날짜를 클릭하면 해당 날짜와 겹치는 모든 일정을 표시한다.
- 일정 클릭 시 오른쪽 상세 패널에서 열고, 더블 클릭 시 편집한다.
- 드래그로 기간 생성과 일정 이동은 1차 안정화 이후 기능으로 둔다.

## 6. 상태와 중요도

상태는 `진행`, `대기`, `완료`, `취소`, `보관`으로 제한한다. `지연`과 `진행 중`은 저장 상태가 아니라 현재 시각과 일정으로 계산되는 표시 상태다.

중요도는 `보통`, `관심`, `중요`, `긴급`을 유지해 기존 데이터와 사용 습관을 보존한다. 색상만으로 구분하지 않고 텍스트 또는 아이콘을 함께 제공한다.

## 7. 위험한 동작

- 삭제는 기본적으로 보관함 이동 또는 소프트 삭제를 사용한다.
- 실제 파일 삭제는 대상 경로와 복구 가능 여부를 명확히 보여준 후 실행한다.
- 첨부파일 연결 해제와 실제 파일 삭제를 별도 동작으로 구분한다.
- DB 가져오기 전 자동 백업 결과를 먼저 보여준다.
