# OfficeFlow 3 사용자 안내

## 설치와 첫 실행

`OfficeFlow-3.0.0-Setup.exe`를 실행한다. 관리자 권한은 필요하지 않으며 기본 설치 위치는
`%LOCALAPPDATA%\Programs\OfficeFlow`다. 시작 메뉴 바로가기는 기본으로 만들고, 바탕 화면
바로가기와 Windows 로그인 시 자동 시작은 설치 화면에서 선택할 수 있다.

사용자 DB, 첨부, 설정과 백업은 설치 폴더와 분리된 `%LOCALAPPDATA%\OfficeFlow`에 저장된다.
같은 위치에 새 버전을 설치해도 이 데이터는 유지되며, 프로그램을 제거해도 자동 삭제하지
않는다.

## 핵심 사용 흐름

- 상단 빠른 등록에 제목을 입력하고 Enter를 누르면 현재 보기 문맥에 맞는 업무가 생긴다.
- 업무를 열면 하루·기간·종일·시간 일정, 반복, 중요도와 알림을 지정할 수 있다.
- 오늘 화면은 `처리 필요`, `오늘 할 일`, 접힌 `완료한 업무`의 세 구역으로 표시된다. 진행 중 업무는 오늘 예정 업무보다 먼저 나온다.
- 업무는 시간·제목·상태·첨부 여부가 한 줄로 표시된다. 왼쪽 원을 누르면 바로 완료되며 10초 안에 `실행 취소`할 수 있다.
- 검색과 상태·중요도·고정·첨부 필터를 조합할 수 있고 보기별 조건은 자동으로 기억된다.
- 반복 업무는 발생 한 건만 완료하거나 건너뛸 수 있으며 다음 발생은 유지된다.
- 업무 기록에서 체크리스트, 완료 요약, 업무일지와 첨부파일을 관리한다.
- 업무 행의 `⋯` 또는 오른쪽 버튼 메뉴에서 바로 완료하거나 `완료 요약 입력 후 완료`를 선택할 수 있다.
- 업무 행의 `⋯` 또는 오른쪽 버튼 메뉴에서 `휴지통으로 이동`할 수 있다. 삭제한 업무는 일반 목록·캘린더·알림에서 제외되지만 기록과 첨부파일은 유지된다. 왼쪽 `휴지통` 화면에서 기존 기록·첨부파일을 조회하거나 업무를 복원할 수 있으며, 내용 수정과 파일 추가·삭제는 복원 후 가능하다.
- 목록의 `첨부` 표시로 첨부 여부를 확인하고, `첨부` 버튼이나 오른쪽 버튼 메뉴로 첨부 목록을 바로 열 수 있다. 새 파일 추가는 열린 첨부 화면에서 한다.
- 업무일지는 선택한 날짜에 완료한 업무와 직접 작성한 일지를 함께 보여 준다.
- 업무일지 검색창은 날짜와 관계없이 제목, 설명, 완료 요약과 업무일지 내용을 함께 검색한다.
- 새 업무는 시작 날짜와 시각 중심으로 간단하게 입력하며 시작 알림은 `기준 시각`이 기본이다. 종료·반복·종료 알림은 `추가 설정 보기`에서 필요할 때만 지정한다.
- 캘린더 일정의 `첨부` 표시로 파일 유무를 확인하며, 일정 막대나 날짜 목록을 오른쪽 클릭해 결과·기록과 첨부파일을 열 수 있다.
- 일정이 많은 달은 날짜별 개수 중심으로 자동 표시된다. 날짜를 누르면 그날의 전체 일정 개수를 강조해 표시하고, 3개 이상이면 스크롤 안내와 항상 보이는 스크롤바로 아래 목록의 나머지 일정을 확인할 수 있다.
- 알림창은 처리할 때까지 화면 중앙의 항상 위 창으로 유지된다. 기본 10분부터 최대 24시간까지 다시 알림 시간을 분 단위로 지정할 수 있다.
- 알림창에서 완료·대기·확인·다시 알림을 처리하면 현재 업무 화면과 캘린더를 즉시 다시 불러온다. `확인`은 알림만 확인 처리하며 업무 상태를 완료로 바꾸지는 않는다.
- 상태·중요도·고정·첨부 필터는 기본적으로 접혀 있으며, 적용 중인 조건과 `모두 해제`는 닫은 뒤에도 표시된다.
- 업무일지 검색은 제목·설명·완료 요약·일지 본문·진행 결과를 대상으로 한다. 같은 업무의 완료 정보와 업무일지는 한 행으로 묶고, 결과가 더 있으면 `업무 더 보기`로 계속 불러온다.
- 오래된 기록을 좁힐 때 업무일지 검색 아래의 `기간 지정`을 켜고 시작일과 종료일을 선택한다.
- ICS 내보내기는 현재 목록, 선택한 업무 또는 기간을 지정할 수 있다. 여러 업무는 `Ctrl`을 누른 채 목록에서 선택한다. 반복 일정은 기본적으로 제외되며 필요할 때만 `반복 일정 포함`을 켠다.
- 기간 지정은 시작일과 종료일 사이에 하루라도 겹치는 여러 날 일정을 포함하고, 휴지통 업무와 일정 없는 업무는 제외한다.

## 알림과 놓친 알림 확인 범위

- OfficeFlow는 실행 중 약 30초마다 예정된 알림을 확인한다. 프로그램이 종료되어 있거나 PC가 절전 상태라 알림 시각을 지나친 경우, 다음 실행·복귀 때 설정된 `놓친 알림 확인 범위` 안의 미처리 알림을 한 번 다시 보여준다.
- 기본값 120분은 현재 시각을 기준으로 최근 2시간 안에 놓친 알림을 뜻한다. 범위보다 오래된 알림은 프로그램 시작 때 한꺼번에 띄우지 않는다.
- 범위를 지나기 전에 복구된 알림은 알림 창에 `놓친 알림`으로 표시된다. 같은 예정 알림은 중복으로 다시 만들지 않는다.
- `다시 알림`으로 미룬 항목은 놓친 알림 확인 범위와 별개로 사용자가 지정한 시각에 다시 울린다.
- 알림 창의 `확인`은 알림만 처리하고 업무를 완료하지 않는다. `완료`와 `대기`는 업무 상태에도 즉시 반영된다.

프로그램 안의 `도움말`을 누르면 설치된 HTML 사용자 안내가 열린다.

## v2.6 데이터 가져오기

1. OfficeFlow v2.6을 완전히 종료한다.
2. v3의 `데이터 → 2.6 데이터 가져오기`를 연다.
3. 기존 `office_tasks.db`를 선택한다. DB 옆의 `saved_files`는 자동으로 찾는다.
4. `가져오기 전 검사`에서 개수, 누락 파일과 날짜 경고를 확인한다.
5. `안전하게 가져오기`를 실행한 뒤 v3를 완전히 종료하고 다시 실행한다.

원본 DB는 읽기 전용으로 취급하고 별도 안전 사본을 만든다. 기존 v3 데이터도 유지된다.

## 백업과 복원

- `데이터 → 사용량`에서 현재 업무·휴지통 개수, DB·첨부파일·백업 용량, 30일 지난 휴지통 업무, 누락·중복·정리 대기 첨부파일과 용량이 큰 파일 상위 5개를 확인할 수 있다.
- `첨부 저장 폴더 열기`로 관리 저장소를 탐색기에서 확인할 수 있다. 내부 파일명으로 보이며, 탐색기에서 파일을 이동·이름 변경·삭제하면 업무와의 첨부 연결이 깨질 수 있으므로 변경은 OfficeFlow에서 한다.
- 확인·완료·대기로 처리한 지 180일이 지난 알림 이력도 `데이터 → 사용량`에서 정리 후보 개수로 확인할 수 있다. 아직 자동으로 삭제하지 않는다.
- 업무에서 첨부 연결을 해제하면 파일과 원래 업무 정보가 `데이터 → 첨부 정리`에 남는다. 여기에서 원래 업무로 복원하거나 확인 후 영구 삭제할 수 있다. 30일이 지나도 자동 삭제하지 않는다. 이전 버전에서 연결 정보 없이 남은 파일은 복원할 업무를 알 수 없어 영구 삭제만 가능하다.
- 같은 업무에 같은 내용의 파일을 다시 첨부하면 중복 복사를 막는다. 100 MB 이상 파일은 백업 크기 증가를 먼저 경고하고, 백업 전에는 필요한 임시 공간과 남은 디스크 공간을 확인한다.
- 중요한 변경 전 `데이터 → 지금 백업`으로 `.ofbackup`을 만든다.
- `데이터 → 내보내기 · 백업`에서 최근 자동 백업과 다음 백업 기준 시각, 수동·자동 백업 개수를 확인하고 백업 폴더를 열 수 있다. PC가 기준 시각에 꺼져 있으면 다음 OfficeFlow 실행 후 자동 백업한다.
- 수동 백업은 자동으로 삭제되지 않는다. `오래된 수동 백업 정리`에서 남길 최근 백업 개수를 정하고 삭제 대상을 확인한 경우에만 오래된 파일을 지운다.
- 복원 파일은 DB와 첨부 체크섬을 검사한 뒤 다음 실행 전에 적용한다.
- 적용 직전의 현재 데이터도 `pre-restore` 백업으로 남긴다.
- 설정에서 자동 백업 주기와 보관 개수를 지정할 수 있다.

## 문제 해결

### 창이 보이지 않을 때

작업 표시줄 알림 영역의 OfficeFlow 아이콘을 두 번 누른다. 설정에 따라 닫기 버튼은 완전
종료가 아니라 트레이 숨기기로 동작할 수 있다.

### 전역 단축키가 동작하지 않을 때

다른 프로그램이 같은 조합을 사용 중인지 확인하고 설정에서 다른 조합을 지정한다.

### 복원이 바로 보이지 않을 때

트레이 아이콘 메뉴에서 `완전히 종료`한 뒤 다시 실행한다.

### v2.6 DB가 실행 중이라고 나올 때

v2.6을 종료한 뒤 DB 옆의 `office_tasks.db-wal` 파일이 사라졌는지 확인한다. 원본 DB를
복사하거나 강제로 수정하지 말고 다시 검사한다.

### 첨부파일이 누락됐을 때

업무 기록에서 누락 상태를 확인하고 원본 파일을 다시 연결한다. v2.6 가져오기 보고서는
`%LOCALAPPDATA%\OfficeFlow\migration-reports`에 저장된다.

## 제거와 재설치

Windows의 설치된 앱에서 OfficeFlow를 제거한다. 실행 파일과 바로가기는 삭제하지만 사용자
데이터는 보존한다. 데이터를 완전히 없애려면 먼저 `.ofbackup`을 별도 보관한 뒤 사용자가
직접 `%LOCALAPPDATA%\OfficeFlow` 폴더를 삭제해야 한다.
