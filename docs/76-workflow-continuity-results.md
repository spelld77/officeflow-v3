# 업무 흐름 연속성 구현·검증

2026-10-16. [75번 설계](75-workflow-continuity-design.md)의 U34/U35/U26을 개발 소스에 반영했다.
사용자 사용 확인·버전 변경·EXE/설치본/ZIP·커밋·GitHub 업로드는 이번 범위가 아니다.
이전 미커밋 작업을 보존하고 실제 사용자 DB/첨부/실행 폴더를 사용하거나 교체하지 않았다.

## 반영

- 탭별 선택 ID/원래 회차·화면 상단 항목/위치·조회량을 메모리에 기억한다. 정렬/필터/검색·날짜 조건이 맞는 경우에만 복귀한다.
  검색어는 계속 해제한다. 조회는 보기/그룹당 최대 500행이다. 새 입력/사용자 탐색/종료는 대기 중 복귀를 취소한다.
- 완료 요약 성공 안내만 `저장됨`/`편집 중 · 미저장`으로 변경했다. 실패·충돌 경고와 입력 보존은 유지한다.
- 우클릭 내일/날짜·시간 이동: 비모달 작은 창, 변경 전후 날짜/요일, 휠 방지/전체 시각 입력, 위험 날짜 확인을 재사용한다.
  기존 시각/기간/종일 유지, 일정 없음은 1일 종일 또는 시각 지정, 새 알림은 자동 추가하지 않는다.
- 반복 한 회차는 원래 식별자를 유지하고 effective 일정만 이동한다. 달력/오늘/하루·알림 미리보기/실행·저장된 알림 요약이 이를 공유한다.
  원래 날짜의 중복을 제거하고 다른 달에서 들어온 회차도 조회한다. 이미 발생한 상대 알림은 다시 복제하지 않는다.
  원래 날짜로 되돌릴 때도 명시적 회차 예외를 유지해 이미 울린 알림의 재발송을 막는다.
- 이동/알림 캐시/의미 있는 이력/요청 영수증은 기존 한 트랜잭션을 사용한다. 직접 지정 알림은 유지한다.
  과거 미발생 상대 알림·같은 규칙 회차 간 충돌·다른 창 수정은 저장하지 않고 입력을 보존한다.
- 현재 화면 유지, 지속 결과와 날짜 보기·마지막 한 건 되돌리기. 후속 수정/완료/삭제를 덮어쓰지 않는다.
  이동 직후 다른 수정이 끼거나 응답 유실 뒤 재시도해도 후속 상태를 되돌리기 승인값으로 사용하지 않도록 보완했다.
  긴 제목보다 이동 날짜를 먼저 표시하고, 일정 없는 상태로 되돌리면 날짜 보기 버튼을 비활성화한다.

## 검증 상태

최신 관련 35개와 최종 Windows 100/150/200% 각 38개가 통과했다.
Windows 검사는 작은 주 화면/이동 창·긴 제목보다 날짜 우선 표시·버튼 접근·밝은 배경과 어두운 기본 팔레트를 확인했다.
캡처 `artifacts/continuity-{main,move}-{False,True}-{1.0,1.5,2.0}.png`를 보존한다.

첫 전체 1,616개는 통과했다. 이후 경계 보완을 포함한 전체 재검증은 기존 첨부 화면 검사에서 대기가 길어져 중단했고
이 실행은 전체 통과로 세지 않는다. 해당 `test_document_paging_delete.py`는 분리하여 12개 통과(40.64초)를 확인했다.
원인이 새 기능이라고 단정하거나 지연 원인까지 규명했다고 하지 않는다. 지연된 첨부 화면 코드는 변경하지 않았다.

전체 실행을 시작한 뒤 반복을 일반 업무로 바꿀 때 과거 이동 기록이 일반 업무를 잘못 조회시키지 않도록
조회 조건 하나를 보완했고, 관련 36개를 별도 실행했다. 이 중 새 회귀 검사 1개를 포함한 최종 보고서의
`classname/name`을 대조한 **중복 제외 고유 검사 수는 1,628개**다. 단일 프로세스에서 1,628개를 한 번에 통과한 것으로 표기하지 않는다.
추가 반복 실행·배율·캡처 수를 고유 검사 수에 합산하지 않았다.

Ruff·mypy(소스 153개)·`git diff --check` 통과. 전체와 관련 성능 검사에서 기존 `record_property`/JUnit 형식 경고 1개가 있었으나 실패/오류는 없다.
상한 밖 복귀/그룹별 상한·검색/새 입력 우선, 저장 성공/실패, 원자적 롤백/재시도,
다른 창/동시 수정/응답 유실 뒤 안전한 되돌리기, 반복 원래/이동 월·오늘/하루·예정/실제 알림·이력 보존을 검증했다.

이번 실행 소유 `artifacts/qa-continuity-*` 합성 fixture 27개 폴더는 정확한 경로와 연결 대상이 소유 폴더 안인지 확인한 뒤 정리했다.
남은 이번 소유 fixture는 0개이며 검사 XML과 작은 화면 캡처는 보존했다. 큰 합성 파일의 논리 크기를 실제 확보한 디스크 공간으로 환산하지 않는다.

관련 검사는 합성 DB/첨부를 사용한다. 회사 보안 제품/실제 장기 운영 환경을 검증한 것으로 간주하지 않는다.
오프스크린 Qt는 이 PC의 한글 폰트를 제대로 표시하지 않아 화면 가독성 판정에 쓰지 않고 Windows native 캡처로 별도 확인한다.
DB0016·백업 v3를 유지하며 첨부 파일의 복사/삭제·보관·백업 계약을 변경하지 않았다.
반복 회차 이동은 앱 내부 일정/알림 기준이다. ICS는 기존 반복 템플릿/규칙을 내보내며 개별 회차 이동 예외 전송은 이번에 추가하지 않았다.

## 사용 확인 후: 날짜 이동 안내 자동 숨김

2026-10-16 사용자 지적에 따라 지속 하단 안내 계약을 변경했다. 75번 3.4절의 최신 규칙을 따른다.
이동 성공/재시도 성공 안내는 8초 후 자동으로 숨겨 본문 공간을 돌려준다. 탭/달력 전환·닫기·되돌리기·종료도 즉시 닫는다.
안내 종료와 함께 해당 안내의 되돌리기도 해제한다. 이동한 날짜는 DB에 그대로 남는다.
새 이동은 8초를 다시 시작하며 날짜 보기 진입 시 안내를 닫기 전에 목적 날짜를 캡처한다.
되돌리기 성공은 하단 영역을 즉시 제거하고 기존 상태 표시줄에 3초만 알린다. 실패는 경고를 자동으로 지우지 않는다.

최신 관련 63개(`artifacts/move-notice-gate.xml`)·Windows 100% 작은 창 27개(`artifacts/move-notice-native.xml`) 통과.
새 회귀 8개는 자동 만료/저장값 유지/본문 공간 복구, 탭·달력·닫기·되돌리기·종료, 목적 날짜 유지와 연속 이동 타이머 재시작을 확인한다.
테스트에서는 같은 타이머의 간격만 짧게 조정하며 실제 설정값 8초도 검사한다. 실패 경고의 타이머 중지도 확인했다.
`artifacts/move-notice-dismissed-1.0.png`로 안내가 없는 실제 Windows 화면을 확인했다. Ruff·mypy·차이 공백 검사 통과.
UI 안내 수명만 바꿨으므로 이번 후속에서는 전체 회귀나 150/200%를 다시 실행하지 않았다. 앞선 전체 수치를 이번 실행으로 재사용하지 않는다.
실사용 DB/실행 폴더·버전·EXE·ZIP·커밋·GitHub는 변경하지 않았다. 이번 합성 fixture만 정리하고 XML/캡처는 보존한다.
