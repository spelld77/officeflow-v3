# U36~U38 구현·검증 기록

작성일: 2026-10-26. 기준 공개 버전 3.0.13, 추가 소스 구현.
사용자 `구현과 테스트 실행해` 승인으로 80~82번 설계를 구현했다.
실사용 DB/첨부/실행 폴더, 버전, EXE/설치본/ZIP, 커밋/GitHub는 변경하지 않았다.

## 구현

- U36: 알림·완료 입력·업무/오늘 알림 메뉴·첨부 메타데이터·첨부 진행창·내보내기 선택창의 종료 후 삭제를 보완했다.
  이전 창의 종료 콜백이 새 알림창 포인터를 지우지 않게 했다. worker 종료 확인 뒤 소유자를 해제한다.
  숨김 주 화면 재조회 절감, 1/2/5/15/30/60초 유휴 점검, 새 파일 작업 때 깨우기를 추가했다.
  자기 프로세스/시스템 합계 숫자 관측은 재사용 worker 한 개, 최근 16개 sample, 1MiB × 3개 로그로 제한한다.
  메모리 압박 때 RAM 이미지 캐시와 대기 자동 썸네일을 줄이고 새 자동 백업만 보류한다.
  알림/직접 저장/수동 백업/진행 중 작업/디스크 보기 사본은 유지한다. 대기와 기존 백업 성공/실패 이력을 분리한다.
- U37: 검색 옆 최근 버튼, 고정 3/최근 5행(작은 화면 적응), 최대 20개 전체 목록과 기록 비우기.
  실제 업무 보기 진입만 기록한다. 기존 창/초안·검색/필터·원래 회차를 보존한다.
  ID/생성 시각/원래 회차/열람 시각만 bounded sidecar에 저장하며 업무 백업에서는 제외한다.
  복원 전 무효화, DB 파일 식별/ID 재사용 방어, 최신 쓰기·비우기 후 늦은 결과 폐기를 구현했다.
- U38: 완료일 기준 월별/전체 완료 기록, 반복 회차/전체 완료/완료일 미상 구분.
  SQL 집계 6개월과 최대 두 그룹 × 50행, keyset 페이지/이전 cursor 최대 20개, 빈 연도 건너뛰기.
  검색·상태·중요도·고정·첨부 조건을 집계와 행에 공유하고 원래 회차로 연다.
  숨긴 월의 행은 해제하고 복귀용 범위/선택/위치만 기억한다. 새 완료 화면의 선택/메뉴는 기존 평면 목록과 분리한다.
  작은 화면은 빠른 등록을 숨기며 상단 `+ 업무`로 등록한다. 내보내기는 기존 업무 단위임을 명시한다.

### native 수명·메모리 관측

Windows의 실제 show/exec/close 경로에서 업무 메뉴 100회·완료 입력 40회·알림 100회,
첨부 이름/메모 각각 40회·진행창 40회·ICS/업무 묶음 선택창 각각 40회를 검사했다.
최근 메뉴 100회·전체 창 40회 종료 뒤 객체 수와 늦은 콜백을 확인했다.

별도 알림 40회 × 4 block 시험의 마지막 3 block은 private/handle/GDI/USER가 각각 일정했다.
100% 예시: private 152,281,088 bytes, handles 1,215, GDI 15, USER 18.
200% 예시: private 153,104,384 bytes, handles 1,190, GDI 15, USER 16.
이 값은 시험 호스트의 Qt/캐시/할당자를 포함하며 제품 보통 메모리 사용량/장기 증가율 보장이 아니다.

초기 offscreen 시험에서 Python으로 재정의한 메뉴 exec→super 호출이 access violation로 끝났다.
시험 방식을 분리해 offscreen은 exec를 생략하고, native는 실제 QMenu.exec와 예약된 close로 검사했다.
native 100/150/200%는 통과했다. 79번의 이전 미측정 native 조기 종료 원인까지 같은 것이라고 단정하지 않는다.

최종 100% 반복 관측의 4개 block은 private 152,207,360 bytes / handles 1,211 / GDI 15 / USER 17로 일정했다.

### 완료 대량 조회

합성 업무 5,001개(일반 완료 5,000 + 반복 템플릿 1), 완료 기록 105,000건.
첫 완료 월 조회 0.1545초, 반환 50행. COUNT/MAX/월 경계/페이지는 SQL에서 처리한다.
EXPLAIN은 `ix_task_occurrences_completed` covering index 검색을 확인했다.

## 한계와 후속

- native 검사는 짧은 반복 시험이다. 회사 PC 실제 종료 원인, 6시간 유휴/알림 운영은 확인하지 않았다.
- 어두운 기본 팔레트 **주입**과 native 렌더링을 확인했으며 Windows OS 테마 자체를 바꾼 검사는 아니다.
- 모든 메모리 누수 없음/강제 종료 방지/종료 직전 경고를 보장하지 않는다. watchdog/자동 재시작은 추가하지 않았다.
- 사용자 사용 확인, 배포물 재생성·버전·커밋·업로드는 후속 요청 때 진행한다.

이번 요청에서 만든 합성 fixture 폴더 44개는 절대 경로/루트와 reparse point를 확인한 뒤 정리했다.
안쪽 junction 3개는 연결 자체만 먼저 제거했으며 XML·작은 PNG·대조 manifest와 기존 다른 산출물은 보존했다.
이번 소유 임시 시험 폴더의 잔여는 0개다.

후속 배포 승인으로 이 변경을 3.0.14에 포함한다. 새 버전/배포물 검사와 공개 결과는 [84번](84-release-checklist.md)을 따른다.
위의 "배포하지 않음"은 구현 검사 마감 시점의 기록이다.
