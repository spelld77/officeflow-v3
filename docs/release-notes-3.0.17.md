# OfficeFlow 3.0.17

## 첨부파일 끌어 복사

첨부 목록·썸네일에서 파일 하나 또는 Ctrl/Shift로 여러 파일을 선택하세요.
목록 위에 준비 완료가 표시되면 **탐색기 폴더·바탕화면으로 끌어 복사**할 수 있습니다.
준비 중 끌었다면 완료 후 다시 끄세요. 내부 첨부는 그대로 남습니다.

- 별도 사본을 전달하며 같은 이름은 번호로 구분합니다.
- 준비 시점의 저장 내용을 사용합니다. 외부 편집 후에는 선택을 해제하고 다시 선택하세요.
  편집기의 미저장 내용과 원본/보관본의 수정된 보기 사본은 자동으로 포함하지 않습니다.
- 한 번에 100개, 창별 사본은 1GiB/32배치까지입니다. 초과 시 기존 저장 기능을 사용하세요.
- 내부로 다시 놓으면 중복 첨부하지 않습니다. 대상 폴더의 동명 파일 처리·복사 진행·취소는 탐색기가 담당합니다.
- 메일·메신저 드래그는 이번 지원 범위가 아닙니다.

사본은 OS 임시 폴더의 별도 소유 세션에 저장됩니다. 마지막 전달/생성 후 24시간 경과하고 소유 잠금이
해제된 세션만 다음 준비 작업에서 정리합니다. 앱을 사용하지 않는 동안 즉시 삭제되지는 않습니다.
기존 업무 자료·DB/첨부·백업에는 이 사본을 추가하지 않습니다.

## 업데이트

기존 앱을 사용하면서 새 ZIP을 별도 폴더에 준비할 수 있습니다.
**새 버전을 실행하기 직전**, 기존 앱에서 전체 백업을 만들고 트레이 메뉴로 완전히 종료하세요.
구버전과 신버전을 같은 자료로 동시에 실행하지 않습니다.

1. `OfficeFlow-Python-3.0.17.zip`을 별도 폴더에 풉니다.
2. `setup-officeflow-python.cmd`를 한 번 실행합니다.
3. `run-officeflow-python.cmd`로 실행합니다. 기존 `%LOCALAPPDATA%\OfficeFlow` 자료를 사용합니다.
   DB/첨부를 새 프로그램 폴더로 복사하지 않습니다.

DB0017·전체 백업 v3를 유지하며 3.0.14 이상에서 새 DB 이행은 없습니다.
Python ZIP에는 Python/실행 라이브러리가 포함되지 않으므로 최초 setup에는 인터넷 연결이 필요합니다.
EXE·설치본·Windows ZIP은 만들지 않습니다. GitHub의 Source code ZIP 대신
릴리스 자산의 **OfficeFlow-Python-3.0.17.zip**을 받으세요.

## 검증과 한계

관련 격리 검사 고유 81개가 통과했습니다. QDrag.exec 대조와 마우스 임계값 검사로
선택한 사본 URL·Copy 전달 경계를 확인했습니다. **실제 탐색기/바탕화면 드롭과 회사 DRM/보안 환경은 미검증**입니다.
기존 응답 없음의 native 잠금 원인은 미확정이며 모든 멈춤을 해결했다고 보장하지 않습니다.
실사용 확인·장시간/대용량 시험·전체 제품 회귀는 별도입니다.
상세 결과는 [92번](92-attachment-drag-copy-results.md), 배포 검증/공개 결과는 [93번](93-release-checklist.md)을 따릅니다.
