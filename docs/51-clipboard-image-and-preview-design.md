# 클립보드 이미지 첨부·미리보기 상세설계

2026-10-10 사용자 승인. U20/U21 구현 전 설계이며 기존 24번 보존 계약을 유지한다.
기존 미커밋 변경은 보존하며 DB 이행·버전·배포·Git 작업은 하지 않는다.

2026-10-10 후속 검토: 첨부 찾기의 주 동선은 목록/썸네일 전환으로 개선하는
[53번 설계](53-attachment-thumbnail-design.md)를 작성했다. 후속 설계만 완료했으며,
아래 별도 미리보기는 아직 현재 소스의 동작이다. U20 입력/파일 안전 계약은 유지한다.

## 입력과 이름

- 새 업무/업무 수정과 기존 첨부에 명시적 `클립보드 이미지 추가`를 제공한다.
  클립보드의 이미지 데이터만 읽고 텍스트/URL/파일 목록을 이미지로 해석하지 않는다.
  감시/자동 첨부/전역 붙여넣기/클립보드 변경은 하지 않는다.
- 누른 시점의 독립 이미지 사본을 확보한다. 이후 클립보드 변경은 대기 사진에 영향을 주지 않는다.
  실제 캡처 시각을 추측하지 않고 추가 시각으로 이름을 정한다.
- 기본 `캡처_yyyy-MM-dd_HH-mm-ss.png`, 같은 초 이름은 번호로 구분한다.
  선택한 대기 사진의 이름을 수정할 수 있다. PNG 확장자는 유지하고 경로/금지 이름은 기존 검증을 사용한다.
- 버튼과 개수, 선택 사진의 작은 미리보기/이름/제거/확대 보기를 제공한다.
  기본 Tab 업무 입력 동선은 유지하고 사진 기능은 명시적 마우스 접근을 중심으로 한다.
  최대 대기 8장, 한 장 16M픽셀·64MiB, 합계 128MiB로 제한한다. 임의 다운샘플로 원본을 대체하지 않는다.

## 저장과 실패

- 저장 전 사진은 한 입력창의 메모리에만 있다. 취소/종료하면 미저장 사진은 버린다.
  미저장 초안의 재시작 복원은 이번 범위가 아니며 UI에 저장 전 상태를 명시한다.
- 제목/일정/알림 검증 후 기존 업무 저장 트랜잭션을 실행한다. 성공한 업무 ID를 고정한다.
  그 뒤 worker에서 사진별 임시 PNG를 생성해 기존 AttachmentService.attach로 일반 첨부 등록한다.
  원본·보관본 자동 지정이나 이미지 BLOB 저장은 하지 않는다.
- 등록 성공한 사진만 대기 목록에서 제거한다. 실패/미처리는 남기고 같은 업무에 재시도한다.
  업무 정보는 이미 저장됐다고 명시하고 잠가서 새 업무/알림/이력을 중복 저장하지 않는다.
  중복 내용 거절은 이미 첨부됨으로 안내하고 다시 만들지 않는다.
  여러 긴 오류가 창을 밀어내지 않도록 짧은 첫 오류와 추가 건수만 표시하고 전체 오류는 tooltip에 둔다.
- PNG 인코딩·복사·해시는 worker에서 진행한다. 대기 중 버튼/이름을 잠그되 알림/주 창은 막지 않는다.
  종료는 취소 요청 후 기존 finish_thread 방식으로 worker 완료까지 소유권을 유지한다.
- 임시 PNG는 worker가 만든 전용 시스템 임시 디렉터리 안에서만 생성하고 정상 성공/실패/취소 시 정리한다.
  강제 프로세스 종료/정전 시 OS 임시 파일이 남을 수 있다. 이를 등록된 첨부로 간주하거나 사용자 폴더를 청소하지 않는다.
  기존 첨부 등록의 파일 공개/DB 실패 정리 계약을 재사용하고 전체 원자 저장이라고 주장하지 않는다.

## 미리보기

- 선택 이미지의 `미리보기`는 별도 비모달 읽기 전용 창이다. 목록 높이를 줄이지 않는다.
  창이 열려 있으면 단일 선택 변경에 맞춰 갱신한다. 여러 선택/선택 해제/비이미지는 이전 사진을 지운다.
  기존 열기/더블클릭의 외부 편집기 동작은 유지한다.
- PNG/JPEG/BMP만 지원한다. 내용 형식도 확인하고 SVG/HTML/PDF/문서/애니메이션 전체 재생은 제외한다.
  파일 크기 64MiB·16M픽셀을 사전에 확인하고 미리보기는 최대 1200x900으로 축소한다.
  형식에 따라 원본 decode가 필요하므로 축소 크기만으로 메모리 안전을 주장하지 않는다.
- 서비스에서 접근 예약·보호 읽기 핸들을 확보한다. 고정 첨부는 같은 핸들에서 크기/해시 검증 후 읽는다.
  관리 경로를 외부에 열지 않고 보기 사본/작업본/보관본/썸네일 디스크 캐시를 만들지 않는다.
- 파일 읽기/검증/decode는 worker 하나로 제한한다. 빠른 선택 전환은 이전 요청을 취소하고 최신 요청만 유지한다.
  세대 토큰으로 늦은 결과를 버린다. GUI에서만 pixmap을 생성한다. 창 닫기·소유창 종료는 worker를 안전하게 기다린다.
- 현재 디스크에 저장된 이미지를 보여준다. 외부 편집기의 미저장 버퍼는 표시하지 않는다.
  누락/권한/잠금/변경된 원본/손상/크기 제한은 창 안에 안내하고 파일/DB는 바꾸지 않는다.

## 검증

이름·확장자·금지 이름, 이미지 없는 클립보드/변경/크기·개수 상한,
신규 업무+사진/취소/실패·부분 성공·재시도 시 업무/첨부 중복 방지,
PNG 인코딩 실패/파일·DB 오류/복사 취소/닫기·알림 독립 조작,
기존 첨부의 일반/고정 읽기·보관 불변·백업·외부 저장,
미리보기 형식/손상/누락/메모리 상한/빠른 선택/창 재사용/종료,
좁은 창·밝음/어둠 제어 팔레트·100/150/200% 렌더링과 관련 회귀를 격리 자료로 검사한다.
