# OfficeFlow 3.0.14

## 바뀐 점

- 닫힌 알림·완료 입력·메뉴·첨부 입력/진행창·내보내기 선택창의 자원을 정리합니다.
- 주 창 숨김 중 불필요한 재조회를 줄이고 유휴 파일 점검 간격을 조절합니다.
- 검색 옆 **최근**에서 고정 업무와 최근 본 업무를 바로 엽니다. 최대 20개 기록과 비우기를 제공합니다.
- **완료**에 월별 묶음과 전체 목록을 제공합니다. 완료한 반복 회차·전체 완료·완료일 미상을 구분합니다.
- 메모리 여유가 부족하면 이미지 메모리 캐시를 줄이고 새 자동 백업만 기다립니다. 알림·직접 저장·수동 백업·진행 중 작업은 유지합니다.
- 자기 프로세스/시스템 합계 숫자를 제한된 자원 로그에 기록합니다. 업무 내용·파일명·다른 앱 목록은 수집하지 않습니다.

## 업데이트

1. 기존 OfficeFlow에서 전체 백업을 만들고 트레이까지 완전히 종료합니다.
2. 설치형은 새 Setup을 사용합니다. Python형은 **OfficeFlow-Python-3.0.14.zip**을 별도 폴더에 풀고 `setup-officeflow-python.cmd`를 한 번 실행합니다.
3. 기존과 같은 데이터 위치로 실행합니다. DB/첨부를 새 프로그램 폴더에 복사할 필요는 없습니다.

첫 실행에서 DB 보호 사본을 만든 뒤 **0017 완료 조회 색인만 추가**합니다. 기존 업무·첨부 내용은 바꾸지 않으며 전체 백업은 v3입니다.
**0017 DB/백업은 3.0.14 이상이 필요합니다.** 이전 실행기로 돌아갈 때는 업데이트 전 자료를 사용하세요.
최근 기록은 이 PC의 작은 조회 정보로 업무 백업에서 제외하며, 복원하면 비웁니다.

## 검증과 한계

개발 검사는 분리 실행 보고서를 대조해 고유 1,683개 통과를 확인했습니다. 대표 Windows 100/150/200% 화면과 native 반복 종료를 별도 검사했습니다.
회사 PC의 간헐적 종료 원인과 장시간 운영은 추가 확인이 필요합니다. 긴 공유 Qt 검사에서 대기가 있어 분리 검증했으며 원인을 모두 해결했다고 주장하지 않습니다.
강제 종료 방지/종료 직전 경고를 보장하지 않습니다. 반복 회차 이동 예외의 ICS 미반영은 유지됩니다.
