# OfficeFlow 3.0.13

2026-10-17. 하루 일정 파악과 입력·등록·날짜 이동 흐름을 개선한 정식 업데이트다.

## 주요 변경

- 달력의 하루 보기: 업무/알림 두 열 시간표, 종일 일정, 중요도와 처리 상태, 겹침 목록, 이전/이후 화면 밖 건수와 이동.
- 업무를 고르지 않아도 날짜별 전체 알림과 처리 이력을 조회한다. 매시 업무기록 알림은 별도다.
- 업무 우클릭의 내일로 이동/날짜·시간 변경. 반복은 선택한 한 회차만 이동하며 이미 울린 알림을 복제하지 않는다.
- 날짜 이동 결과·날짜 보기·되돌리기는 8초 후 숨기고 본문 공간을 돌려준다. 탭 전환 때도 즉시 숨긴다.
- 예정 빠른 등록은 내일 종일·알림 없음으로 등록하고 예정에 머문다. 저장 결과와 현재 목록 밖 여부를 표시한다.
- 같은 실행 중 탭별 선택/목록 위치를 기억한다(보기/그룹당 최대 500행). 검색어는 탭 이동 시 종전처럼 해제한다.
- 날짜 입력의 휠 오변경 방지와 연도/먼 날짜 확인. 일반 날짜에는 불필요한 경고를 표시하지 않는다.
- 완료 요약과 완료 상태의 동시 저장 수정. 저장 실패 시 입력을 보존한다. 업무 보기의 요약 저장 성공은 확인창 대신 한 줄로 표시한다.
- 왼쪽 메뉴 정돈과 관리 메뉴 통합, 달력 오늘/이전/다음 버튼과 종일 두 번째 줄 잘림·밝은 스크롤바·시간 버튼 개선.

## 업데이트

먼저 전체 백업을 만들고 트레이까지 종료한다.
Python 사용자는 `OfficeFlow-Python-3.0.13.zip`을 새 폴더에 풀어
`setup-officeflow-python.cmd`를 한 번 실행한 뒤 `run-officeflow-python.cmd`로 시작한다.
같은 기본/직접 지정 데이터 경로를 쓰면 DB·첨부를 복사할 필요가 없다.
Python 3.12 64비트와 실행 라이브러리가 필요하며 Python/wheel은 이번 ZIP에 포함하지 않는다.
최초 환경 구성에는 인터넷이 필요할 수 있다.

설치형은 `OfficeFlow-3.0.13-Setup.exe`, EXE 폴더형은 `OfficeFlow-3.0.13-Windows.zip` 전체를 사용한다.
보안 정책을 우회하거나 실사용 폴더를 자동 교체하지 않는다. 기존 3.0.12 공개 릴리스는 유지한다.

## 호환과 제한

- DB0016·전체 백업 v3 유지. 3.0.10~3.0.12에서 새 DB 이행은 없다. 기존 업무·첨부·설정은 보존한다.
- 0016 DB/백업은 3.0.10 이상에서 사용하며 구버전 복귀에는 업데이트 전 자료를 권장한다.
- 반복 회차 이동 예외는 현재 ICS 내보내기에 반영되지 않는다. 원본 반복 규칙을 내보내는 기존 방식이다.
- 탭 위치는 재시작 후 복원하지 않으며 날짜·정렬·필터 변경 또는 복원 상한 밖에서는 정확한 이전 위치가 보장되지 않는다.
- 실제 회사 DRM/문서 편집기·장기간 운영·OS 테마/DPI 실시간 전환은 별도 확인 대상이다.

검증·배포 상태는 [릴리스 체크리스트](78-release-checklist.md)를 따른다.
