## 릴리스 산출물

- `dist/installer/OfficeFlow-3.0.0-Setup.exe`
- `dist/OfficeFlow/` 휴대용 폴더형 실행본
- `dist/SHA256SUMS.txt`
- `dist/release-manifest.json`

코드 서명이나 별도 OS 실기기 확인이 필요한 외부 공개 배포에서는 마지막 두 미완료 항목을
완료한 뒤 태그를 만든다. 개인 PC 설치용 3.0.0 빌드는 나머지 게이트를 충족한다.
