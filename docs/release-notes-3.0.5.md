# OfficeFlow 3.0.5

사용이 끝난 **OfficeFlow 2.6 데이터 가져오기** 기능을 제거하고 설치형·Python 배포본에 반영했습니다.
이미 이전한 업무·업무일지·메모·첨부파일은 그대로 사용할 수 있습니다.

## 주요 변경

- 데이터 관리의 가져오기 메뉴, 검사·미리보기·변환기와 관련 전용 테스트를 제거했습니다.
- 도움말과 데이터 관리 안내를 현재 기능에 맞게 정리했습니다.
- 새 실행에서 가져오기 보고서 폴더를 만들지 않습니다. 이미 저장된 보고서·원본 안전 사본은 자동 삭제하지 않습니다.
- 기존 원본 ID와 가져오기 표식은 호환용 정보로 보존합니다. DB 스키마·데이터 경로를 변경하거나 다시 변환하지 않습니다.
- DB 업그레이드·첨부 검색·백업·예약 복원·매시 알림 등 기존 기능은 유지합니다.

이 버전부터 2.6 원본 DB를 새로 가져올 수 없습니다. 이미 v3로 이전했다면 별도 작업이 필요 없으며,
PC를 옮길 때는 v3의 `.ofbackup` 백업·복원을 사용하십시오.

## Python 사용자 업데이트

1. 기존 OfficeFlow의 트레이 메뉴에서 `완전히 종료`하고 중요한 데이터는 수동 백업합니다.
2. `OfficeFlow-Python-3.0.5.zip`을 **새 폴더**에 압축 해제합니다. 기존 폴더에 덮어씌우면 삭제된 옛 코드가 남을 수 있습니다.
3. `setup-officeflow-python.cmd`를 한 번 실행합니다. Python 3.12 64비트가 필요합니다.
4. `run-officeflow-python.cmd`로 실행합니다. 기존 `%LOCALAPPDATA%\OfficeFlow`의 DB·첨부·설정을 그대로 사용합니다.
5. 새 폴더의 실행기로 바로가기를 바꾸고, Windows 자동 시작을 사용한다면 설정을 껐다가 켭니다.

DB를 배포 폴더에 복사하거나 테스트용 `.local-data`로 옮길 필요가 없습니다.
설치형은 새 Setup.exe를 기존 버전 위에 설치할 수 있습니다. 회사 보안 정책 때문에 설치형을
쓸 수 없는 사용자는 계속 Python 모드를 사용하면 됩니다. 3.0.4 → 3.0.5는 DB 스키마 변경이 없습니다.

## 다운로드 파일

- `OfficeFlow-Python-3.0.5.zip`: Python 실행용 소스·실행기·설정 스크립트·도움말. 최초 설정에 인터넷이 필요합니다.
- `OfficeFlow-3.0.5-Setup.exe`: Windows 10/11 x64 설치형.
- `OfficeFlow-Python-3.0.5.zip.sha256.txt`: Python ZIP의 SHA-256.
- `SHA256SUMS.txt`, `release-manifest.json`: 배포 파일의 체크섬·버전·크기 목록.

기존 3.0.0~3.0.4 릴리스와 다운로드 파일은 유지합니다.
