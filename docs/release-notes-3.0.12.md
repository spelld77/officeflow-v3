# OfficeFlow 3.0.12

업무를 열어 내용을 확인하는 흐름과 첨부파일 입력·이미지 호환, 달력 조회를 개선했습니다.

## 주요 변경

- 목록·달력의 더블클릭/Enter를 `업무 보기`로 통일. 설명·일정·상태를 확인하고 `수정`에서 편집합니다.
- 설명은 필요한 만큼 펼쳐 보고 복사할 수 있습니다. 같은 업무/원래 회차 창과 미저장 기록 초안을 유지합니다.
- 목록의 첨부 표시를 클릭하면 첨부 탭으로 바로 이동합니다. 창을 만들 때 작은 설명/안내 창이 잠깐 뜨던 현상을 제거했습니다.
- WebP 및 PNG 이름의 실제 WebP를 썸네일/확대로 표시합니다. 원본 변환 없이 기존 메모리·픽셀 상한과 고정 내용 검증을 유지합니다.
- 이미지 형식 미지원·크기·누락·읽기 실패와 실제 고정 내용 불일치를 구분합니다.
- 이름 변경은 전체 파일명도 입력할 수 있고 같은 확장자 중복을 방지합니다. 완성 이름은 한 줄, 전체 이름은 도움말로 확인합니다.
- 파일 추가의 마지막 선택 폴더 기억과 첨부 드롭/파일 추가 버튼을 보완했습니다.
- 달력은 미완료를 먼저 표시하고 숨은 미완료 수를 강조합니다. 알림 확인을 업무 완료로 취급하지 않습니다.
- 날짜 도움말에 시작/종료까지의 달력 날짜 차이를 표시하며 알림 건수 클릭 뒤 해당 목록으로 스크롤합니다.

## 호환과 업데이트

DB0016·전체 백업 v3를 유지합니다. 3.0.10/3.0.11에서 추가 DB 이행은 없고 업무·일지·첨부 내용/경로를 변경하지 않습니다.
더 오래된 DB는 보호 사본 후 필요한 이행을 순서대로 적용하므로 업데이트 전 전체 백업을 권장합니다.
업무 날짜 간편 변경(U26)·내부 장기 자료 정리는 이번 버전에 포함하지 않았습니다.

Python 사용자는 기존 프로그램을 트레이까지 완전히 종료하고 새 ZIP을 별도 폴더에 풀어
`setup-officeflow-python.cmd`를 한 번 실행한 뒤 `run-officeflow-python.cmd`로 시작합니다.
같은 `%LOCALAPPDATA%\OfficeFlow`를 사용하면 DB와 첨부를 복사할 필요가 없습니다.
직접 지정한 `OFFICEFLOW_DATA_DIR`이 있으면 새 실행에서도 같은 경로를 유지하세요.
개발용 `run-officeflow-dev.cmd`는 별도 `.local-data`를 사용하므로 실사용 실행기와 구분합니다.
Python ZIP에는 Python 자체나 오프라인 wheel이 없으며 최초 환경 구성에 인터넷 연결이 필요합니다.
설치형·Windows ZIP도 기존 프로그램을 완전히 종료한 뒤 업데이트합니다. `_internal`을 포함한 EXE 폴더 전체가 필요합니다.

## 배포 파일

- `OfficeFlow-3.0.12-Setup.exe`: Windows 설치/업데이트.
- `OfficeFlow-3.0.12-Windows.zip`: 전체 EXE 폴더.
- `OfficeFlow-Python-3.0.12.zip`: Python 실행용 소스·실행기·사용자 안내.
- `OfficeFlow-Python-3.0.12.zip.sha256.txt`: Python ZIP 체크섬.
- `SHA256SUMS.txt`: 배포 파일 해시 목록.
- `release-manifest.json`: 버전·경로·크기·SHA-256 목록.

회사 보안/DRM·문서 편집기는 별도 환경 확인이 필요합니다. 실사용 실행 폴더는 자동 교체하지 않습니다.
