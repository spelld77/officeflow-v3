# OfficeFlow 3.0.2

OfficeFlow 3.0.2는 업무 탐색, 캘린더, 업무일지와 첨부파일 사용성을 개선한 유지보수 릴리스다.

## 주요 변경

- 업무일지 검색은 기본적으로 전체 기간을 대상으로 하고, 필요할 때만 기간을 제한한다.
- 업무일지 목록이 새로고침되어도 선택한 업무의 상세 내용을 유지한다.
- 시작 시 비정상 종료 안내를 먼저 닫은 후 미처리 알림을 표시해 창 우선순위 충돌을 막았다.
- 캘린더 하단에 선택한 날짜의 일정을 기본 3개까지 보여주고, 목록 확대와 드래그 분할선을 제공한다.
- 업무 검색 중임을 눈에 띄게 표시하고, 업무 메뉴로 이동하면 이전 검색어를 자동으로 해제한다.
- 첨부파일 여러 개를 한번에 선택하거나 Windows 탐색기에서 드래그앤드롭할 수 있다.
- 일부 첨부파일이 중복 또는 오류로 실패해도 나머지 파일을 계속 처리한다.

## 설치형

`OfficeFlow-3.0.2-Setup.exe`를 실행한다. 관리자 권한은 필요하지 않다. 기존 3.0.x 위에
설치하면 프로그램 파일만 갱신하며 `%LOCALAPPDATA%\OfficeFlow`의 사용자 데이터는
유지한다. 업데이트 전에는 기존 OfficeFlow를 완전히 종료하고 수동 백업을 만드는 것을 권장한다.

## Python형

`OfficeFlow-Python-3.0.2.zip`을 별도 폴더에 압축 해제한다. Python 3.12 64비트를 설치한 뒤
최초 한 번 `setup-officeflow-python.cmd`를 실행하고, 이후 `run-officeflow-python.cmd`로 실행한다.

설치형과 Python형을 동시에 실행하지 않는다. 실행 방식을 바꿀 때는 기존 OfficeFlow를
트레이에서 완전히 종료한다.
