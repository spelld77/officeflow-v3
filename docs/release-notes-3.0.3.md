# OfficeFlow 3.0.3

OfficeFlow 3.0.3은 첨부파일을 원래 파일명으로 찾고 바로 여는 기능을 추가한 릴리스다.

## 주요 변경

- 상단 `첨부파일` 검색 모드에서 완료·보관 업무를 포함한 전체 기간 파일을 찾는다.
- 파일명 일부를 2글자 이상 입력하며 여러 단어는 같은 파일명에서 모두 일치해야 한다.
  문서 본문·Excel 셀·이미지 OCR은 검색하지 않는다.
- 파일 종류·첨부일·휴지통·정리 대기 포함 조건을 지정할 수 있다.
- 검색 결과에서 파일 열기, 연결 업무 확인, 첨부 관리가 가능하다.
- 업무·캘린더·업무일지 검색에도 파일명 조건과 일치 위치 표시를 추가했다.
- 검색과 첨부 관리 중 알림을 함께 처리할 수 있으며 종료 중 첨부 복사를 안전하게 취소한다.
- 작은 창의 메뉴 잘림, Enter 단축키 충돌, 빈 결과의 동작 버튼 상태를 보완했다.
- 기존 DB에 검색 색인을 추가하기 전 보호 사본·디스크 공간을 확인하고 준비 상태를 표시한다.

## Python형 업데이트 (기존 Python 사용자 권장)

1. 기존 OfficeFlow에서 수동 `.ofbackup`을 만들고 트레이에서 완전히 종료한다.
2. `OfficeFlow-Python-3.0.3.zip`을 새 폴더에 압축 해제한다.
3. Python 3.12 64비트가 있는 PC에서 `setup-officeflow-python.cmd`를 한 번 실행한다.
4. `run-officeflow-python.cmd`로 실행한다. 자동 시작을 쓰면 새 경로에서 설정을 껐다가 켠다.

이전 버전과 동일한 `%LOCALAPPDATA%\OfficeFlow`의 DB·첨부·설정을 사용한다. 배포 폴더에
DB만 복사하거나 첨부를 옮길 필요는 없다. 사용자 지정 데이터 경로를 쓰는 경우 동일 경로를
유지한다. 설치형과 Python형을 동시에 실행하지 않는다.

첫 실행에서 `data/schema-backups`에 DB 보호 사본을 만들고 검색 색인을 준비한다.
보호 사본은 DB만 포함하므로 첨부까지 포함하는 `.ofbackup` 전체 백업을 대체하지 않는다.
새 스키마에서 구버전 실행은 검증하지 않았으므로 임의로 다운그레이드하지 않는다.

## 설치형

`OfficeFlow-3.0.3-Setup.exe`를 실행한다. 기존 사용자 데이터는 유지한다.
코드 서명은 적용되지 않았으므로 회사 보안 정책에서 실행 파일을 제한하면 Python형을 사용한다.
Python형도 조직 보안 정책을 우회하거나 실행 허용을 보장하는 방식은 아니다.

## 검증

- 전체 자동 테스트 265개 통과, 코드 커버리지 83%, Ruff·mypy strict 통과.
- 150%·200% 배율에서 첨부 검색 UI 각 15개 테스트 통과.
- 기존 DB 업그레이드, 예전/최신 백업 복원, v2.6 가져오기와 첨부 검색 회귀 확인.
- 업무 5천 건·첨부 5만 건 합성 데이터에서 파일 검색 p95 0.64~10.45ms 측정.
  이 개발 PC의 쿼리 시간이며 디바운스·렌더링 및 다른 PC 성능은 포함하지 않는다.

설치/업그레이드/제거와 배포 ZIP 검증 결과는 릴리스 체크리스트에 기록한다.
첨부 실물의 OS 연결 프로그램 실행과 회사 보안 제품의 허용 여부는 사용 PC에서 확인해야 한다.

## 다운로드 파일

- `OfficeFlow-3.0.3-Setup.exe`: Windows 설치형.
- `OfficeFlow-Python-3.0.3.zip`: Python 3.12 실행용 배포본.
- `OfficeFlow-Python-3.0.3.zip.sha256.txt`: Python ZIP의 SHA-256.
- `SHA256SUMS.txt`: 배포 파일의 SHA-256 목록.
- `release-manifest.json`: 버전·빌드 시각·파일 크기·체크섬 명세.

GitHub가 자동 제공하는 `Source code` ZIP은 실행 라이브러리를 포함한 Python 배포 ZIP과 다르다.
