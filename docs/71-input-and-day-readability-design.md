# 남은 입력·하루 보기 가독성 보완 상세설계

2026-10-16. 사용자 `이야기한것중에 아직 완료안된것 설계하고 개선해` 요청.
69/70번의 미커밋 구현·하루 시간 탐색을 보존하고 아래 미완료 후보를 구현·검증한다.
이 문서는 구현 전 기준이며 실제 검사 결과는 72번에 별도로 기록한다.

## 1. 범위와 유지할 계약

등록/수정 버튼 크기·하단 여백, 날짜 안내의 공간/주의 강조, 하루 중요도/상태 표시, 관리의 중복 점만 보완한다.
24시간 시간축·탐색·조회 상한·회차 식별자·업무 완료와 알림 확인의 구분은 유지한다.
DB/알림 예약/첨부 보존·사용자 자료·버전·EXE/설치/ZIP·커밋·GitHub는 변경하지 않는다.

## 2. 등록/수정 화면

- 저장/취소는 같은 높이(최소 40 DIP)·충분한 글자 폭(최소 72 DIP)으로 맞추고 좌우 22 DIP 여백을 둔다.
- 시간 +/-는 고정 32 DIP를 제거한다. 최소 36 DIP와 글자에 맞는 힌트·축소한 내부 패딩을 사용한다.
  공통 TimeInput을 사용하는 알림 추가/수정에도 반영하며 시간 입력/탭/휠·날짜 넘김 정책은 유지한다.
- 알림 설정 버튼은 줄어들지 않게 확보한다. 본문은 위부터 배치하고 남는 공간을 안내 한 줄에 분배하지 않는다.
- 평범한 날짜 변경/내일 안내는 없앤다. 날짜·요일 자체는 입력칸에 계속 표시한다.
- 위험 날짜는 해당 날짜 칸의 주황 테두리/옅은 배경과 바로 아래 한 줄 `주의 · 연도 변경: 2026 → 2027` 등으로 표시한다.
  전체 이전/이후 날짜·요일은 도움말과 저장 확인에 남긴다. 경고가 없어지면 배경/공간도 복원한다.
  새 경고가 생긴 행은 스크롤 끝에 문구가 잘리지 않도록 한 번 보여주며, 같은 경고 갱신으로 계속 이동하지 않는다.
  실제 입력 오류의 빨간 표시가 주의 표시보다 우선하며 오류를 해소하면 해당 날짜의 주의 표시로 돌아간다.
- 기존 기준: 월일 그대로 연도만 변경, 180일 이상 큰 이동, 새 업무/알림의 현재 대비 1년 초과 날짜.
  큰 이동은 같은 연도에서도 적용한다. 정상 연말/연초 단기 이동·기존 장기 업무 제목 수정은 경고하지 않는다.
  달력에서 명시적으로 고른 최초 먼 날짜는 주의 표시는 하지만 새 변경이 아니므로 강제 재확인하지 않는다.
- 종료/반복 날짜도 같은 공통 표시를 사용한다. 접힌 추가 설정에 위험 날짜가 있으면 체크 항목에 `날짜 확인`을 표시한다.
- 직접 지정 알림의 날짜 주의/일정 변경 후 시각 유지 안내는 알림 행 아래 한 줄에 모은다. 일정 아래 별도 안내 구역은 제거한다.
- 알림 추가/수정의 직접 날짜 입력도 같은 강조를 사용한다. 저장 확인은 소유 업무 최종 저장/단독 설정 저장 경계를 유지한다.
  확인 중 수정·실패 시 입력 보존·승인된 초안 재검증 계약을 유지하고 날짜를 몰래 보정하지 않는다.

## 3. 하루 보기

- 일정의 옅은 파랑/알림의 옅은 주황 배경은 유지한다. 일정 왼쪽에 월 달력과 동일한 중요도 띠를 추가한다.
  보통 파랑/관심 초록/중요 주황/긴급 빨강, 완료·취소·보관은 회색. 중요도 이름은 도움말에도 표시한다.
- 일정 카드·종일·일정 목록·묶음 목록·선택 상세에 진행/대기/완료/취소/보관을 일관되게 표시한다.
  반복은 템플릿 상태가 아니라 원래 회차 투영 상태를 사용한다. 보관을 취소라고 표시하지 않는다.
- 짧은 카드에도 상태를 그린다. 상태는 작은 오른쪽 표식으로 확보하고 제목만 줄인다.
  매우 좁으면 상태를 우선하고 제목/시각은 도움말·선택 상세로 확인한다. 종료 없는 일정의 실제 종료를 만들지 않는다.
- 알림 카드는 예정/재알림/미확인/확인 필요를 표시한다. 업무 진행 상태로 알림 상태를 대체하지 않는다.
  확인함/대기 처리/완료 처리/업무 완료 등의 이력은 기존 `처리 이력 보기`에 그대로 둔다.
- 여러 항목의 묶음은 단일 업무의 상태/중요도처럼 칠하지 않는다. `N건/개`를 표시하고 전체 목록에서 각각 확인한다.
- 종일/일정 목록에도 중요도 색 표식과 상태를 함께 제공하며 색만으로 의미를 전달하지 않는다.
  조회·선택·표시만 바꾸고 확인/완료 처리는 발생시키지 않는다.

## 4. 관리 메뉴

표기는 `관리`만 남긴다. 기존 QMenu 화살표로 펼침을 알리고 점/별도 화살표 문자를 덧붙이지 않는다.
하위 데이터 관리/설정/도움말·키보드 접근·좁은 사이드바·현재 선택 유지 동작은 바꾸지 않는다.
