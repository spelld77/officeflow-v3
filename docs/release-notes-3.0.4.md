# OfficeFlow 3.0.4

인사랑의 시간대별 업무기록을 잊지 않도록 독립적인 **매시 알림**을 추가했습니다.
인사랑 출근·업무기록은 직접 해야 하며, 기록 전송이나 초과근무 인정 확인 기능은 아닙니다.

## 주요 변경

- 실제 실행마다 자동 ON, 기본 매시 35분. 대상 시간에 시작하면 현재 구간을 한 번 바로 안내합니다.
- 평일 09~18시 제외, 주말 하루 전체. 평일 공휴일 출근은 `오늘 휴일근무`로 해당 날짜만 적용합니다.
- 08시 전부터 켜둔 흐름/전날부터 ON인 실행은 08시까지 자동 연속 안내합니다. 평일 08시 이후 첫 실행은 아침 안내를 생략합니다.
- 실제 조기출근·기록 후 앱만 늦게 켰다면 `오늘 08시 알림 받기`를 사용합니다.
- 같은 구간의 건너뛰기/취소·닫기·5분 뒤 알림, 이번 실행 동안 끄기. 다음 실제 실행에는 다시 켜집니다.
- 한 개의 비차단 최상위 알림창과 짧은 `다음 20:35` / `재알림 19:45` 상태 표시.
- `설정 → 매시 알림 설정...`에서 문구·분·평일 제외 시간, 추가 제외 시간·소리를 조정합니다.
- `늦게 켜도 08시 알림 받기` 옵션은 기본 꺼짐이며, 범용 알림에 필요할 때만 켭니다.
- 일반 설정창도 비차단으로 열고 설정 저장 실패가 종료 정리를 막지 않도록 보완했습니다.

업무에 연결된 기존 알림은 매시 알림의 켜짐/꺼짐과 독립적으로 작동합니다.
절전 복귀 시 현재 구간만 안내하고 지난 여러 시간의 알림을 한꺼번에 띄우지 않습니다.
PC/프로그램 종료·강제 종료 중에는 알릴 수 없고 Windows 보안 화면·독점 전체화면의 위 표시는 보장하지 않습니다.

## Python 사용자 업데이트

1. 기존 OfficeFlow의 트레이 메뉴에서 `완전히 종료`합니다. 중요한 데이터는 수동 백업을 권장합니다.
2. `OfficeFlow-Python-3.0.4.zip`을 새 폴더에 압축 해제합니다.
3. `setup-officeflow-python.cmd`를 한 번 실행합니다. Python 3.12 64비트가 필요합니다.
4. `run-officeflow-python.cmd`로 실행합니다. 기존 `%LOCALAPPDATA%\OfficeFlow` DB·첨부·설정을 그대로 사용합니다.
5. 폴더를 옮겼다면 기존 바로가기를 새 실행기로 바꾸고 Windows 자동 시작 설정을 껐다가 켭니다.

DB·첨부를 ZIP 폴더에 복사하거나 테스트용 `.local-data`로 옮길 필요가 없습니다.
3.0.3 → 3.0.4는 DB 스키마 변경이 없으며, 설치형은 새 Setup.exe를 기존 버전 위에 설치할 수 있습니다.
회사 보안 정책 때문에 설치형을 쓸 수 없는 사용자는 계속 Python 모드를 사용하면 됩니다.

## 다운로드 파일

- `OfficeFlow-Python-3.0.4.zip`: Python 실행용 소스·실행기·설정 스크립트·도움말. 최초 설정에 인터넷이 필요합니다.
- `OfficeFlow-3.0.4-Setup.exe`: Windows 10/11 x64 설치형.
- `OfficeFlow-Python-3.0.4.zip.sha256.txt`: Python ZIP의 SHA-256.
- `SHA256SUMS.txt`, `release-manifest.json`: 배포 파일의 체크섬·버전·크기 목록.

기존 3.0.0~3.0.3 릴리스와 다운로드 파일은 유지합니다.
