# OfficeFlow 3.0.10 릴리스 체크리스트

작성일: 2026-10-11. 사용자 요청으로 지금까지의 미배포 작업을 마감·문서 정리·빌드·커밋·공개한다.
46~58번 문서의 미배포 표기는 작성 당시 기록이며 이번 릴리스 결과는 이 문서가 기준이다.

## 범위와 안전

- U17 폴더 바로가기, U16 읽기용 HTML/Excel 업무 묶음 보관(내부 정리는 제외).
- U18 등록/시간 입력, U19 알림 업무 보기, U20 클립보드 이미지, U21 썸네일.
- U22 화면 정돈 1~14와 빠른 등록 Enter 충돌 수정.
- DB0016·백업 v3, 업그레이드 전 DB 보호 사본·전체 백업 안내.
- 사용자 자료·실사용 설치 등록·자동 시작 설정은 검증에 사용하거나 교체하지 않는다.
- EXE/설치본/Windows ZIP/Python ZIP 및 체크섬·manifest를 생성한다.
- 처리 필요·알림/매시 규칙·자동 삭제·URL/클라우드 연결은 변경하지 않는다.

## 업데이트

기존 버전에서 전체 백업 후 트레이까지 종료한다. Python형은 새 ZIP을 별도 폴더에 풀고
setup을 한 번 실행한 뒤 새 run으로 시작한다. 같은 사용자 데이터 경로이면 DB/첨부 복사는 불필요하다.
첫 실행에 DB0016을 준비하므로 구버전으로 되돌리려면 업데이트 전 자료가 필요하다.
외부 폴더 내용은 백업에 포함되지 않으며 업무 묶음은 조회용 사본이다.
