# OfficeFlow 3.0.16

## 바뀐 점

- 달력 자동 갱신 결과가 같으면 목록을 다시 만들거나 선택을 복원하지 않습니다.
- 행 순서가 같으면 바뀐 내용만 갱신하고 선택·스크롤을 유지합니다.
- 달력에서 업무를 직접 클릭하는 동작, 임시 조회 후 선택 복원, 실패 후 재시도를 보완했습니다.
- 기존 창 종료 개선과 DB0017·전체 백업 v3·데이터 경로를 유지합니다.

## 업데이트

Python ZIP을 별도 폴더에 준비하는 동안 기존 OfficeFlow를 계속 사용할 수 있습니다.
**새 버전을 실행하기 직전**, 기존 앱에서 전체 백업을 만들고 트레이 메뉴에서 완전히 종료하세요.
구버전과 신버전을 같은 운영 자료로 동시에 실행하지 않습니다.

1. `OfficeFlow-Python-3.0.16.zip`을 별도 폴더에 풉니다.
2. `setup-officeflow-python.cmd`를 한 번 실행합니다.
3. `run-officeflow-python.cmd`로 실행합니다. 기존 `%LOCALAPPDATA%\OfficeFlow` 자료를 사용하므로
   DB/첨부를 프로그램 폴더로 복사하지 않습니다.

3.0.14/3.0.15에서 새 DB 이행은 없습니다. DB0017/해당 전체 백업은 3.0.14 이상에서 사용합니다.
Python ZIP에는 Python과 실행 라이브러리가 포함되지 않으며 최초 setup에는 인터넷 연결이 필요합니다.
EXE·설치본·Windows ZIP은 만들지 않습니다. GitHub의 자동 Source code ZIP 대신
릴리스 자산의 **OfficeFlow-Python-3.0.16.zip**을 받으세요.

## 검증과 한계

관련 회귀 고유 91개와 Windows 100/150/200% 검사를 통과했습니다.
실제 시스템 테마 전환이 아닌 밝은 UI와 팔레트 주입 검사입니다.
변화 없는 갱신의 위험 호출을 줄인 개선이며, 원래 응답 없음의 native 잠금 소유자는 미확정입니다.
실사용 무재발·회사 Excel/보안 제품과의 인과·전체 제품 회귀·장시간 운영은 확인하지 않았습니다.
구조 변경과 명시적 사용자 선택에는 필요한 Qt 선택 호출이 남습니다.

구현·검증 상세는 [89번](89-calendar-refresh-stability-results.md),
패키지 검사와 공개 결과는 [90번](90-release-checklist.md)을 따릅니다.
