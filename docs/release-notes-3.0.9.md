# OfficeFlow 3.0.9

오늘 완료한 운영 신뢰성·자료 조회 1~3차를 설치형·Windows ZIP·Python 실행형에 함께 반영합니다.

## 주요 변경

- 백업 실패/확인 필요 안내가 사라지지 않도록 유지하고, 데이터 관리에서 최근 결과와 확인 여부를 조회합니다.
  성공·실패·취소·보관 정리 경고를 구분합니다.
- `데이터 → 자료 검사`에서 현재/해제 첨부·보관본·중요 시점 파일의 상태를 읽기 전용으로 확인합니다.
  일반 파일의 정상 편집과 고정 파일의 변경, 누락·기준 없음·확인 불가를 구분합니다. 자동 수정/삭제는 하지 않습니다.
- 예외와 비정상 종료 진단을 남기고 진단 폴더를 열 수 있습니다. 강제 종료 전 안내나 모든 오류의 원인 확보를 보장하지 않으며 감시 프로그램/자동 재시작은 추가하지 않습니다.
- 첨부파일 검색에서 현재/해제 첨부뿐 아니라 개별 보관본·중요 시점 보관 파일과 메모를 종류별로 찾습니다.
  파일 내부 본문/OCR 검색은 아닙니다.
- 전체 백업을 현재 DB에 복원하지 않고 필요한 파일만 선택해 외부 폴더에 저장할 수 있습니다.
  기존 파일을 덮어쓰지 않으며, 일부 실패/취소는 저장 결과에 따로 표시합니다.
- 달력 하단과 오늘 알림을 같은 업무/원래 반복 회차별로 묶습니다. 실제 일정 없는 날의 알림은 `알림만`으로 구분합니다.
- `알림 시각 보기`에서 묶음 안의 개별 날짜·요일·시각·상태를 확인합니다. 업무 묶음 수와 실제 알림 건수를 구분하며 개별 알림의 확인/재알림/완료 처리 규칙은 유지합니다.
- 좁은 달력 하단의 세 번째 행과 안내 겹침, 작은 날짜 셀의 일정/알림 클릭 영역, 긴 제목과 새 창의 밝은 테마를 정비했습니다.

`처리 필요` 분류 변경, 폴더/URL 바로가기, 읽을 수 있는 외부 업무 묶음 보관, 자동 자료 삭제는 이번에 포함하지 않습니다.

## 업데이트와 호환

업데이트 전 전체 백업을 만들고 OfficeFlow를 트레이에서도 완전히 종료하세요.

3.0.9는 3.0.8과 같은 DB 스키마 0015·전체 백업 형식 v3를 사용합니다. 3.0.8에서 새 DB 이행은 없습니다.
3.0.7 이하의 DB는 보호 사본 후 0015로 업그레이드합니다. 기존 ID·파일 경로·내용은 유지하며 자동 원본 지정은 하지 않습니다.
새 DB/형식 v3 백업을 3.0.7 이하로 열지 마세요. 이전 형식 v1/v2 백업 읽기는 유지합니다.

### Python 실행형

1. `OfficeFlow-Python-3.0.9.zip`을 새 폴더에 압축 해제합니다.
2. Python 3.12 64비트 환경에서 `setup-officeflow-python.cmd`를 한 번 실행합니다.
3. `run-officeflow-python.cmd`로 시작합니다. 같은 데이터 경로를 사용하면 DB·첨부를 배포 폴더로 복사할 필요가 없습니다.
4. 실행 바로가기와 Windows 자동 시작을 새 실행기 위치에 맞춥니다.

최초 환경 구성용 오프라인 라이브러리는 이번 ZIP에 포함하지 않습니다. 처음 구성할 때 인터넷 연결 또는 승인된 라이브러리 공급 방법이 필요합니다. 회사 보안 정책을 우회하지 않습니다.

### Windows 설치형/ZIP

`OfficeFlow-3.0.9-Setup.exe`를 기존 설치 위에 실행합니다. 설치 없이 사용하려면
`OfficeFlow-3.0.9-Windows.zip`을 전체 해제하고 `OfficeFlow/OfficeFlow.exe`를 실행합니다.
EXE만 복사하면 안 되며 `_internal` 포함 전체 폴더가 필요합니다. 조직에서 EXE를 제한하면 허용된 Python 실행형을 사용하세요.

## 다운로드 파일

- `OfficeFlow-3.0.9-Setup.exe`: 설치·업데이트
- `OfficeFlow-3.0.9-Windows.zip`: 전체 EXE 폴더
- `OfficeFlow-Python-3.0.9.zip`: Python 소스·실행기·설정기·도움말
- `OfficeFlow-Python-3.0.9.zip.sha256.txt`: Python ZIP 체크섬
- `SHA256SUMS.txt`: 빌드 파일 체크섬 목록
- `release-manifest.json`: 버전·빌드 정보·파일 크기·체크섬

사용자 DB·첨부·백업·로그는 포함하지 않습니다. 체크섬은 다운로드 손상 확인용이며 코드 서명이나 보안 인증을 대신하지 않습니다.
검증 결과와 미검증 환경은 [3.0.9 릴리스 체크리스트](https://github.com/spelld77/officeflow-v3/blob/main/docs/45-release-checklist.md)를 참고하세요.
