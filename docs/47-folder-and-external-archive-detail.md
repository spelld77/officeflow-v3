# 폴더 바로가기·외부 업무 보관 상세설계

## 1. 폴더

`task_folder_links`: id, task_id(FK cascade), name(1~200), path, position, created_at.
업무당 최대 50개. 같은 실제 경로의 중복 등록은 거절한다. 추가 순서로 표시한다.
폴더 탭: 목록 → `열기 / 추가 / 이름 변경 / 폴더 다시 지정 / 연결 삭제`.
선택 경로는 별도 줄(줄바꿈/전체 툴팁), 목록 자체는 늘어나는 영역과 세로 스크롤을 가진다.
긴 이름은 말줄임+툴팁으로 보이고 가로 스크롤은 만들지 않는다. 새로고침으로 다른 창의 변경을 재조회한다.
등록 시 실제 경로로 정규화하여 alias 중복을 막는다. 이름/재지정 명령은 이전 값을 확인해 다른 창의 변경을 덮어쓰지 않는다.
열기 실패 안내는 이동/이름 변경뿐 아니라 권한·공유 드라이브 연결도 구분하여 안내한다.
목록 조회는 파일 시스템에 접근하지 않는다. 재지정은 동일 ID/이름/순서를 유지한다.
연결 삭제 확인 문구: 실제 폴더와 파일은 삭제하지 않습니다.

## 2. 보관 범위

연도 기본값은 현재 연도, 사용자 기간은 시작~끝 날짜(양끝 포함, 설정 시간대).
날짜 기준 선택: `등록일 / 완료일 / 최근 수정일`. 기본 등록일로 일정 없는 업무도 포함한다.
`완료 업무만` 기본 켬. 진행 업무는 이를 끄면 포함한다. 휴지통 업무는 항상 제외한다.
선택 업무 범위는 메인 목록의 선택 ID를 사용하며 날짜 필터를 적용하지 않는다.
반복 업무는 1개 업무로 보관하고 저장된 회차의 상태·결과를 상세에 포함한다.
미래 반복 회차를 생성/확장하지 않는다. 회차 날짜 기준 내보내기는 이번 범위가 아니다.
주 화면 검색/필터는 기간 보관에 적용하지 않는다. 이를 옵션 창에 명시한다.

내용: 제목·설명·상태·중요도·일정/반복정보·결과·체크리스트·업무일지·저장된 회차·폴더 연결 정보.
현재 첨부 기본 포함, 개별 보관본/중요시점 파일은 옵션으로 추가한다.
해제 첨부/캐시/자동 변경 이력/중요시점 정보 payload 전체/외부 연결 폴더 내용은 제외한다.
특정 파일만 저장할 때는 기존 첨부의 선택 저장 기능을 사용한다. 묶음에서는 파일 종류 단위로 선택한다.
완료 상태만으로 최종 제출 파일을 추정하지 않는다. 옵션에서 보관 자료 포함을 결정한다.

## 3. 결과

`OfficeFlow_2026_생성시각_고유ID/업무목록.html`, `업무목록.xlsx`, `첨부파일/업무ID/...`,
`보관정보.json`, `완료.txt`. 실패 시 `미완료.txt`를 유지하며 위치를 오류에 포함한다.
HTML compact details 행, 키워드 입력/지우기, 상태 필터, 일치 업무 수. JS 꺼도 모든 업무를 펼쳐 읽을 수 있다.
검색 대상: 제목/설명/결과/체크리스트/일지/파일명·메모/폴더명·경로. 첨부 본문/OCR 검색은 없다.
파일 링크는 bundle 상대 경로를 URI 인코딩하며 사용자 텍스트를 HTML/JS로 실행하지 않는다.
Excel 업무목록 시트 1업무 1행 + 상세 시트에 유형/순번/분할문구 + 파일 시트의 역할/메모/상대 경로.
시트 autofilter/freeze pane, 텍스트 명시, Excel 금지 제어문자는 가독성 있는 표기로 치환한다.
본문은 HTML에 보존한다. 폴더 바로가기는 설명으로만 포함하며 HTML에서 외부 경로 자동 실행하지 않는다.
파일명은 안전한 이름+충돌 번호. sha256/크기를 manifest에 기록한다.
임시 HTML/XLSX 작성 후 닫기·fsync 및 재읽기 확인. 완료 표식은 마지막에만 만든다.
완료 표식도 임시 파일 작성·fsync 후 이름 변경으로 공개한다. 표식 작성 실패는 미완료로 남긴다.
이미 완료 표식을 공개한 뒤 미완료 표식 제거만 실패하면 보관 성공과 정리 경고를 함께 표시한다.
완료 후 `보관 폴더 열기` 제공, 문서 자동 열기는 하지 않는다.

## 4. 검증

신규/0015 이행·FK cascade·휴지통 읽기전용·백업 연결 보존·외부 내용 백업 제외.
폴더 재지정/이름 변경/내부·junction 거절/없는 공유 경로의 연결 유지.
기간 경계/선택 ID/일정 없는 업무/완료 필터/반복 회차/파일 옵션.
HTML escape·숨은 상세 검색·상대 링크/수식 주입·긴 본문 분할/동명·긴 파일명.
변경·누락·잠금·취소·출력 실패 시 미완료, pin·스레드 해제, 원본 미변경.
종합 회귀·lint/type·새 UI 밝음/어둠 palette와 100/150/200 배율 렌더링.
배포 및 실제 회사 PC의 공유 드라이브/보안제품 환경 검증은 별도다.
