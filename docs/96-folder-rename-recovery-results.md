# U43 연결 폴더 이름 변경 확인·복구 구현 결과

2026-11-11 사용자 `구현해` 요청으로 [95번 상세설계](95-folder-rename-recovery-design.md)를 구현했다.
상태: **개발 소스 구현·관련 격리 검증 완료. 후속 3.0.18 배포/공개는 [97번](97-release-checklist.md)을 따른다. 사용 확인은 별도다.**
기존 미커밋 첨부 안내 제거/전체·예정 정렬 변경을 보존했다.

## 구현

- 새 연결/명시적 다시 지정에서만 가능한 식별 정보를 저장한다. 기존 연결은 NULL로 유지하고
  열기/목록/표시 이름 수정 때 자동 수집하지 않는다. 기존 첨부의 내용/경로/원장은 변경하지 않는다.
- 로컬 고정 NTFS의 MachineGuid 해시·볼륨 serial·128-bit FileId·생성 시각을 사용한다.
  지원하지 않는 새 연결은 기존 경로 연결로 저장한다. 추적 연결의 식별 확인 불가는 수동 지정을 안내한다.
- 기존 경로가 정상이면 바로 확인/열기, FileNotFound일 때만 같은 상위 폴더의 직접 하위 항목을 찾는다.
  이름의 숫자나 유사 문자열로 동일 폴더라고 판정하지 않는다. 다른 PC·권한 오류·다른 볼륨·미지원은 자동 복구하지 않는다.
- 단일 후보를 찾으면 비동기 확인창에서 `이 폴더 사용 / 다른 폴더 선택 / 취소`를 제공한다.
  확인 전 DB 변경/폴더 열기는 없다. 승인 시 후보를 다시 검증하고 expected DB 값을 대조해 갱신한 뒤 연다.
  이전 폴더명을 그대로 쓰던 표시 이름만 새 이름으로 바꾸며, 별도 이름은 유지한다(200자 상한).
- 취소/후보 재변경/다른 창 수정/기존 경로에 생긴 다른 폴더/후보 복수는 연결을 보존한다.
  새 경로 저장 후에는 새 경로로 바로 연다. 휴지통/읽기 전용에서는 자동 경로 갱신을 제안하지 않는다.
- 폴더 검증은 helper 자식 프로세스가 수행하고 worker가 5초 상한/취소를 확인해 자기 helper만 종료·회수한다.
  탐색은 1,000항목·2초 예산이며 단일 OS 호출이 지연될 때는 상위 helper 시간 제한을 적용한다.
  앱 시작/목록 렌더링에서 외부 경로 조사·상시 감시·전체 디스크 검색·자동 재시도를 하지 않는다.
- 외부 폴더에 식별 표식 파일을 쓰거나 이름/내용을 변경하지 않는다. 평소 UI 버튼/상시 안내 줄도 추가하지 않았다.

## DB·백업

DB0018 `task_folder_links.folder_identity` nullable TEXT 열만 추가한다.
0017 기존 연결은 모두 NULL인 채로 보존하며 자료를 순회하지 않는다. 기존 보호 사본/구버전 차단을 유지한다.
전체 백업 v3는 그대로이며 새 열을 포함한다. 0018 백업에서 열이 빠지면 손상된 스키마로 거부한다.
기존 연결의 백업/복원·작업 삭제 시 연결 행만 삭제하는 검사도 통과했다.
검증기와 최신 revision 단언 3곳은 새 head로 맞췄다. imported_data_compatibility의 revision 단언도 갱신했으나
해당 파일 전체 실행은 이번에 하지 않았다.

**0018 DB/백업은 기존 공개 3.0.17 이하에서 사용하지 않는다.** 아직 운영 DB를 이행하지 않았고,
새 버전/배포도 하지 않았다. 실제 전환 안내는 후속 릴리스 때 필요하다.

## 실패/범위 보완과 보존

- 기존 junction 검사 1개가 제한 권한에서 생성 실패했다. 실패한 합성 검사만 별도 권한으로 확인해 통과했다.
- 기존 회귀의 `-k folder`가 파일명까지 일치해 외부 보관 검사도 함께 실행됐다.
  계획보다 범위가 넓어져 32MiB 합성 파일 검사/중단 보존 검사도 포함됐으며 44.86초에 완료했다.
  이를 '소형 폴더 검사만 수행'으로 표시하지 않는다. 추가 대용량/장시간 반복은 하지 않았다.
- 초기 lint의 import/예외 연쇄·테스트 lambda/fixture 가정을 정리했다. 실행 검사 실패는 junction 1개뿐이다.
- 모든 DB/폴더는 이번 소유 tmp_path이고 자식 앱/검사 환경에 별도 OFFICEFLOW_DATA_DIR/TEMP/TMP를 명시했다.
  helper는 앱/DB를 초기화하지 않는다. 운영 DB/첨부/설정/외부 폴더·실행 중인 앱은 사용하거나 변경하지 않았다.
- 소유 fixture는 경로·링크 경계를 확인해 정리하고 XML/JSON/작은 캡처를 보존한다.
  버전·배포물·커밋/GitHub 공개는 이번 요청에 포함하지 않았다.
