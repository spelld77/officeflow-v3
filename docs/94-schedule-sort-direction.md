# 전체·예정 탭 일정순 보완

2026-11-11 사용자 수정 요청과 후속 예정 탭 포함 요청에 따른 구현 전 결정.

- 전체·예정 탭의 기본 `일정순`은 시작일 내림차순(미래→과거)으로 한다.
- 고정 우선, 날짜 없는 업무 마지막, 동일 시각의 중요도/제목/ID 결정 순서는 유지한다.
- SQL에서 페이지를 자르기 전에 정렬한다. 현재 시각에 따른 별도 그룹 재배치는 하지 않는다.
- 다른 탭의 일정순과 중요도/수정일/제목순, 저장된 정렬 선택은 유지한다.
- 정렬 방향 선택 UI/새 설정은 추가하지 않는다. DB/운영 자료/버전/배포/Git는 변경하지 않는다.
- 앞선 첨부 안내 제거의 미커밋 변경을 보존한다. 관련 소형 합성 정렬 검사만 수행한다.

SQL 정렬에 탭 범위를 전달해 전체·예정의 일정순에만 내림차순을 적용했다.
기존 저장값 `schedule`에도 새 방향이 적용되며 다른 저장된 정렬 선택은 유지한다.
관련 합성 검사 3개 통과: 두 탭의 실제 DB 정렬/페이지 경계·고정 우선·날짜 없음 마지막,
오늘 탭의 오름차순과 명시적 제목 정렬을 확인했다. Ruff·format check 통과.
증거: artifacts/schedule-sort/results.xml. 전체 회귀·화면 배율 검사는 반복하지 않았다.
운영 DB/설정·실행 중 앱·버전·배포/Git는 변경하지 않았다. 공개 ZIP에는 아직 미반영이다.
