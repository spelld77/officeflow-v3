# 메모리·창 자원 누적 조사 기록

기록일: 2026-10-26. 대상: 3.0.13 개발 기준 소스. 상태: 조사/후속 목록 기록만, 수정 전.
후속 요청으로 [80번 공통설계](80-resource-and-task-finding-common-design.md)와
[81번 상세설계](81-resource-lifecycle-detail-design.md)를 작성했다. 아래 재현/측정은 설계 전 사실이며 구현 완료를 뜻하지 않는다.
회사 PC의 Python 실행 중 간헐적 종료 보고다. 여러 업무 프로그램과 브라우저가 함께 느려졌으나
메모리 부족 안내 여부·종료 시각은 확인되지 않았다. 회사 PC의 종료 기록은 여기서 조회하지 못했다.
현재 개발 PC의 최근 14일 시스템 이벤트 2004는 없었고 조회한 Application 1000/1001 중
OfficeFlow/pythonw 일치 기록은 없었다. 이는 회사 PC의 원인을 부정하는 근거가 아니다.

## 재현한 정리 누락

| 항목 | 생성/처리 반복 | 남은 객체 | 수명/근거 |

메뉴/입력창 시험은 표시·사용자 선택을 시험용으로 생략하고 실제 생성/취소 후 정리 경로를 검사했다.
첨부 진행창은 실제 복사 대신 종료 정리 경로를 실행했다. 실제 파일/회사 데이터의 복사·변경은 없었다.
GC 및 Qt 지연 삭제 이벤트 처리 뒤에도 남는 객체를 셌다. 상위 창을 닫아야 정리되는 누적과
프로그램 종료까지 남는 누적을 구분한다. 각각의 MB 증가량 전부를 누수량으로 등치하지 않는다.

## 제한된 메모리 측정

Windows Qt, 작은 합성 제목/설명, 메모리 내 저장소를 사용했다. 실사용 DB/첨부는 열지 않았다.
GetProcessMemoryInfo의 PrivateUsage 차이이며 단위는 MiB다. 같은 시험 프로세스에서 종류별 시작점을 다시 잡았다.
완전한 화면 표시/렌더링·문서 내용/이미지·실제 회사 환경을 포함하지 않은 참고값이다.

| 종류 | 10회 | 30회 | 40회 |
| --- | ---: | ---: | ---: |
| 업무 메뉴 | 0.168 | 0.898 | 1.539 |
| 업무 알림창 | 8.289 | 25.055 | 33.328 |
| 완료 입력창 | 4.656 | 14.039 | 20.293 |

초기화·메모리 할당자·캐시·측정 순서 영향을 포함한다. 회당 고정 비용/장시간 증가율로 외삽하지 않는다.
화면 표시까지 포함하려던 별도 시험은 측정 전 시험 프로세스가 일찍 종료되어 수치를 얻지 못했다.
이 시험은 측정 결과에서 제외하며 실제 앱 종료의 원인을 재현했다고 주장하지 않는다.
메뉴의 native exec 시험 대기/중단도 종료 후 자동 삭제 여부의 근거로 사용하지 않고,
표시를 생략한 제한 시험으로 다시 검사했다. 실제 Windows 장시간 실행/화면 포함 측정은 추후 필요하다.

## 짧은 시험에서 정상 정리를 확인한 범위

- 업무 보기·새 업무·일반 설정 각 10회 종료 뒤 해당 native 창 객체와 보관 목록 0.
- 첨부 서비스를 연결한 업무 보기 20회 종료 뒤 창·첨부 구독자·공유 썸네일 client 0.
- 하루 조회·알림 미리보기 조회 각 30회 완료 뒤 QThread와 worker/thread wrapper 0.
- 이력 창 10회 종료 뒤 이력 창·구독자·보관 목록 0.
- 30초 숨김 유휴 시험에서는 창 개수가 늘지 않았다. 장시간 누수 없음의 증명은 아니다.

## 후속 검토 범위

U36의 순서대로 명확한 정리 누락부터 수정한다. 숨김 화면 재조회, 유휴 복구 점검의 반복 스레드 생성,
리소스 기록 부재는 별도 비용/관측 개선 후보다. 원래 알림 예약·미처리 알림·미저장 입력·저장 소유권을 유지한다.
짧은 시험만으로 모든 누수 없음 또는 회사 PC 강제 종료 해결을 약속하지 않는다.
조사 시에는 이 문서와 개선 목록만 기록했고, 이후 요청으로 80~82번 설계 문서를 추가했다.
실행 코드·DB·사용자 파일·배포물·GitHub는 변경하지 않는다.

후속 `구현과 테스트 실행해` 승인 이후의 소스 수정/반복 검증은 [83번](83-resource-and-task-finding-results.md)을 따른다.
이 문서의 MB와 잔여 객체 수는 개선 전 제한 시험이며, 수정 후 실측과 합치지 않는다.
